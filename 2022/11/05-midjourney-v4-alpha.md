# Midjourney V4 alpha release

- **Date:** 2022-11-05
- **Who:** Midjourney
- **Type:** model

Midjourney released an alpha of version 4 of its image model to users. V4 added image prompts alongside text prompts, better understanding of creatures and multi-subject scenes, and the Remix feature, which drove wide sharing. The release pushed the service further toward photorealism, which drew attention to how realistic AI images had become.
