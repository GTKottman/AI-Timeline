# Anthropic acquires Stainless

- **Date:** 2026-05-18
- **Who:** Anthropic; Stainless
- **Type:** acquisition

Anthropic acquired Stainless, a New York startup that generates SDKs from API specifications. Anthropic did not disclose the terms. Anthropic said it would wind down Stainless's hosted products, and existing customers keep the SDKs they have already generated.
