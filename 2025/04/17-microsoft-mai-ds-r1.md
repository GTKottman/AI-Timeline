# Microsoft MAI-DS-R1 post-trained DeepSeek-R1

- **Date:** 2025-04-17
- **Who:** Microsoft AI
- **Type:** model

Microsoft released MAI-DS-R1, an open-weight post-trained version of DeepSeek-R1 that was retrained to answer blocked topics, such as those restricted in China, while keeping its reasoning ability. It was released through Azure AI Foundry and Hugging Face. Microsoft claimed a 99.3% response rate on blocked-topic prompts and no loss in general reasoning; those are Microsoft's own figures. An aggregator lists April 21, so the exact day rests on Microsoft's post.
