# Nvidia publishes Megatron-LM, training an 8.3B-parameter language model

- **Date:** 2019-09-17
- **Who:** Nvidia Applied Deep Learning Research
- **Type:** research

Nvidia's Megatron-LM paper showed a GPT-2-style transformer with 8.3 billion parameters, trained with intra-layer model parallelism on 512 GPUs. It reached state-of-the-art perplexity on WikiText103 and accuracy on LAMBADA. The code was released publicly, and it became a template for training very large language models.
