# MosaicML releases MPT-7B open model

- **Date:** 2023-05-05
- **Who:** MosaicML
- **Type:** model

MosaicML released MPT-7B, a 7-billion-parameter model trained from scratch on about 1 trillion tokens and licensed Apache 2.0 for commercial use, along with instruction-tuned and long-context variants. MosaicML said the base training cost about $200k. It mattered because a commercially usable open model trained at this cost made custom LLM training look practical for businesses. The Chat variant carried a non-commercial licence, unlike the base model.
