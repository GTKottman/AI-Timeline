# Baidu brings NVIDIA Pascal GPUs into its cloud for AI

- **Date:** 2017-04-17
- **Who:** Baidu; NVIDIA
- **Type:** hardware

NVIDIA's April 17, 2017 press release, "Baidu Advances AI in the Cloud with Latest NVIDIA Pascal GPUs," said Baidu was using the latest NVIDIA Pascal-generation GPUs to advance AI in its cloud. Only the release headline was checked in detail for this entry.
