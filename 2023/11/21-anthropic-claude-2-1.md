# Anthropic releases Claude 2.1 with 200K-token context

- **Date:** 2023-11-21
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude 2.1 with a 200K-token context window, about 150,000 words, and said it halved the rate of false statements compared with Claude 2.0. The release added system prompts, a beta tool-use feature and reduced pricing. Computerworld reported that the full 200K window was for paying Pro users, while free users kept a 100K limit.
