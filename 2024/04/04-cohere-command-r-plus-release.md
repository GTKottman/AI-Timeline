# Cohere releases Command R+ open-weights model for retrieval and tool use

- **Date:** 2024-04-04
- **Who:** Cohere
- **Type:** model

Cohere released Command R+, a 104 billion parameter model with a 128K context window, aimed at retrieval-augmented generation and tool use, and followed Command R from March 2024. Its weights were published as an open research release under CC-BY-NC, so commercial use required API access or a separate contract. Cohere positioned it for enterprise RAG and tool use.
