# G7 leaders launch the Hiroshima AI Process

- **Date:** 2023-05-20
- **Who:** G7 leaders (Hiroshima Summit, hosted by Japan)
- **Type:** policy

At the G7 summit in Hiroshima, leaders agreed to set up the "Hiroshima Process" on governing generative AI in line with shared democratic values, with cabinet-level talks to report by year-end. The process later produced a comprehensive policy framework with guiding principles and a code of conduct, agreed in December 2023. It mattered as the first multilateral G7 framework aimed specifically at generative AI.
