# Google releases ShieldGemma safety classifiers and Gemma Scope interpretability tools

- **Date:** 2024-07-31
- **Who:** Google / Google DeepMind
- **Type:** software

Google released ShieldGemma, a set of safety classifiers that flag hate speech, harassment, sexually explicit content and dangerous content in model inputs and outputs, in several sizes. The same day it released Gemma Scope, a set of over 400 freely available sparse autoencoders covering the layers of Gemma 2 2B and 9B for interpretability research. Google's release log lists both as initial releases on July 31, 2024.
