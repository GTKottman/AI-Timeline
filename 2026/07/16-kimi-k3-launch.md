# Moonshot launches Kimi K3, a 2.8-trillion-parameter model

- **Date:** 2026-07-16
- **Who:** Moonshot AI
- **Type:** model

Moonshot launched Kimi K3 on July 16, 2026 as a 2.8-trillion-parameter mixture-of-experts model with native vision and a 1-million-token context, live on Kimi products and the API. The full weights and technical report were promised for July 27; one source says they shipped that day, but the Hugging Face page still read "upcoming" in the sources checked, so the weights status is unconfirmed. Moonshot's launch pricing lists $3 per million uncached input and $15 per million output tokens, and it says K3 still trails Claude Fable 5 and GPT-5.6 Sol overall. Benchmark results so far are company-run or from mixed harnesses.
