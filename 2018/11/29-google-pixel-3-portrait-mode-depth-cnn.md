# Google's Pixel 3 switches Portrait Mode depth to a neural network

- **Date:** 2018-11-29
- **Who:** Google (Pixel camera team)
- **Type:** product

Google explained that Pixel 3 Portrait Mode replaces traditional stereo depth with a convolutional neural network that predicts depth from dual-pixel autofocus images. The network was trained on data captured with a custom rig of five Pixel 3 phones. It runs on the phone GPU through TensorFlow Lite and is combined with person segmentation masks. It showed a shipped consumer product running a trained depth network on-device.
