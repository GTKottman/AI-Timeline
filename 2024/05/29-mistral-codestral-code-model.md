# Mistral launches Codestral, its first code model

- **Date:** 2024-05-29
- **Who:** Mistral AI
- **Type:** model

Codestral is an open-weight model focused on code generation across many programming languages. It was Mistral's first generative model specialised for coding, aimed at developer tools and IDE integration.
