# Anthropic releases Claude Sonnet 4.6

- **Date:** 2026-02-17
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude Sonnet 4.6, a full upgrade across coding, computer use, long-context reasoning and agent planning. It added a 1M-token context window in beta. Pricing stayed at $3 and $15 per million tokens, the same as Sonnet 4.5. It followed Opus 4.6 by twelve days.
