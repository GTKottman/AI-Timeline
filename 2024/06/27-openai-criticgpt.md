# OpenAI introduces CriticGPT to find errors in ChatGPT code

- **Date:** 2024-06-27
- **Who:** OpenAI (paper co-authored by Jan Leike)
- **Type:** research

OpenAI introduced CriticGPT, a GPT-4-based model trained to critique ChatGPT responses and point out bugs in its code, to help human trainers during RLHF labelling. In OpenAI's tests, people who had CriticGPT's help outperformed unaided reviewers 60% of the time. The accompanying paper, "LLM Critics Help Catch LLM Bugs," described AI-assisted human feedback as a route to scalable oversight, and OpenAI said the tool was used internally rather than released publicly.
