# Report reveals Anthropic's Project Panama book-scanning effort

- **Date:** 2026-01-27
- **Who:** Anthropic
- **Type:** dataset

A Washington Post report described Project Panama, an Anthropic effort to buy physical books in bulk, cut off their bindings, scan them for AI training data and then recycle the paper. The project was led by Tom Turvey, a former Google executive.
