# OpenAI releases the Responses API and Agents SDK

- **Date:** 2025-03-11
- **Who:** OpenAI
- **Type:** software

OpenAI released the Responses API with built-in web search, file search and computer use tools. It also released the open-source Agents SDK, an upgrade of its experimental Swarm project, with agent handoffs, guardrails and tracing. OpenAI positioned the Responses API as the successor to the Assistants API and set a target of mid-2026 for sunsetting the Assistants API, which it called a target rather than a firm date. Coverage dates the launch March 11, 2025.
