# OpenAI launches Codex, a cloud software engineering agent

- **Date:** 2025-05-16
- **Who:** OpenAI
- **Type:** product

OpenAI launched Codex as a research preview: a cloud agent that runs many coding tasks in parallel, each in an isolated environment with the user's GitHub repository. It is powered by codex-1, a version of o3 tuned for software engineering. It first reached ChatGPT Pro, Team and Enterprise users, and Plus users got access on June 3, 2025.
