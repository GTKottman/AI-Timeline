# DeepSeek releases V4.1-Flash, natively multimodal

- **Date:** 2026-09-10
- **Who:** DeepSeek
- **Type:** model

DeepSeek released V4.1-Flash, a natively multimodal model with a different encoder-decoder architecture from V4 and lower memory use. DeepSeek said it beat Kimi K3 on cyber and coding benchmarks.
