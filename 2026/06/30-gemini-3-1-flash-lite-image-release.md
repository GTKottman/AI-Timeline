# Google releases Gemini 3.1 Flash-Lite Image (Nano Banana 2 Lite)

- **Date:** 2026-06-30
- **Who:** Google DeepMind
- **Type:** model

Google released a cost-effective image model built on Gemini 3.1 Flash-Lite, called Nano Banana 2 Lite. It pushed image generation toward lower-cost, high-volume use.
