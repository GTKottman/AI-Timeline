# YOLOv4 object detector released with open-source code

- **Date:** 2020-04-23
- **Who:** Alexey Bochkovskiy, Chien-Yao Wang, Hong-Yuan Mark Liao
- **Type:** model

The arXiv paper "YOLOv4: Optimal Speed and Accuracy of Object Detection" combined existing CNN improvements such as Mish activation, cross-stage-partial connections and Mosaic augmentation into one detector. It reached 43.5% AP on MS COCO at about 65 FPS on a Tesla V100, with source code published. The release made YOLO-family detectors a common choice for real-time vision applications.
