# Helios real-time long video model released

- **Date:** 2026-03-04
- **Who:** Peking University, ByteDance
- **Type:** model

Helios is a 14B-parameter autoregressive diffusion model that generates minute-scale video in near real time, reported at 19.5 FPS on a single NVIDIA H100 (the authors' figure). It supports text-to-video, image-to-video and video-to-video. It matters because long, fast video generation on one GPU makes video models usable for interactive work rather than only offline rendering.
