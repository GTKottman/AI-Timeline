# OpenAI launches ChatGPT plugins

- **Date:** 2023-03-23
- **Who:** OpenAI
- **Type:** product

OpenAI launched plugins for ChatGPT, tools built for language models that let the chatbot reach live information, run calculations and call outside services. The first rollout went to ChatGPT Plus users with about a dozen third-party plugins, including Expedia, Instacart, OpenTable, Shopify, Slack and Zapier, plus OpenAI's own web browser and code interpreter. It mattered because it turned ChatGPT from a closed text box into a platform that other companies could extend.
