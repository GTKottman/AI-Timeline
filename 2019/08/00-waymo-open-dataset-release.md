# Waymo Open Dataset Released

- **Date:** 2019-08-00
- **Who:** Waymo (Alphabet)
- **Type:** dataset

Waymo released the Waymo Open Dataset, a multimodal sensor dataset from its self-driving vehicles, to let outside researchers train and test autonomous driving perception. The release contains 1,000 driving segments of 20 seconds each, with data from five lidars and five cameras, plus 12 million 3D labels and 1.2 million 2D labels. Coverage spans Phoenix, Kirkland, Mountain View and San Francisco. The exact release day was not confirmed in the sources, so only the month is recorded; trade coverage is dated August 21-22, 2019.
