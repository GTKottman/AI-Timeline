# Meta releases V-JEPA 2 video world model

- **Date:** 2025-06-11
- **Who:** Meta AI (FAIR)
- **Type:** model

Meta released V-JEPA 2, a video-trained world model that predicts how the physical world responds to actions, with code and three new physical-reasoning benchmarks. Coverage says it infers properties such as gravity, anticipates object motion, and supports zero-shot robot planning. It mattered as an open step toward models that plan by predicting physical outcomes instead of generating pixels.
