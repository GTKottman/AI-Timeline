# Microsoft gets exclusive license to GPT-3 from OpenAI

- **Date:** 2020-09-22
- **Who:** Microsoft, OpenAI
- **Type:** acquisition

Microsoft announced an exclusive license to GPT-3 technology from OpenAI to build AI products and services, as part of a multiyear partnership that extended its 2019 investment. OpenAI kept its own GPT-3 API, so public access continued. MIT Technology Review noted that GPT-3 was likely the first of several models to be licensed exclusively to Microsoft.
