# OpenAI enables native image generation in GPT-4o, and Ghibli-style images go viral

- **Date:** 2025-03-25
- **Who:** OpenAI
- **Type:** product

OpenAI enabled native image generation inside GPT-4o, replacing DALL-E for ChatGPT images. Users quickly made Studio Ghibli-style pictures that went viral. The release showed a single multimodal model generating images, rather than a separate image model.
