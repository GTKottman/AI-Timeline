# Google researchers publish Titans: neural long-term memory for test time

- **Date:** 2024-12-31
- **Who:** Google Research
- **Type:** paper

The Titans paper, posted to arXiv on the last day of 2024, proposes a neural long-term memory module that is updated while the model runs, so attention can focus on the current input while still reaching far-back context. The authors built a family of three architecture variants on this module. They reported better results than Transformers and recent linear recurrent models on language modeling and needle-in-haystack retrieval at context lengths beyond 2 million tokens.
