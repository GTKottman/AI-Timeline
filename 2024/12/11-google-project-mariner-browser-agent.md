# Google unveils Project Mariner, a Chrome agent that uses the web for you

- **Date:** 2024-12-11
- **Who:** Google DeepMind
- **Type:** product

Google DeepMind unveiled Project Mariner, a research prototype built on Gemini 2.0 that runs in Chrome, moves the cursor, clicks and fills in forms. It works only on the active tab, which Google said keeps users able to watch it. It does not handle checkout or payment details, and it does not accept cookies or terms for the user. It was first shown to a small set of preselected testers, and one source says it scored 83.5% on WebVoyager.
