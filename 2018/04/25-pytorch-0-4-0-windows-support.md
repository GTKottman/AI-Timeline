# PyTorch 0.4.0 released with Windows support

- **Date:** 2018-04-25
- **Who:** Facebook AI Research and PyTorch community
- **Type:** software

PyTorch 0.4.0 merged the Variable and Tensor classes, deprecated the volatile flag, and added Windows support. It also brought fuller advanced indexing, FFT support and better ONNX export. The official migration guide is dated April 22, and press coverage reports the release on April 25; this file uses the press date.
