# DeepMind Flamingo visual language model

- **Date:** 2022-04-29
- **Who:** DeepMind
- **Type:** model

DeepMind described Flamingo, a family of vision-language models that learn new tasks from only a few image-and-text examples in the prompt. Few-shot multimodal prompting like this became a major research direction for image-understanding models.
