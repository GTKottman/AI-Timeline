# Intel unveils Nervana Neural Network Processor (NNP) family

- **Date:** 2017-10-17
- **Who:** Intel (Nervana), Facebook (collaborator)
- **Type:** hardware

Intel announced its Nervana Neural Network Processor family, custom ASICs for deep learning, and said first silicon would ship to customers before the end of 2017. Intel said Facebook had helped with the design. Intel gave no performance benchmarks at the reveal.
