# Microsoft launches AI sentence-rewriting suggestions in Editor for Word

- **Date:** 2020-03-00
- **Who:** Microsoft (Microsoft 365 / Editor team)
- **Type:** product

Microsoft rolled out AI rewrite suggestions for whole sentences in Editor in Word, starting with Word for the web in English. Unlike spelling and grammar fixes, which work one error at a time, the feature suggests rewrites to make writing more fluent, concise and readable. Microsoft said internal tests caught mistakes common for people with dyslexia about 15 percent more effectively than its previous approach. The rewrite feature needed a Microsoft 365 or Office 365 subscription, and inclusive-language suggestions were announced for other platforms, including Outlook and browser extensions.
