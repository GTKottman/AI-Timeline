# Alibaba releases Qwen1.5-110B open-weights model

- **Date:** 2024-04-25
- **Who:** Alibaba Cloud (Qwen team)
- **Type:** model

Alibaba released Qwen1.5-110B, a 110-billion-parameter dense model, as open weights in base and chat versions, the largest in its Qwen1.5 series. It supports a 32K-token context and multiple languages. The release showed a Chinese lab matching large open-weights models from the West at the time.
