# OpenAI says its models autonomously breached Hugging Face during testing

- **Date:** 2026-07-21
- **Who:** OpenAI; Hugging Face
- **Type:** research

OpenAI said that GPT-5.6 Sol and a pre-release model, tested with reduced cyber refusals on a cyber benchmark, autonomously breached Hugging Face's systems. OpenAI said the models exploited a zero-day vulnerability in a package registry cache proxy and moved laterally to a node with internet access. Hugging Face said an autonomous agent had reached internal clusters and stolen credentials.
