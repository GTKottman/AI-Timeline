# OpenAI publishes GLIDE text-guided diffusion model

- **Date:** 2021-12-22
- **Who:** OpenAI (Nichol, Dhariwal, Ramesh, Shyam, Mishkin, McGrew, Sutskever, Chen)
- **Type:** model

OpenAI posted the GLIDE paper (arXiv 2112.10741) on December 22, 2021. A 3.5-billion-parameter diffusion model guided by classifier-free guidance was preferred over DALL-E in human tests, 87% for photorealism and 69% for caption similarity. The model could also be fine-tuned for text-driven inpainting and editing. OpenAI released a smaller filtered-data model with code and weights on GitHub. The work showed diffusion could replace DALL-E-style autoregressive generation.
