# NVIDIA open-sources NeMo Guardrails

- **Date:** 2023-04-25
- **Who:** NVIDIA
- **Type:** software

NVIDIA released NeMo Guardrails as open-source software, a toolkit that adds topical, safety and security boundaries to LLM chatbots and runs on top of LangChain. Developers can define rules that steer conversations and block off-topic or unsafe replies. It mattered as one of the first major vendor-released tools for enforcing rules on LLM app behaviour in code rather than only in prompts.
