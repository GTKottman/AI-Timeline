# Google Cloud TPU available in beta, opened to outside companies

- **Date:** 2018-02-12
- **Who:** Google Cloud
- **Type:** hardware

Google made its Cloud TPU machine learning accelerators available in beta on Google Cloud Platform, letting outside companies rent TPU capacity for training and inference rather than only using them internally. It was the first time Google sold access to its custom AI chips to third parties.
