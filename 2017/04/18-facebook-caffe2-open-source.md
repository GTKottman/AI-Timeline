# Facebook open-sources Caffe2 deep learning framework

- **Date:** 2017-04-18
- **Who:** Facebook, with NVIDIA, Intel, Qualcomm, Amazon and Microsoft
- **Type:** software

At its F8 conference, Facebook open-sourced Caffe2, a cross-platform deep learning framework that succeeded the Berkeley Caffe project. It was aimed at deployment on mobile devices and at scale. NVIDIA, Intel, Qualcomm, Amazon and Microsoft worked with Facebook to optimize it for their hardware. Facebook described PyTorch as the research-oriented framework.
