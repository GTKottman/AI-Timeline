# RoboCat: self-improving foundation agent for robotic manipulation

- **Date:** 2023-06-20
- **Who:** Google DeepMind
- **Type:** model

RoboCat is a multi-embodiment robot agent built on the Gato architecture and trained on images and actions from many robot arms across hundreds of tasks. It improves itself: a fine-tuned copy practices new tasks, and its data feeds the next version. DeepMind reported that the agent could learn new tasks from as few as 100 demonstrations, and that its success on unseen tasks roughly doubled after the self-training loop.
