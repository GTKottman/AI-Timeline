# Google releases deeplearn.js for machine learning in the browser

- **Date:** 2017-08-11
- **Who:** Google Research
- **Type:** software

Google Research posted about deeplearn.js, an open source library that runs machine learning models in the browser using WebGL, so models can train and run on the user's GPU without a server. It made in-browser ML and interactive model demos possible for any web developer. It later grew into TensorFlow.js.
