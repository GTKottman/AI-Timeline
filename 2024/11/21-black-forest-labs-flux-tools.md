# Black Forest Labs releases FLUX.1 Tools

- **Date:** 2024-11-21
- **Who:** Black Forest Labs
- **Type:** software

FLUX.1 Tools added Fill, Depth, Canny and Redux controls to the FLUX.1 image models, in both Pro and Dev versions. They gave creators fine control over inpainting, structure and style, extending the model family beyond text-to-image.
