# NVIDIA launches NIM inference microservices

- **Date:** 2024-03-18
- **Who:** NVIDIA
- **Type:** software

NVIDIA introduced NIM, packaged inference microservices that deliver optimized models as containers deployable on clouds, data centers or workstations. NIM is built on Triton Inference Server and TensorRT-LLM, and NVIDIA announced support for it in Amazon SageMaker Inference at GTC 2024. It made deploying models at scale a standard container task rather than a custom serving project, and broader developer access followed in mid-2024.
