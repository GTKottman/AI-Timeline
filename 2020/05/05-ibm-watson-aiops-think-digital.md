# IBM launches Watson AIOps at virtual Think Digital event

- **Date:** 2020-05-05
- **Who:** IBM (IBM Research, Watson)
- **Type:** product

At its virtual Think Digital conference, IBM launched Watson AIOps, which uses machine learning to detect, diagnose and respond to IT infrastructure anomalies in real time without manual triage.
