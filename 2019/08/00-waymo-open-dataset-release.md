# Waymo Open Dataset Released

- **Date:** 2019-08-00
- **Who:** Waymo (Alphabet)
- **Type:** dataset

Waymo released the Waymo Open Dataset, a multimodal sensor dataset from its self-driving vehicles, to let outside researchers train and test autonomous driving perception. Synced's 2019 review says the data came from over 10 million autonomous driving miles across 25 cities. The exact release day was not confirmed in the sources, so only the month is recorded.
