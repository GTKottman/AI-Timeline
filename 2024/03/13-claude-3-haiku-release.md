# Anthropic releases Claude 3 Haiku

- **Date:** 2024-03-13
- **Who:** Anthropic
- **Type:** model

Claude 3 Haiku was the smallest and fastest model in the Claude 3 family, aimed at low-cost, high-volume tasks. It followed the Opus and Sonnet launch on March 4 and completed the three-tier lineup.
