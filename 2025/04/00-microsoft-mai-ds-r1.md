# Microsoft MAI-DS-R1 post-trained DeepSeek-R1

- **Date:** 2025-04-00
- **Who:** Microsoft AI
- **Type:** model

Microsoft released MAI-DS-R1, an open-weight post-trained version of DeepSeek-R1 that was retrained to respond better to previously blocked topics, such as those restricted in China, while keeping its reasoning ability. It is listed on Hugging Face, and GitHub announced it as generally available in GitHub Models on April 17, 2025. OpenRouter lists its release as April 21, 2025, so the exact day is unresolved.
