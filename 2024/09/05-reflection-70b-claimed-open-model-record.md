# Matt Shumer announces Reflection 70B as "world's top open-source model"

- **Date:** 2024-09-05
- **Who:** Matt Shumer (OthersideAI / HyperWrite), with Glaive AI
- **Type:** model

Shumer announced Reflection 70B, a Llama 3.1 70B fine-tune trained with "Reflection-Tuning" so the model would notice and correct mistakes in its own reasoning. The launch claimed it beat Claude 3.5 Sonnet and GPT-4o on several benchmarks. Independent testing by Artificial Analysis found it trailed the base Llama 3.1 70B, and Shumer later admitted in October 2024 that the reported benchmarks were not reached. It mattered as a fast lesson in how open-model launch claims can outrun verification.
