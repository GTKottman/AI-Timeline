# NVIDIA unveils Tesla V100 with Volta GPU and Tensor Cores

- **Date:** 2017-05-10
- **Who:** NVIDIA
- **Type:** hardware

At GTC 2017, NVIDIA CEO Jensen Huang unveiled the Tesla V100, built on the Volta GV100 GPU. Its 640 Tensor Cores ran mixed-precision matrix operations for a claimed 120 teraflops of deep learning performance, and it was built on a 12 nm process. The Tensor Core design became the standard for training large neural networks on GPUs.
