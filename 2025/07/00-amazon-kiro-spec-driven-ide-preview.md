# Amazon launches Kiro, a spec-driven agentic IDE, in preview

- **Date:** 2025-07-00
- **Who:** Amazon Web Services
- **Type:** product

AWS released Kiro in preview, an IDE built on the VS Code architecture that turns a prompt into structured requirements, design documents and task lists before writing code. It uses Anthropic's Claude Sonnet 4 by default and offers event-driven agent hooks. It mattered as AWS's entry into the agentic coding-tool market against Cursor and Windsurf.
