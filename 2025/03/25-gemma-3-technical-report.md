# Google publishes Gemma 3 technical report

- **Date:** 2025-03-25
- **Who:** Google DeepMind
- **Type:** paper

The Gemma 3 technical report describes a multimodal extension of Google's open-weight Gemma family, spanning 1 to 27 billion parameters. It adds image understanding, support for more languages, and context windows of at least 128K tokens.
