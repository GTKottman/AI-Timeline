# OpenAI releases GPT-5.3-Codex

- **Date:** 2026-02-05
- **Who:** OpenAI
- **Type:** model

OpenAI released GPT-5.3-Codex, which combines the coding strength of GPT-5.2-Codex with GPT-5.2's reasoning and professional knowledge and runs about 25% faster. OpenAI called it its first model that was instrumental in creating itself. It rolled out to paid ChatGPT plans across Codex app, CLI, IDE and web, with API access following. It shipped the same day as Anthropic's Claude Opus 4.6, the start of a close release race.
