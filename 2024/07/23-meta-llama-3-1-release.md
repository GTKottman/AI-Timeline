# Meta releases Llama 3.1, including a 405B open-weight model

- **Date:** 2024-07-23
- **Who:** Meta AI
- **Type:** model

Llama 3.1 shipped in 8B, 70B and 405B sizes, with the 405B model the largest openly released model at the time. Meta argued that open weights could compete with closed frontier models. The release sparked a wide debate on open-source AI safety.
