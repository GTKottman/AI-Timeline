# PyTorch Lightning 1.0 releases its stable API

- **Date:** 2020-10-19
- **Who:** PyTorch Lightning team
- **Type:** software

PyTorch Lightning 1.0 was the first release with a stable API for the framework that separates research code from engineering boilerplate for PyTorch training loops. It dropped the older Result abstraction and launched alongside a new website and a preview of a native cloud platform for training at scale. The release helped establish Lightning as a standard wrapper for research and production PyTorch code.
