# Facebook announces Tensor Comprehensions, open-source ML compiler

- **Date:** 2018-02-14
- **Who:** Facebook AI Research
- **Type:** software

Facebook AI Research released Tensor Comprehensions, a framework-agnostic compiler that lets researchers write ML operations in mathematical notation and generates tuned GPU code automatically. It uses a polyhedral just-in-time compiler built on Halide IR, plus a multi-GPU autotuner. It was integrated with Caffe2 and PyTorch.
