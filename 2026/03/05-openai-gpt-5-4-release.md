# OpenAI launches GPT-5.4 with Thinking and Pro versions

- **Date:** 2026-03-05
- **Who:** OpenAI
- **Type:** model

OpenAI launched GPT-5.4 in standard, Thinking and Pro versions. OpenAI said it set record scores on computer-use benchmarks OSWorld-Verified and WebArena Verified. OpenAI said GPT-5.4 is 33% less likely than GPT-5.2 to make errors in individual claims.
