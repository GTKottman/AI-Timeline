# Google combines deep RL and roadmaps for long-range robot navigation

- **Date:** 2019-02-28
- **Who:** Google AI
- **Type:** research

Google researchers combined deep reinforcement learning with long-range planning so robots could navigate large spaces. Local planners were trained in simulation with AutoRL, an automated search over reward functions and network architectures. Roadmaps built from those planners transferred to real robots. The work showed automated design of RL components as a route to practical robot navigation.
