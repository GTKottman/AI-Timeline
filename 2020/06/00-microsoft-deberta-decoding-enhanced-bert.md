# Microsoft publishes DeBERTa on arXiv

- **Date:** 2020-06-00
- **Who:** Microsoft Research (Pengcheng He, Xiaodong Liu, Jianfeng Gao, Weizhu Chen)
- **Type:** research

DeBERTa, or Decoding-enhanced BERT with Disentangled Attention, was posted to arXiv in June 2020. It represents each token's content and position separately in attention and improves the mask decoder, and the team reported gains on language understanding benchmarks. Microsoft released the pre-trained models, code and fine-tuning scripts in June 2020. Hugging Face now hosts a 1.5-billion-parameter DeBERTa-v2 xxlarge model.
