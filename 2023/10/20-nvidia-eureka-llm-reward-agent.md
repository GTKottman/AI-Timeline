# NVIDIA Research unveils Eureka, a GPT-4 agent that writes robot reward code

- **Date:** 2023-10-20
- **Who:** NVIDIA Research
- **Type:** research

NVIDIA Research introduced Eureka, a GPT-4-powered agent that writes reward functions for reinforcement learning from environment source code and a task description. It iterates through reward sampling, GPU-accelerated evaluation and reflection. The paper reported its reward programs beat expert-written ones on more than 80% of tasks, and a robot hand learned pen spinning. The code and benchmarks were open-sourced on the Isaac Gym simulator.
