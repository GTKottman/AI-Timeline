# OpenAI releases GPT-5.2-Codex

- **Date:** 2025-12-18
- **Who:** OpenAI
- **Type:** model

OpenAI released GPT-5.2-Codex, a GPT-5.2 variant tuned for agentic software engineering in Codex and its CLI, with better context compaction and stronger reading of screenshots, diagrams and UI. Access started with paid ChatGPT users, with API access following, and a cybersecurity-focused trusted-access pilot was added for defensive uses. Benchmark figures vary between write-ups and are not used here.
