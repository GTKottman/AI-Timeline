# Moonshot AI releases open-weight Kimi K2.6

- **Date:** 2026-04-20
- **Who:** Moonshot AI
- **Type:** model

Kimi K2.6 is an open-weight multimodal model with a mixture-of-experts design (reported 1T total parameters, 32B active) and a 256K context window. Moonshot targets long-horizon coding, autonomous execution and large agent swarms, claiming open-source leadership on Humanity's Last Exam with tools and SWE-Bench Pro. The benchmark claims are the company's own; weights were posted on Hugging Face, with a Code Preview in beta from April 13.
