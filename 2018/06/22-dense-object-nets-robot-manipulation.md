# MIT's Dense Object Nets: robots learn to grasp specific points on objects

- **Date:** 2018-06-22
- **Who:** Peter R. Florence, Lucas Manuelli, Russ Tedrake (MIT)
- **Type:** paper

The paper introduces self-supervised dense object descriptors, learned for both rigid and non-rigid objects in about 20 minutes. They let a robot grasp a chosen point on an object after seeing it. The method was an early example of learned visual descriptors guiding robotic manipulation without hand-labelled data.
