# Apple unveils new Apple Foundation Models and developer framework at WWDC 2025

- **Date:** 2025-06-09
- **Who:** Apple
- **Type:** model

Apple unveiled a new generation of its language foundation models at WWDC 2025, including an on-device model of about 3 billion parameters and a larger server model for Private Cloud Compute. The models added image understanding, stronger tool use and reasoning, and support for 15 languages. Developers got free access to the on-device model through a new Foundation Models framework with structured output and tool calling.
