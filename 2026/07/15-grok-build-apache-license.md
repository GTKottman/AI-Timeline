# xAI releases Grok Build under Apache 2.0 after upload backlash

- **Date:** 2026-07-15
- **Who:** xAI
- **Type:** software

xAI released the Grok Build codebase under the Apache 2.0 license a few hours after reports that its grok CLI uploaded whole user directories to xAI's Google Cloud storage. xAI disabled the upload feature and said default data retention was disabled for all Grok Build users from July 12.
