# Google Cloud TPU available in beta, opened to outside companies

- **Date:** 2018-02-12
- **Who:** Google Cloud
- **Type:** hardware

Google made its Cloud TPU machine learning accelerators available in beta on Google Cloud Platform, letting outside companies rent TPU capacity for training and inference rather than only using them internally. Each Cloud TPU combines four custom chips with up to 180 teraflops of floating-point compute and 64 GB of high-bandwidth memory. Google said larger TPU pods would follow later in 2018.
