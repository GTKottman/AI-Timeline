# Baidu releases ERNIE 1.0 pretrained language model

- **Date:** 2019-03-16
- **Who:** Baidu (PaddlePaddle team)
- **Type:** model

Baidu released ERNIE 1.0, an open-source pretrained language model that learns from knowledge integration such as entities and phrases, not just masked words. The paper states that the code and pretrained models were released in Baidu's PaddlePaddle LARK repository. The paper was posted to arXiv on April 19, 2019. The March 16 date comes from a secondary listing and is approximate. ERNIE 2.0 followed later in 2019.
