# Anthropic launches Claude Opus 4 and Claude Sonnet 4

- **Date:** 2025-05-22
- **Who:** Anthropic
- **Type:** model

Anthropic launched Claude Opus 4 and Claude Sonnet 4. Anthropic called Opus 4 the best coding model in the world and reported about 72% on the SWE-bench Verified coding benchmark for both models. Opus 4 was released under AI Safety Level 3 protections, the first Anthropic model to be deployed under that level.
