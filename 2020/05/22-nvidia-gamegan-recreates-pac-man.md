# Nvidia GameGAN recreates Pac-Man with a neural network

- **Date:** 2020-05-22
- **Who:** Nvidia (lead author Seung-Wook Kim), Bandai Namco
- **Type:** research

To mark Pac-Man's 40th anniversary, Nvidia showed GameGAN, a generative adversarial network that reproduced the game's behaviour without a game engine or hand-written code. It was trained on about 50,000 generated play sequences and used a memory module to keep the simulated map consistent. The work was presented as the first use of GAN-based networks to emulate a game engine, an early example of neural simulation of interactive environments.
