# NVIDIA Project Clara debuts at GTC 2018

- **Date:** 2018-03-27
- **Who:** NVIDIA (Jensen Huang)
- **Type:** product

At the GTC 2018 keynote, Jensen Huang introduced Project Clara, an initiative that gives legacy medical imaging scanners in the field access to supercomputing through a virtualized, remotely reachable data center. NVIDIA said it was working with many healthcare companies, research institutions and startups on it. It mattered as an early push to run GPU-based AI inside existing clinical imaging systems rather than only in new hardware.
