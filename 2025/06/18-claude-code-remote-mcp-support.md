# Claude Code adds support for remote MCP servers

- **Date:** 2025-06-18
- **Who:** Anthropic
- **Type:** software

Anthropic added support for remote Model Context Protocol servers to Claude Code. The release notes list SSE and HTTP transports, OAuth 2.0 sign-in through the /mcp command, and the ability to reference MCP resources in prompts. This let coding agents reach hosted tools and data without a local server, following the June 11 release of the Claude Code SDK in TypeScript and Python.
