# ByteDance announces Seedream 4.0 image model

- **Date:** 2025-09-09
- **Who:** ByteDance (Seed team)
- **Type:** model

ByteDance announced Seedream 4.0, a multimodal model that handles text-to-image generation and image editing in one system, with support for 4K output and multi-image workflows. ByteDance said it was ten times faster than Seedream 3.0 and claimed it beat Google's Gemini 2.5 Flash Image on internal benchmarks, which could not be independently verified. Sources disagree on the date: Vercel lists an August 28 model ID while Hedra gives September 9 as the official announcement, which is the date used here.
