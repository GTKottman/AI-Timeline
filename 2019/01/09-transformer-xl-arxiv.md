# Transformer-XL posted to arXiv

- **Date:** 2019-01-09
- **Who:** Zihang Dai, Zhilin Yang, Yiming Yang, Jaime Carbonell, Quoc V. Le, Ruslan Salakhutdinov (Google Brain and Carnegie Mellon University)
- **Type:** paper

Transformer-XL reuses hidden states across text segments and adds a new positional encoding, so it can model longer dependencies than fixed-context Transformers. It reported state-of-the-art language-modelling results and much faster evaluation. It became a standard reference for long-context language modelling.
