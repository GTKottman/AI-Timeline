# EleutherAI releases GPT-Neo open models

- **Date:** 2021-03-21
- **Who:** EleutherAI
- **Type:** model

EleutherAI released GPT-Neo weights, the 1.3B and 2.7B parameter models trained on The Pile, after months of delay. They were among the first openly downloadable GPT-3-style language models, letting researchers run and study large models without access to a closed API. The release fed the open-source LLM movement that followed.
