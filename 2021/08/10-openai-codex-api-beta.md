# OpenAI introduces Codex

- **Date:** 2021-08-10
- **Who:** OpenAI
- **Type:** model

OpenAI announced an upgraded Codex, a GPT-3 descendant trained on public code that turns natural language into programming code. It was offered through a private API beta and powered GitHub Copilot. It showed that large language models could write working software in many languages.
