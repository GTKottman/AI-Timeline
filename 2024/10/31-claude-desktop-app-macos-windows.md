# Anthropic releases Claude desktop apps for macOS and Windows

- **Date:** 2024-10-31
- **Who:** Anthropic
- **Type:** product

Anthropic released Claude desktop apps for macOS and Windows, bringing its chat assistant out of the browser. It was part of the push to make Claude a daily-use app alongside ChatGPT.
