# Hugging Face releases DistilBERT

- **Date:** 2019-10-02
- **Who:** Hugging Face (Victor Sanh, Lysandre Debut, Julien Chaumond, Thomas Wolf)
- **Type:** model

DistilBERT is a smaller, faster distilled version of BERT, described in an arXiv paper posted in October 2019. The paper says it keeps most of BERT's accuracy while being much lighter to run. It became one of the most widely used compact models. Hugging Face's Transformers library, then renamed from pytorch-transformers, added it alongside TensorFlow 2.0 support.
