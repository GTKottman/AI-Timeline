# Tencent open-sources AI COVID-19 self-triage assistant on GitHub

- **Date:** 2020-04-03
- **Who:** Tencent (Tencent Smart Healthcare)
- **Type:** software

Tencent released an AI-based chat assistant for COVID-19 self-assessment as open source on GitHub. It collects contact history, symptoms and underlying conditions, then estimates infection likelihood and suggests whether to seek treatment or self-quarantine, following China's National Health Commission diagnosis protocol. Tencent said it had already been used by 40 disease control centers and more than 300 hospitals in China. Tencent gave no independent accuracy evaluation.
