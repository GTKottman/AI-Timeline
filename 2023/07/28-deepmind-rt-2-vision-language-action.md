# DeepMind RT-2: vision-language-action model for robots

- **Date:** 2023-07-28
- **Who:** Google DeepMind
- **Type:** model

RT-2 is a vision-language-action model that is trained on web data and robot data together, with robot actions written as text tokens. It can follow instructions for tasks it was never trained on, such as identifying trash and throwing it away. DeepMind reported 62% success on novel tasks, up from 32% for RT-1, across more than 6,000 trials.
