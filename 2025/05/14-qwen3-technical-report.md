# Qwen team publishes the Qwen3 technical report

- **Date:** 2025-05-14
- **Who:** Alibaba (Qwen team)
- **Type:** paper

The Qwen3 technical report describes a model family spanning roughly 0.6 to 235 billion parameters, with dense and mixture-of-experts variants. Its main contribution is one model that supports both a deliberate reasoning mode and a faster direct-response mode, with a compute-budget control. The models were released under Apache 2.0.
