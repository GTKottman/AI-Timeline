# Microsoft publishes DeBERTa on arXiv

- **Date:** 2020-06-05
- **Who:** Microsoft Research (Pengcheng He, Xiaodong Liu, Jianfeng Gao, Weizhu Chen)
- **Type:** research

DeBERTa, or Decoding-enhanced BERT with Disentangled Attention, was posted to arXiv in early June 2020. It represents each token's content and position separately in attention and improves the mask decoder, and the team reported gains on language understanding benchmarks. Microsoft released the pre-trained models, code and fine-tuning scripts shortly after (a June 2020 changelog entry is the only source for that date), and the architecture later led to a 1.5-billion-parameter version that topped SuperGLUE in January 2021.
