# Anthropic makes Claude Code generally available alongside Claude 4

- **Date:** 2025-05-22
- **Who:** Anthropic
- **Type:** product

At its Code with Claude event, Anthropic announced general availability for Claude Code, its terminal coding agent, with beta extensions for JetBrains and VS Code. It was described as extending Claude into terminal, IDE and background-job workflows through an SDK. The launch came with Claude Opus 4 and Sonnet 4. Coverage gives May 22, 2025 as the date, and the sources checked were mostly secondary.
