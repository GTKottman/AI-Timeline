# Meta releases Code Llama, a coding model built on Llama 2

- **Date:** 2023-08-24
- **Who:** Meta AI
- **Type:** model

Meta released Code Llama, a version of Llama 2 further trained on code, in 7B, 13B and 34B sizes, with Python and instruction-tuned variants. It was free for research and commercial use and became a widely used open coding model.
