# Facebook AI Research open sources Detectron object detection platform

- **Date:** 2018-01-22
- **Who:** Facebook AI Research (FAIR)
- **Type:** software

FAIR open sourced Detectron, its object detection research platform built on Caffe2 and released under Apache 2.0, with code and baselines for more than 70 pretrained models. It gave researchers a reproducible, state-of-the-art codebase for Mask R-CNN-style detection and segmentation. It mattered because it made top detection research easy for anyone to rerun and extend.
