# Second Workshop and Challenge on Learned Image Compression announced for CVPR 2019

- **Date:** 2019-02-06
- **Who:** Google, with the CVPR 2019 workshop organizers
- **Type:** competition

Google co-sponsored the second Workshop and Challenge on Learned Image Compression at CVPR 2019 in Long Beach. The challenge had a low-rate track aiming at 0.15 bits per pixel with maximum quality, and a transparent track seeking the smallest files at a set quality threshold. The workshop featured invited talks and presentations from the top-performing teams. It pushed neural image codecs as a benchmarked research area.
