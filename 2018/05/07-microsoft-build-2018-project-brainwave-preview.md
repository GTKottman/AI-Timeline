# Microsoft Build 2018: Project Brainwave preview

- **Date:** 2018-05-07
- **Who:** Microsoft
- **Type:** hardware

At Build 2018 Microsoft previewed Project Brainwave, an FPGA-based architecture for low-latency real-time AI inference on Azure, running on Intel FPGAs (reported as Stratix 10 devices). The same week it also announced Project Kinect for Azure, a depth-sensor package with onboard compute for edge AI. Brainwave showed Microsoft pushing custom hardware for inference alongside GPUs and TPUs.
