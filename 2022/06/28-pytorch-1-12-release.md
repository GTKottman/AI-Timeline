# PyTorch 1.12 release (functional module API and nvFuser)

- **Date:** 2022-06-28
- **Who:** Meta AI / PyTorch community
- **Type:** software

PyTorch 1.12 added a functional API for modules, which runs a module with a chosen set of parameters, and brought in the nvFuser compiler for optimizing deep learning workloads. These changes made PyTorch programs easier to transform and faster on NVIDIA GPUs.
