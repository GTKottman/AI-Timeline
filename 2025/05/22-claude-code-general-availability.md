# Anthropic makes Claude Code generally available alongside Claude 4

- **Date:** 2025-05-22
- **Who:** Anthropic
- **Type:** product

At its Code with Claude event in San Francisco, Anthropic made Claude Code, its terminal coding agent, generally available alongside the new Claude Opus 4 and Sonnet 4 models. The MIT AI Agent Index lists May 22, 2025 as the general release date. Claude Code was offered at the event as a terminal and IDE agent for coding work.
