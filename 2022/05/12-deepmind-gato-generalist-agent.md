# DeepMind Gato: one generalist agent

- **Date:** 2022-05-12
- **Who:** DeepMind
- **Type:** model

DeepMind announced Gato, a single transformer policy that plays Atari games, captions images, chats and controls a robot arm. It serialized data from many tasks and modalities into one token sequence, and it helped push the field toward general-purpose agents rather than one model per task.
