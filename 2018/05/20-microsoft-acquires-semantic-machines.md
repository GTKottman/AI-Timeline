# Microsoft acquires Semantic Machines

- **Date:** 2018-05-20
- **Who:** Microsoft (David Ku, CVP and CTO of Microsoft AI & Research); Semantic Machines (Berkeley)
- **Type:** acquisition

Microsoft announced in a blog post that it had acquired Semantic Machines, a Berkeley conversational AI startup. Financial terms were not disclosed. Microsoft tied the deal to Cortana, with the aim of improving dialogue, speech recognition and language understanding, and said it would set up a conversational AI center of excellence in Berkeley.
