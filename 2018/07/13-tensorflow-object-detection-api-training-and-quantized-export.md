# TensorFlow Object Detection API gains faster TPU training and mobile export

- **Date:** 2018-07-13
- **Who:** Google Research (TensorFlow team)
- **Type:** software

Google added Cloud TPU training, TensorFlow Lite export with quantization, and new detectors such as RetinaNet and the Pooling Pyramid Network to the TensorFlow Object Detection API. Pretrained COCO weights came with it. The post reported a quantized SSD MobileNet running above 15 frames per second on a Pixel 2 CPU, so detectors could run on phones.
