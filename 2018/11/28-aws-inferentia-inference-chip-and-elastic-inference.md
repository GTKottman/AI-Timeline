# Amazon unveils Inferentia inference chip at re:Invent

- **Date:** 2018-11-28
- **Who:** Amazon Web Services (Andy Jassy keynote)
- **Type:** hardware

At re:Invent 2018, AWS unveiled Inferentia, its custom chip for machine learning inference, and a companion service called Elastic Inference. AWS positioned Inferentia as a cheaper alternative to GPUs for serving models, noting that inference can make up most of a machine learning project's cost. The chip was to work with EC2 and with Amazon SageMaker, and with frameworks such as TensorFlow and PyTorch. Sources differed on when it would ship, with reports pointing to 2019.
