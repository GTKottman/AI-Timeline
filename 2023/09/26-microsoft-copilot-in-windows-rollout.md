# Microsoft Copilot in Windows begins rolling out

- **Date:** 2023-09-26
- **Who:** Microsoft
- **Type:** product

Microsoft began rolling out Copilot in Windows on September 26, 2023, placing a single AI assistant button on the Windows 11 taskbar. The unified Copilot spanned Windows 11, Microsoft 365 and Edge. It was not offered in China, Russia, Belarus or the European Union because of local regulations, and Microsoft used controlled feature rollout to distribute it. It made a general-purpose AI assistant a default part of the Windows desktop.
