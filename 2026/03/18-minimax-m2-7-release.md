# MiniMax releases M2.7 agentic coding model

- **Date:** 2026-03-18
- **Who:** MiniMax
- **Type:** model

MiniMax M2.7 is an agentic model aimed at end-to-end software engineering. MiniMax reports 56.2% on SWE-Pro and 57.0% on Terminal Bench 2; these are company-reported figures. Open weights were listed under a modified MIT license; NVIDIA's model page dates the weights April 11, 2026, while OpenRouter lists the model from March 18, so the release date is unresolved.
