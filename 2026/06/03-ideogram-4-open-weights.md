# Ideogram 4 image model weights released on Hugging Face

- **Date:** 2026-06-03
- **Who:** Ideogram
- **Type:** model

Ideogram released the weights of Ideogram 4, a 9.3B-parameter diffusion transformer, on Hugging Face, which makes it the company's first model with downloadable weights. The weights are under a non-commercial license while the inference code is Apache 2.0, and a quantized nf4 build is reported to run on a single 24 GB GPU. It matters because a strong text-in-image model became available for local use, though the non-commercial terms limit it. Coverage is secondary, so the license and ranking claims should be checked against Ideogram's model card.
