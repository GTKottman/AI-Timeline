# NVIDIA releases Llama-3.1-Nemotron-70B-Instruct

- **Date:** 2024-10-12
- **Who:** NVIDIA
- **Type:** model

NVIDIA released Llama-3.1-Nemotron-70B-Instruct, a customized version of Meta's Llama 3.1 70B tuned to make responses more helpful. Its Hugging Face repository first received weights on October 12, 2024. NVIDIA's model card reports 85.0 on Arena Hard against 79.3 for GPT-4o and 79.2 for Claude 3.5 Sonnet; these are NVIDIA's own figures. The model showed a large chip maker shipping a competitive open instruct model built on another lab's base.
