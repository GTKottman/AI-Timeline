# OpenAI releases the Responses API and Agents SDK

- **Date:** 2025-03-11
- **Who:** OpenAI
- **Type:** software

OpenAI released the Responses API with built-in tools for web search, file search and computer use. It also released the open-source Agents SDK, an upgrade of its experimental Swarm project, with agent definitions, handoffs between agents, input and output guardrails and tracing. OpenAI positioned the Responses API as the successor to the Assistants API, which it planned to phase out in mid-2026. One source gives March 12 as the date, but the other sources point to March 11.
