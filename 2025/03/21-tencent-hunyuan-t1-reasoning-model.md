# Tencent Hunyuan-T1 reasoning model

- **Date:** 2025-03-21
- **Who:** Tencent
- **Type:** model

Tencent released Hunyuan-T1, a reasoning model built on its Hybrid-Transformer-Mamba MoE base (TurboS) and trained with large-scale reinforcement learning. Tencent pitched it as a rival to DeepSeek-R1 on performance and price, citing 87.2 on MMLU-Pro and charging 1 yuan per million input tokens. Coverage gives March 21 or 22 as the launch day, so the exact day is uncertain; all figures are Tencent's own.
