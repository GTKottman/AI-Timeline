# Runway releases Gen-1 video-to-video model

- **Date:** 2023-02-06
- **Who:** Runway
- **Type:** model

Runway released Gen-1, a video-to-video model that restyles an existing clip using a text prompt or a reference image, while keeping the original motion and layout. Its demos turned street footage into claymation-style figures and stacked books into a night cityscape. Gen-1 was among the first commercial generative video tools available to creators, and it preceded Runway's text-to-video Gen-2 later in 2023.
