# NVIDIA Titan Xp launch

- **Date:** 2017-04-06
- **Who:** NVIDIA
- **Type:** hardware

NVIDIA launched the Titan Xp at $1,199. It is a Pascal GPU with 12 GB of GDDR5X memory and 3840 CUDA cores.
