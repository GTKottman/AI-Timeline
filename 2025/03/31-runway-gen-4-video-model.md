# Runway releases Gen-4 video model with character and scene consistency

- **Date:** 2025-03-31
- **Who:** Runway
- **Type:** model

Runway released Gen-4, an image-to-video model that keeps characters, locations and objects consistent across scenes using reference images. It was offered to paying individual and enterprise customers, with reference features promised in a later update. AlternativeTo reported better fidelity, motion and prompt adherence than Gen-3 Alpha.
