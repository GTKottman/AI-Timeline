# TensorFlow 2.8.0 released

- **Date:** 2022-02-02
- **Who:** Google (TensorFlow team)
- **Type:** software

TensorFlow 2.8.0 shipped as a stability-focused release with changes to TensorRT integration, TPU embedding APIs, tf.data, Keras preprocessing layers and TFLite op support. It also deprecated boosted trees code in favour of TensorFlow Decision Forests and included security fixes. It mattered for AI because it is a widely used deep learning framework and this release tightened GPU inference and text preprocessing for practitioners.
