# Google introduces PlaNet, a planning agent that learns a model from pixels

- **Date:** 2019-02-15
- **Who:** Google AI
- **Type:** research

Google AI introduced PlaNet, a Deep Planning Network agent that learns a model of how the environment behaves from image inputs alone and then plans with it. On image-based control tasks it performed competitively with the best model-free methods while using far less interaction data. It showed that learned world models could be a data-efficient route to control from raw pixels.
