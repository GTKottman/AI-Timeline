# Microsoft launches AI sentence-rewriting tools in Editor for Word, Outlook and the browser

- **Date:** 2020-03-30
- **Who:** Microsoft (Microsoft 365 / Editor team)
- **Type:** product

Microsoft rolled out AI-based writing suggestions in Editor for Word, Editor in Outlook and a new Editor browser extension. Unlike spelling and grammar fixes, which work one error at a time, the new feature suggests rewrites of whole sentences to make writing clearer, more concise and more inclusive. Microsoft said internal tests caught mistakes common for people with dyslexia about 15 percent more effectively than the previous approach. Basic checks stayed free, and Microsoft 365 subscribers could opt into the advanced AI rewrites.
