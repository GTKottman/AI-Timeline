# OpenAI announces SearchGPT prototype

- **Date:** 2024-07-25
- **Who:** OpenAI
- **Type:** product

OpenAI announced SearchGPT, a prototype AI search tool that combines its models with web information to return answers with sources. It launched to a limited group of users and publishers, with a waitlist, and OpenAI said it planned to fold the best features into ChatGPT. It was OpenAI's first direct move into web search, and it put it in competition with Google's AI search features.
