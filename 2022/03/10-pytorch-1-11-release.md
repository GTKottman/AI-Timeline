# PyTorch 1.11 release (TorchData and functorch in beta)

- **Date:** 2022-03-10
- **Who:** Meta AI / PyTorch community
- **Type:** software

PyTorch 1.11 shipped with TorchData, a new beta library of modular data-loading primitives, and functorch, a beta library of composable function transforms. These tools made it easier to build input pipelines and to compute per-sample gradients and other transformed functions in research code.
