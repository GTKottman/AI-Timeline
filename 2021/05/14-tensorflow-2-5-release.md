# TensorFlow 2.5.0 release

- **Date:** 2021-05-14
- **Who:** Google (TensorFlow team)
- **Type:** software

TensorFlow 2.5.0 shipped in May 2021, with DevClass reporting the release on 14 May 2021. The release added Python 3.9 support, strict round-robin reads in tf.data for synchronous training, a debug mode for input pipelines, an MLIR-based quantization backend as the TFLite default, and a pluggable-device interface so third-party hardware can connect as a plug-in. It also renamed an environment variable, which is a breaking change. The day shown is the date of the press report, not a confirmed release-note date.
