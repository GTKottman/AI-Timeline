# Hugging Face publishes the Transformers library paper on arXiv

- **Date:** 2019-10-09
- **Who:** Hugging Face (Thomas Wolf and colleagues)
- **Type:** software

The arXiv paper "HuggingFace's Transformers: State-of-the-art Natural Language Processing" (arXiv 1910.03771, submitted 9 October 2019) described the Transformers library, which gives pretrained NLP models such as BERT, GPT-2 and XLNet one API for PyTorch and TensorFlow 2.0. It gave the open-source community a citable reference for a toolkit that became a standard way to load and fine-tune pretrained language models.
