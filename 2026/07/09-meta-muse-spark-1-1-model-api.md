# Meta launches Muse Spark 1.1 and public preview of Meta Model API

- **Date:** 2026-07-09
- **Who:** Meta
- **Type:** product

Meta released Muse Spark 1.1, a multimodal reasoning model aimed at agentic tasks, coding and computer use, and opened a public preview of the Meta Model API to US developers. The model accepts text, images, video and PDFs and outputs text, with reported pricing of $1.25 and $4.25 per million input and output tokens and $20 in free credits for new accounts. It is a shift for a company that had mostly shipped its models as downloadable open weights. The preview is limited to US developers and is not yet open in the EU.
