# Microsoft extends OpenAI partnership with multiyear, multibillion-dollar investment

- **Date:** 2023-01-23
- **Who:** Microsoft / OpenAI
- **Type:** funding

Microsoft announced a multiyear, multibillion-dollar investment extending its partnership with OpenAI. Microsoft did not disclose the amount; Bloomberg reported about $10 billion, which the companies did not confirm. Reports said the deal would let Microsoft offer OpenAI's technology through its Azure OpenAI Service.
