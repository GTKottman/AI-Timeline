# Anthropic launches Claude Fable 5 and Mythos 5

- **Date:** 2026-06-09
- **Who:** Anthropic
- **Type:** model

Anthropic launched Claude Fable 5, the first general public release from its Mythos-class tier, and Claude Mythos 5, which is offered only to vetted partners who already have Claude Mythos Preview access. Both are priced at $10 per million input tokens and $50 per million output tokens.
