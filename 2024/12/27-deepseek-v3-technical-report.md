# DeepSeek publishes DeepSeek-V3 technical report

- **Date:** 2024-12-27
- **Who:** DeepSeek-AI
- **Type:** paper

The DeepSeek-V3 technical report describes a 671-billion-parameter mixture-of-experts model with 37 billion parameters active per token. It introduces a load-balancing method that avoids an auxiliary loss, multi-token prediction, and pretraining on 14.8 trillion tokens. The authors report results competitive with leading closed-source models.
