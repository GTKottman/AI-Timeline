# Alibaba Qwen releases Qwen3.6-27B dense open model

- **Date:** 2026-04-22
- **Who:** Alibaba Qwen team
- **Type:** model

Qwen3.6-27B is the first dense model in the Qwen3.6 line, with 27B parameters all active per token, a 262K native context and text, image and video input. Qwen reports it beats the prior 397B-A17B MoE on coding (77.2 vs 76.2 on SWE-bench Verified). It is released under Apache 2.0 and fits on a single 24GB GPU at 4-bit. The benchmark claims are Qwen's own.
