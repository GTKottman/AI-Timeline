# Microsoft announces Windows Copilot at Build 2023

- **Date:** 2023-05-23
- **Who:** Microsoft
- **Type:** product

At its Build developer conference, Microsoft announced Windows Copilot, a centralized AI assistant for Windows 11 reached from a taskbar button, with preview planned for June. Microsoft also said Copilot would power Microsoft 365, Viva, GitHub and Dynamics, and it adopted OpenAI's plugin standard so one plugin could work across ChatGPT, Bing and its copilots. It mattered as Microsoft's plan to put one assistant across the desktop and its software suite.
