# OpenAI launches gpt-realtime and makes Realtime API generally available

- **Date:** 2025-08-28
- **Who:** OpenAI
- **Type:** product

OpenAI released gpt-realtime, its speech-to-speech model with gains in instruction following, tool calling and natural speech, and made the Realtime API generally available. The API added remote MCP server support, image input and SIP phone calling, plus two new voices, Cedar and Marin. Reported Big Bench Audio accuracy rose to 82.8% from 65.6%. It mattered as a production-ready voice agent stack for developers.
