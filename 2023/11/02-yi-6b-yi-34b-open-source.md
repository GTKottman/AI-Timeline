# 01.AI open-sources Yi-6B and Yi-34B base models

- **Date:** 2023-11-02
- **Who:** 01.AI
- **Type:** model

01.AI, founded by Kai-Fu Lee, open-sourced the base models Yi-6B and Yi-34B, a bilingual English and Chinese pair, according to the project changelog. Both were trained with a 4K sequence length and can be extended to 32K at inference. The 200K-context base models followed on November 6.
