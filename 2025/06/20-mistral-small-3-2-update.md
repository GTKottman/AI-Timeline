# Mistral releases Small 3.2, a 24B instruction-following update

- **Date:** 2025-06-20
- **Who:** Mistral AI
- **Type:** model

Mistral released Small 3.2, an update to Mistral Small 3.1 with the same 24-billion-parameter architecture. It targets instruction following, repetition and function calling. One summary reports WildBench v2 instruction-following rising from 55.60% to 65.33%, and repetition failures falling from 2.11% to 1.29%, from secondary sources. It keeps the 128K context window and is open-weight.
