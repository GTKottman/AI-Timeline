# OpenAI and Amazon sign $38 billion AWS compute deal

- **Date:** 2025-11-03
- **Who:** OpenAI, Amazon Web Services (AWS)
- **Type:** funding

OpenAI agreed to a $38 billion compute arrangement with AWS, reported as a seven-year deal, to run its AI workloads on Amazon EC2 UltraServers with NVIDIA GB200 and GB300 GPUs. According to the companies, OpenAI gets access to hundreds of thousands of chips, with capacity to be deployed before the end of 2026 and room to expand into 2027. The deal came days after OpenAI completed a restructuring that ended Microsoft's exclusive cloud rights, and it shows OpenAI spreading its compute across more than one cloud provider.
