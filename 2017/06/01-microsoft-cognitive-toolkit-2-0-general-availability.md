# Microsoft Cognitive Toolkit 2.0 Generally Available as Open Source

- **Date:** 2017-06-01
- **Who:** Microsoft
- **Type:** software

Microsoft made Cognitive Toolkit 2.0, the renamed CNTK, generally available under an open-source license. The release added Python support, Keras support (in preview), Java bindings for model evaluation, and tools for running trained models on low-powered devices such as phones. It mattered because a major lab-backed framework moved toward Python and Keras-style workflows, the same direction TensorFlow and other frameworks were taking.
