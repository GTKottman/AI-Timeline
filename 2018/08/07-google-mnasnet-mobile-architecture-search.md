# Google's MnasNet searches for mobile CNNs using measured phone latency

- **Date:** 2018-08-07
- **Who:** Google Brain
- **Type:** model

Google introduced MnasNet, a reinforcement learning architecture search that measures model speed directly on Pixel phones and trades it off against accuracy. Google's blog said the searched models were 1.5 times faster than MobileNetV2 and 2.4 times faster than NASNet at the same ImageNet top-1 accuracy. The paper was first posted to arXiv on July 31, 2018, and its peer-reviewed version was published at CVPR 2019 with updated figures.
