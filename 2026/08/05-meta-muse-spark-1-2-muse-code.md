# Meta releases Muse Spark 1.2 and Muse Code terminal agent

- **Date:** 2026-08-05
- **Who:** Meta
- **Type:** model

On August 5, 2026 Meta released Muse Spark 1.2, a coding-focused update with a 1M-token context, alongside Muse Code, a terminal coding agent in beta for macOS and Linux. Muse Code runs persistent background agents that can fan out subagents, and it logs every model call and edit so work can resume after a crash. Meta reports 82.9% on Terminal-Bench 2.1, up from 76.2%, in its own harness. One outlet citing CNBC reports pricing of $1.25 and $4.25 per million input and output tokens. All figures are vendor-reported.
