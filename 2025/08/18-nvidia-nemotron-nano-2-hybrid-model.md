# Nvidia releases Nemotron Nano 2 hybrid Transformer-Mamba models

- **Date:** 2025-08-18
- **Who:** Nvidia
- **Type:** model

Nvidia released Nemotron Nano 2, hybrid reasoning models combining Transformer and Mamba layers, including a 12B base model and 9B base and aligned models on Hugging Face. Nvidia said the 9B model is built to run on a single A10G, with a configurable thinking budget. It mattered as an open-weight small reasoning model built on a hybrid architecture.

Benchmark claims are Nvidia's, relayed by secondary outlets.
