# TensorFlow 1.10.0 released

- **Date:** 2018-08-08
- **Who:** Google (TensorFlow team)
- **Type:** software

TensorFlow 1.10.0 was released on August 8, 2018, per the GitHub release page (dated "08 Aug"). Distributions and Bijectors moved from tf.contrib.distributions into TensorFlow Probability, and the contrib module was deprecated. tf.data gained initial Bigtable integration, and prebuilt binaries were built against NCCL 2.2 and no longer bundle NCCL, which required multi-GPU users to upgrade. It mattered as the release that began separating probabilistic modeling into its own library.
