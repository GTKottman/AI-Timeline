# AWS and Microsoft announce Gluon deep learning interface

- **Date:** 2017-10-12
- **Who:** Amazon Web Services, Microsoft
- **Type:** software

AWS and Microsoft jointly announced Gluon, an open source Python interface for building deep learning models with pre-built network components while keeping training performance. It launched working with Apache MXNet, with Microsoft Cognitive Toolkit support planned, and the reference specification was published so other engines could integrate. It mattered because it lowered the barrier to writing neural networks and was pitched as an open ecosystem rather than a single-vendor framework.
