# Google Releases Open Images V5 with Segmentation Masks

- **Date:** 2019-05-08
- **Who:** Google
- **Type:** dataset

Google released Open Images V5, an update to its large public image dataset, adding 2.8 million instance segmentation masks across 350 object categories. Segmentation masks give pixel-level labels, which are more detailed than bounding boxes and are used to train and benchmark object segmentation models. The release was tied to the ICCV 2019 challenge work on the dataset.
