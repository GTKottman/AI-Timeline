# Google introduces MobileNetV2 for on-device computer vision

- **Date:** 2018-04-03
- **Who:** Google (Mark Sandler, Andrew Howard, Menglong Zhu, Andrey Zhmoginov, Liang-Chieh Chen)
- **Type:** model

Google's AI blog presented MobileNetV2, a mobile-first network built from inverted residual blocks with linear bottlenecks. It improved the accuracy-per-compute tradeoff on several benchmarks across model sizes. The paper also covered SSDLite for object detection and Mobile DeepLabv3 for segmentation, and the team released the models for the community to build on. The arXiv preprint dates from January 2018 and was published at CVPR 2018.
