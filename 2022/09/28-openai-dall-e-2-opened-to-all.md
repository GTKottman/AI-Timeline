# OpenAI opens DALL-E 2 to all users without a waitlist

- **Date:** 2022-09-28
- **Who:** OpenAI
- **Type:** product

OpenAI removed the DALL-E 2 waitlist, so anyone could sign up and generate images. The move turned text-to-image generation into an everyday public tool.
