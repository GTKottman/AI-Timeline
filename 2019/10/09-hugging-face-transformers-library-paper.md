# Hugging Face publishes the Transformers library paper on arXiv

- **Date:** 2019-10-09
- **Who:** Hugging Face (Thomas Wolf and colleagues)
- **Type:** software

The paper "Transformers: State-of-the-Art Natural Language Processing" (arXiv 1910.03771) described the Transformers library, which unified many pretrained NLP models (BERT, GPT-2, XLNet and others) behind one API. It landed a few days after the library was renamed from "PyTorch Transformers" and made compatible with TensorFlow 2.0 in early October 2019. The paper gave the open-source community a citable reference for the toolkit that became the standard way to load and fine-tune pretrained language models.
