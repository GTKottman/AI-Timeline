# Google releases TF-Ranking, a scalable TensorFlow library for learning-to-rank

- **Date:** 2018-12-05
- **Who:** Google AI (Xuanhui Wang, Michael Bendersky)
- **Type:** software

Google AI announced TF-Ranking, a TensorFlow library for learning-to-rank released with a GitHub repository. It supports standard pointwise, pairwise and listwise losses, an implementation of LambdaLoss for optimizing ranking metrics, and losses for unbiased learning-to-rank. It matters because ranking models for search and recommendation became easier to build inside the mainstream deep learning framework.
