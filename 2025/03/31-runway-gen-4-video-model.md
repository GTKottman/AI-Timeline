# Runway releases Gen-4 video model with character and scene consistency

- **Date:** 2025-03-31
- **Who:** Runway
- **Type:** model

Runway released Gen-4, an image-to-video model that uses reference images to keep characters, locations and objects consistent across scenes. It was offered to paying individual and enterprise customers. Coverage conflicts on whether the reference features were live at launch; The Decoder said they would follow in a later update.
