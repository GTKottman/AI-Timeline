# OpenAI publishes GPT-3 paper: language models are few-shot learners

- **Date:** 2020-05-28
- **Who:** OpenAI
- **Type:** paper

OpenAI published the GPT-3 paper, introducing an autoregressive language model with 175 billion parameters. It showed that very large models can perform new tasks from a few examples in the prompt, without gradient updates. The result shifted the field toward scaling and prompt-based use of large language models.
