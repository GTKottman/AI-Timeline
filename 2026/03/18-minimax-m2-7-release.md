# MiniMax releases M2.7 agentic coding model

- **Date:** 2026-03-18
- **Who:** MiniMax
- **Type:** model

MiniMax M2.7 is an agentic model aimed at end-to-end software engineering, with support for multi-agent collaboration and skill orchestration. MiniMax reports 56.2% on SWE-Pro and 57.0% on Terminal Bench 2 and claims it helped build parts of its own reinforcement-learning pipeline; these are company-reported figures. Open weights followed on Hugging Face in April under a modified MIT license.
