# Microsoft and Facebook launch ONNX open model format

- **Date:** 2017-09-07
- **Who:** Microsoft, Facebook
- **Type:** software

Microsoft and Facebook announced ONNX, an open format for representing deep learning models, so that models could move between frameworks such as PyTorch, Caffe2 and the Microsoft Cognitive Toolkit. It was meant to decouple frameworks from hardware-specific runtimes. ONNX became a common interchange format for deploying models across tools.
