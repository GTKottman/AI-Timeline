# Anthropic launches the Citations API for grounded Claude answers

- **Date:** 2025-01-23
- **Who:** Anthropic
- **Type:** product

Anthropic added Citations to its API, so developers can pass documents to Claude and get answers that point to the exact passages they draw on. It first worked with Claude 3.5 Sonnet and Claude 3.5 Haiku and was also offered through Google's Vertex AI. Anthropic says it beats most custom citation setups by up to 15%, a figure from its own evaluations. Anthropic later added the feature to Amazon Bedrock on June 30, 2025.
