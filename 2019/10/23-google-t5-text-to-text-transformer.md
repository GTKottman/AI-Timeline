# Google publishes T5, a unified text-to-text transformer

- **Date:** 2019-10-23
- **Who:** Google (Colin Raffel, Noam Shazeer, Adam Roberts, et al.)
- **Type:** model

The T5 paper, "Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer," casts every NLP task as text in and text out. It is a systematic study of pretraining choices, and it introduced the C4 web-text dataset. Google released the code and pretrained models, which became a common base for later language research.
