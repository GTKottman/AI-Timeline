# Huawei unveils Kirin 980 with a dual neural processing unit

- **Date:** 2018-08-31
- **Who:** Huawei (HiSilicon)
- **Type:** hardware

Huawei unveiled the Kirin 980 at IFA 2018 in Berlin, calling it the first 7nm smartphone chip. It carried a dual-core NPU, Huawei's neural network processing unit, which made on-device image recognition a dedicated hardware feature in a phone system-on-chip. Huawei claimed 2.2 times the speed of the Kirin 970's NPU. The chip was pitched for face recognition, object detection and segmentation, and was first expected in the Mate 20 series.
