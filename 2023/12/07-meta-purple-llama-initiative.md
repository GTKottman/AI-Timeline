# Meta launches Purple Llama trust and safety initiative

- **Date:** 2023-12-07
- **Who:** Meta, AI Alliance partners, AMD, AWS, Google Cloud, Hugging Face, Microsoft
- **Type:** software

Meta announced Purple Llama, an umbrella project of open trust and safety tools and evaluations for generative AI. Its first release included CyberSecEval, a set of cybersecurity safety benchmarks for LLMs that tests insecure code generation and compliance with cyberattack requests, and Llama Guard, an input and output safety classifier. Partners including AMD, AWS, Google Cloud, Hugging Face and Microsoft agreed to work on it, making it an early shared safety toolkit for open models.
