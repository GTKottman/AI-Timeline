# Ray 2.0 and Ray AI Runtime launched with $99M extension

- **Date:** 2022-08-23
- **Who:** Anyscale (Ray project); funding from Addition, Intel Capital and Foundation Capital
- **Type:** software

Anyscale released Ray 2.0 at Ray Summit 2022, adding Ray AI Runtime, a unified runtime for ML applications across TensorFlow, PyTorch and Hugging Face, plus large-scale data shuffling in Ray Datasets and KubeRay for Kubernetes. The same day Anyscale announced $99 million in additional Series C funding. Ray was the distributed compute layer behind OpenAI's training work, so 2.0 targeted the full ML pipeline rather than training alone.
