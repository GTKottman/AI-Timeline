# Nvidia GameGAN recreates Pac-Man with a neural network

- **Date:** 2020-05-22
- **Who:** Nvidia (lead author Seung-Wook Kim), Bandai Namco
- **Type:** research

To mark Pac-Man's 40th anniversary, Nvidia showed GameGAN, a generative adversarial network that reproduced the game's behaviour without a game engine or hand-written code. It was trained on 50,000 PAC-MAN episodes, according to Nvidia. The work was presented as the first use of GAN-based networks to emulate a game engine, an early example of neural simulation of interactive environments.
