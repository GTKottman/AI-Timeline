# NVIDIA releases Nemotron 3 Ultra (550B open model)

- **Date:** 2026-06-04
- **Who:** NVIDIA
- **Type:** model

NVIDIA released Nemotron 3 Ultra, a 550B-total-parameter open model aimed at complex reasoning. It was the largest model in the Nemotron 3 family.
