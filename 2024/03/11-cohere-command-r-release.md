# Cohere releases Command R

- **Date:** 2024-03-11
- **Who:** Cohere
- **Type:** model

Cohere released Command R, a 35-billion-parameter model aimed at enterprise work: retrieval-augmented generation, tool use and long context (128K tokens). Cohere published the weights for research use under a non-commercial license. It was an early open-weights model built around RAG and tool calling, a pattern that later became standard for enterprise AI apps.
