# AWS launches Inf1 instances powered by Inferentia

- **Date:** 2020-12-08
- **Who:** Amazon Web Services
- **Type:** hardware

At re:Invent's first machine learning keynote, AWS unveiled Inf1 EC2 instances built on its Inferentia inference chip, with support for EKS and SageMaker. The same keynote added distributed training libraries for SageMaker, which AWS said could finish up to 40% faster, and new SageMaker tools for pipelines and bias detection. It made cheap inference hardware available to ordinary cloud customers rather than only AWS itself.
