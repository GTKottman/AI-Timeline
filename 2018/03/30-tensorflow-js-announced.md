# Google announces TensorFlow.js for machine learning in the browser

- **Date:** 2018-03-30
- **Who:** Google TensorFlow team (Daniel Smilkov, Nikhil Thorat and colleagues)
- **Type:** software

At the TensorFlow Developer Summit in Mountain View, Google introduced TensorFlow.js, a framework for building and running machine learning models in JavaScript. It let developers run models in the browser on the client's own hardware and train them there, and it grew out of the earlier deeplearn.js project. It opened ML to web developers who had no Python stack, and it was one of the first mainstream ways to run neural networks directly in a web page.
