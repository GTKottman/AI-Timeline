# OpenAI introduces DALL-E 3, text-to-image model with better prompt following

- **Date:** 2023-10-03
- **Who:** OpenAI
- **Type:** model

OpenAI introduced DALL-E 3, an image generator designed to follow detailed prompts more closely than earlier versions, and integrated it with ChatGPT. It shifted the image-generation race toward prompt fidelity and text rendering.
