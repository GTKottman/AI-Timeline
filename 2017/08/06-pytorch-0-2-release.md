# PyTorch 0.2 released with broadcasting, advanced indexing and distributed training

- **Date:** 2017-08-06
- **Who:** PyTorch team (Facebook AI Research)
- **Type:** software

PyTorch 0.2 added broadcasting, advanced indexing, higher-order gradients, and the first distributed PyTorch support. The release was timed for the ICML season and made the framework's dynamic-graph style more capable for research work. Broadcasting changed behavior in some cases, which the release notes flagged.
