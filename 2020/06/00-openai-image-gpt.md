# OpenAI releases Image GPT, generative pretraining from pixels

- **Date:** 2020-06-00
- **Who:** OpenAI (Mark Chen, Alec Radford, Ilya Sutskever and colleagues)
- **Type:** model

OpenAI released iGPT, a GPT-2-style transformer that is trained to predict the next pixel in low-resolution images. It can generate images unconditionally or conditionally, and its features reached 96.3% linear-probe accuracy on CIFAR-10. The work showed that the GPT-style pretraining recipe transfers from text to images.
