# AWS Panorama Appliance and Device SDK for edge computer vision

- **Date:** 2020-12-01
- **Who:** Amazon Web Services (AWS); partners Axis Communications, Basler AG, NVIDIA (Jetson), Ambarella
- **Type:** hardware

At AWS re:Invent 2020 on December 1, Amazon announced AWS Panorama, an on-premises machine learning appliance that adds computer vision to existing ONVIF-compatible IP cameras. The appliance runs multiple models per camera stream and is rated for harsh environments. AWS also announced the Panorama Device SDK so camera and device makers can build Panorama-enabled smart cameras on NVIDIA Jetson and Ambarella CV2x chips. It was offered as a developer-kit preview, with partner cameras "coming soon." The point was to run vision models locally, with low latency and without sending video to the cloud.
