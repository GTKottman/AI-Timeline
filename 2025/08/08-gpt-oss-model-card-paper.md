# OpenAI publishes gpt-oss-120b and gpt-oss-20b model card

- **Date:** 2025-08-08
- **Who:** OpenAI
- **Type:** paper

The gpt-oss model card paper describes two open-weight reasoning models, gpt-oss-120b and gpt-oss-20b, which use mixture-of-experts designs and are trained with distillation and reinforcement learning. The models are tuned for agentic tasks such as web browsing, Python tool use and developer-defined function calls. Weights, inference code and tokenizers were released under Apache 2.0.
