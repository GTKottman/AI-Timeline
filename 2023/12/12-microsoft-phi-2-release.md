# Microsoft Research releases Phi-2 small language model

- **Date:** 2023-12-12
- **Who:** Microsoft Research
- **Type:** model

Phi-2 is a 2.7-billion-parameter language model for language and coding, released after a November preview at Microsoft Ignite. Microsoft said it matched or beat models up to about 25 times larger on reasoning, math and coding benchmarks. It supported the idea that data quality, not only scale, drives capability, and it kept small models in active research use.
