# OpenAI releases GPT-5-Codex

- **Date:** 2025-09-15
- **Who:** OpenAI
- **Type:** model

OpenAI released GPT-5-Codex, a version of GPT-5 tuned for agentic coding in Codex across the cloud, CLI and IDE extension. It can adjust how long it thinks to task complexity, from seconds for simple requests to runs of hours on large jobs. OpenAI reported its refactoring score rising from 33.9% for GPT-5 (high) to 51.3%, and it launched for ChatGPT paid plans first, with API access added on September 23.
