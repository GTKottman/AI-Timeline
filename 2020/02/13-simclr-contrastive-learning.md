# Google publishes SimCLR, a simple framework for contrastive visual learning

- **Date:** 2020-02-13
- **Who:** Google Research (Chen, Kornblith, Norouzi, Hinton)
- **Type:** paper

The arXiv paper "A Simple Framework for Contrastive Learning of Visual Representations" showed that self-supervised image representations can be learned without memory banks or special architectures. It found that data augmentation choice, a learnable nonlinear projection head, and large batches with long training mattered most. Its linear classifier reached 76.5% top-1 on ImageNet, which helped make contrastive self-supervision a mainstream method.
