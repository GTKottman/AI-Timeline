# Microsoft unveils seven in-house MAI models at Build 2026

- **Date:** 2026-06-03
- **Who:** Microsoft AI (Mustafa Suleyman), Microsoft
- **Type:** model

At Build 2026 in San Francisco, Microsoft launched seven in-house MAI models, led by MAI-Thinking-1, which it calls its first purpose-built reasoning model. Reports describe it as a sparse mixture-of-experts model with about one trillion total and 35 billion active parameters; the context window is reported as either 128K or 256K. The family also includes MAI-Code-1-Flash for GitHub Copilot and VS Code, MAI-Image-2.5 and MAI-Transcribe-1.5. Performance and cost claims are Microsoft-reported. Build ran June 2 to 3; the exact announcement day was not confirmed.
