# OpenAI Hide-and-Seek Shows Emergent Tool Use

- **Date:** 2019-09-17
- **Who:** OpenAI, with Igor Mordatch
- **Type:** research

OpenAI trained teams of agents in a simulated hide-and-seek game with no direct reward for using objects. Over hundreds of millions of games (MIT Technology Review says nearly 500 million) the agents went through six strategies and counterstrategies, including building forts, moving boxes to block exits, and using ramps to get over obstacles. Several of these behaviors were ones the researchers did not expect the environment to support. The work, "Emergent Tool Use From Multi-Agent Autocurricula," showed that competition alone can drive complex tool use, and it was published as an ICLR 2020 paper.
