# Nvidia announces H200 GPU

- **Date:** 2023-11-13
- **Who:** Nvidia
- **Type:** hardware

Nvidia announced the HGX H200 built on its Hopper architecture, at the SC23 conference. It is the first GPU with HBM3e memory, with 141 GB at 4.8 TB/s, nearly double the memory capacity and 2.4 times the bandwidth of the A100. Nvidia said it roughly doubles inference speed over the H100 on some large language models, and it was hardware and software compatible with HGX H100 systems. Availability was set for the second quarter of 2024.
