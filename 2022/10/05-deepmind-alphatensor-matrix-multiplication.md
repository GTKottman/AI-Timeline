# DeepMind AlphaTensor finds faster matrix multiplication algorithms

- **Date:** 2022-10-05
- **Who:** DeepMind
- **Type:** research

DeepMind announced AlphaTensor, a reinforcement learning system built on AlphaZero that searches for matrix multiplication methods needing fewer scalar multiplications. It found algorithms that matched or beat known human-designed methods for certain matrix sizes, showing AI could discover new algorithms.
