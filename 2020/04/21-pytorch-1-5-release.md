# PyTorch 1.5 released with stable C++ frontend and distributed RPC

- **Date:** 2020-04-21
- **Who:** PyTorch team (Facebook AI)
- **Type:** software

PyTorch 1.5 promoted the C++ frontend to parity with Python and marked it stable, and made the distributed RPC framework stable after it was experimental in 1.4. The release added channels-last memory format for vision models and new autograd APIs for Hessians and Jacobians. It mattered because it moved PyTorch's production-facing C++ path and distributed training from experimental to supported.
