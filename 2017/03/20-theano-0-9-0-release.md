# Theano 0.9.0 released

- **Date:** 2017-03-20
- **Who:** Theano development team
- **Type:** software

Theano 0.9.0, a large release of the Python deep learning library, shipped on March 20, 2017. It added Python 3.5 and NumPy 1.12 support, conda packages for Mac, Linux and Windows, better Windows tooling, and checkpointing in scan to trade speed for memory on long sequences. The release was the last major version to ship the old GPU back-end, and users were pointed to the libgpuarray back-end.
