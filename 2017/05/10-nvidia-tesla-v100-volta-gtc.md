# NVIDIA unveils Tesla V100 with Volta GPU and Tensor Cores

- **Date:** 2017-05-10
- **Who:** NVIDIA
- **Type:** hardware

At GTC 2017, NVIDIA unveiled the Tesla V100, built on the Volta GV100 GPU. Its 640 Tensor Cores gave a claimed 120 teraflops of deep learning performance, a peak mixed-precision figure. The Tensor Core design became a standard feature of NVIDIA's data center GPUs for training neural networks.
