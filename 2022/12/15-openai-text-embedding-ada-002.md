# OpenAI releases text-embedding-ada-002

- **Date:** 2022-12-15
- **Who:** OpenAI
- **Type:** model

OpenAI released text-embedding-ada-002, a single embedding model that replaced five separate embedding models in its API (text-similarity, text-search query and doc, code-search text and code). It accepted inputs up to 8192 tokens, four times the earlier limit, and produced 1536-dimension vectors. OpenAI priced it about 99.8% below the old Davinci-based embeddings, which made cheap retrieval and semantic search over large text collections practical for many developers.
