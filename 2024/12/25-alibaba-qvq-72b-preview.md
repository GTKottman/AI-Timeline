# Alibaba Qwen releases QVQ-72B-Preview open-weight visual reasoning model

- **Date:** 2024-12-25
- **Who:** Alibaba Qwen team
- **Type:** model

QVQ-72B-Preview is an open-weight visual reasoning model built on Qwen2-VL-72B and trained to reason step by step over images. Qwen reported 70.3% on MMMU, positioning it against o1-style reasoning models. Qwen's own post lists known limits, including language switching and reasoning loops.
