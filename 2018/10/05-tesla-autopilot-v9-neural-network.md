# Tesla Autopilot V9 ships a unified camera neural network

- **Date:** 2018-10-05
- **Who:** Tesla (Autopilot team; Elon Musk)
- **Type:** model

Tesla began the wide rollout of Autopilot version 9 on October 5, 2018. Analysis by Tesla Motors Club members, reported by Electrek on October 15, described a network that processes all eight cameras with one shared set of weights at higher input resolution, and suggested it was near the limits of the onboard computer. On October 16 Musk tweeted that V9 is about a 400% increase in useful ops per second over V8.1, and said the analysis significantly overestimated the neural network gain. It showed a production car moving toward one vision network across all cameras.
