# Microsoft brings DALL-E 2 to Azure OpenAI Service at Ignite

- **Date:** 2022-10-12
- **Who:** Microsoft (with OpenAI)
- **Type:** product

At Microsoft Ignite on October 12, 2022, Microsoft announced that the DALL-E 2 image generation model would be offered through the Azure OpenAI Service, which then ran as a limited, invitation-only preview. Microsoft also said DALL-E 2 would reach its consumer products, starting with Microsoft Designer and then Bing Image Creator. It put OpenAI image generation in front of selected enterprise cloud customers, next to GPT-3.
