# Moonshot releases Kimi K2 Thinking, an open-weights reasoning model

- **Date:** 2025-11-06
- **Who:** Moonshot AI
- **Type:** model

Moonshot released Kimi K2 Thinking, an open-weights mixture-of-experts model with 1 trillion total parameters and 32 billion active per token, under a modified MIT licence. Moonshot reports 44.9% on Humanity's Last Exam with tools and 60.2% on BrowseComp, and says the model can run 200 to 300 sequential tool calls without human input. These benchmark figures are company-reported. The weights are roughly 600GB, which makes self-hosting demanding.
