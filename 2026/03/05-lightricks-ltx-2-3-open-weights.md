# Lightricks releases LTX-2.3 open-weight audio-video model

- **Date:** 2026-03-05
- **Who:** Lightricks
- **Type:** model

LTX-2.3 is an update to Lightricks' 22B-parameter LTX-2 diffusion transformer that generates synchronized video and audio. The update adds a rebuilt VAE for sharper output, native portrait video, cleaner audio and better prompt adherence, and the weights were posted on Hugging Face with day-0 ComfyUI support. Sources disagree on the license terms, so the Hugging Face model card should be checked before commercial use.
