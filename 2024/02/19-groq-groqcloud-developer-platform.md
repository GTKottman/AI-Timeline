# Groq soft-launches GroqCloud developer platform

- **Date:** 2024-02-19
- **Who:** Groq
- **Type:** product

Groq opened GroqCloud, a developer platform and API for running open LLMs on its LPU inference chips. Its fast token output drew wide attention to specialised inference hardware as an alternative to GPU serving.
