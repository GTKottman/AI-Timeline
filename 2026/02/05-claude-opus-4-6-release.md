# Anthropic releases Claude Opus 4.6 with agent teams

- **Date:** 2026-02-05
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude Opus 4.6 with agent teams, which split a large task into parts that several Claude agents work on in parallel. It also integrated Claude as a side panel in PowerPoint. Agent teams started in research preview for API users and subscribers.
