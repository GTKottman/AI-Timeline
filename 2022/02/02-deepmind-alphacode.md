# DeepMind unveils AlphaCode

- **Date:** 2022-02-02
- **Who:** DeepMind
- **Type:** model

DeepMind introduced AlphaCode, a code-generation system for competitive programming with a largest model of 41.4 billion parameters. Across ten recent Codeforces contests with more than 5,000 participants, it achieved an average ranking in the top 54.3% of human participants. The team also released its CodeContests dataset. The result showed language models could handle problems that need algorithmic reasoning, not only short code completion.
