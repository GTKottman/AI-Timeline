# Google releases Gemma open model family

- **Date:** 2024-02-21
- **Who:** Google; Google DeepMind
- **Type:** model

Gemma is a family of small, openly available models built from the same research and technology as Gemini. Google released weights for free use, which gave developers a light, permissive base model to fine-tune and run locally.
