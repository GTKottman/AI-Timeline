# AWS announces DeepLens, a deep-learning video camera for developers

- **Date:** 2017-11-29
- **Who:** Amazon Web Services
- **Type:** hardware

AWS announced DeepLens at re:Invent 2017 as a wireless video camera that runs deep learning models on the device, built for developers learning machine learning. It has a 1080p camera, an Intel Atom processor and 8 GB of RAM, is programmable with AWS Lambda, and integrates with SageMaker. Pre-orders opened the same day at $249.
