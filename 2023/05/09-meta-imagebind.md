# Meta releases ImageBind multimodal embedding model

- **Date:** 2023-05-09
- **Who:** Meta AI
- **Type:** model

Meta released ImageBind, an open model that maps six modalities (images, video, text, audio, depth, thermal and IMU motion data) into one shared embedding space, so one kind of input can retrieve another, such as finding video from an audio clip. It was released as an open-source checkpoint and research project. It mattered as a step toward a single embedding space across senses, with a clear path to adding touch and other modalities.
