# Anthropic releases Claude desktop apps for macOS and Windows

- **Date:** 2024-10-31
- **Who:** Anthropic
- **Type:** product

Anthropic released Claude desktop apps for macOS and Windows in public beta, bringing its chat assistant out of the browser. Windows builds came in x64 and arm64 versions. It was part of the push to make Claude a daily-use app alongside ChatGPT.
