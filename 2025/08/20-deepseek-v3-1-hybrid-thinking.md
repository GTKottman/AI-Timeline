# DeepSeek releases V3.1, a hybrid model with switchable thinking

- **Date:** 2025-08-20
- **Who:** DeepSeek
- **Type:** model

DeepSeek released V3.1, a 671-billion-parameter mixture-of-experts model with about 37 billion parameters active per token and a 128K context window. One model handles both reasoning and standard chat, switched through the chat template. It was trained with the UE8M0 FP8 scale format. The Hugging Face date is August 20, and coverage dated August 21.
