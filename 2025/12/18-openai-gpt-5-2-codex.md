# OpenAI releases GPT-5.2-Codex

- **Date:** 2025-12-18
- **Who:** OpenAI
- **Type:** model

OpenAI released GPT-5.2-Codex, a GPT-5.2 variant tuned for agentic software engineering in Codex and its CLI, with better context compaction and stronger reading of screenshots, diagrams and UI. Coverage cites 56.4% on SWE-Bench Pro and 64.0% on Terminal-Bench, which are vendor-reported. Access started with paid ChatGPT users, with API access following, and a cybersecurity-focused trusted-access pilot was added for defensive uses.
