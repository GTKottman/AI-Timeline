# Measuring Attribution in Natural Language Generation Models (AIS framework)

- **Date:** 2021-12-23
- **Who:** Hannah Rashkin and coauthors, Google Research
- **Type:** paper

Google Research posted an arXiv paper (2112.12870, first submitted 23 December 2021) proposing Attributable to Identified Sources (AIS), a framework for checking whether text a generation model produces about the external world is supported by a provided source. The authors define a two-stage human annotation pipeline and test it on conversational QA, summarization and table-to-text data, and they release their evaluation guidelines. It gave the field a concrete way to measure factual grounding in generated text.
