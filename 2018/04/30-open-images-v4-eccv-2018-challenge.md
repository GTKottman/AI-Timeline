# Google releases Open Images V4 and the ECCV 2018 Open Images Challenge

- **Date:** 2018-04-30
- **Who:** Google Research
- **Type:** dataset

Google released Open Images V4, then the largest public dataset with object location annotations. It contains 15.4 million bounding boxes for 600 object categories on 1.9 million images, plus 30.1 million image-level labels, most of the boxes drawn by hand by professional annotators. The release came with the ECCV 2018 Open Images Challenge, which included object detection and visual relationship tracks. The dataset paper was later published in IJCV.
