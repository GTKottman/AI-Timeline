# Meta releases Code Llama 70B

- **Date:** 2024-01-29
- **Who:** Meta AI
- **Type:** model

Meta added a 70-billion-parameter version to its Code Llama family of open coding models. Meta described it as the largest and top-performing model in the Code Llama family, which kept its open-weight line competitive for software tasks.
