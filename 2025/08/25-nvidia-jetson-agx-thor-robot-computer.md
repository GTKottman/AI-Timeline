# Nvidia launches Jetson AGX Thor robotics computer

- **Date:** 2025-08-25
- **Who:** Nvidia
- **Type:** hardware

Nvidia launched Jetson AGX Thor, a Blackwell-based robot computer with 128 GB memory and up to 2,070 FP4 teraflops, sold as a developer kit at $3,499, with a T5000 production module for bulk buyers. It mattered as Nvidia's dedicated onboard AI platform for physical robots.

Sources differ on the shipping date.
