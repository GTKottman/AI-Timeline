# Grok Build released under Apache License after data-upload criticism

- **Date:** 2026-07-16
- **Who:** xAI
- **Type:** software

xAI released Grok Build under the Apache License two days after criticism that it uploaded users' repositories to company cloud storage. It was a fast response to a developer-trust problem in an AI coding tool.
