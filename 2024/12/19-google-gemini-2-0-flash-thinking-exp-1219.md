# Google releases Gemini 2.0 Flash Thinking Experimental (1219)

- **Date:** 2024-12-19
- **Who:** Google DeepMind (Jeff Dean announced)
- **Type:** model

Google released gemini-2.0-flash-thinking-exp-1219, an experimental model built on Gemini 2.0 Flash that generates an explicit thinking process before its answer. It was free in Google AI Studio and the Gemini API, and Jeff Dean described it as trained to use its thoughts to strengthen reasoning. LMArena ranked it first overall, up from third. A third-party guide gave its limits at launch as text and image input, 32k input tokens and no built-in search or code tools. The January 21, 2025 update added a 1 million token context and code execution.
