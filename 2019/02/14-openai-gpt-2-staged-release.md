# OpenAI announces GPT-2 and withholds the full model

- **Date:** 2019-02-14
- **Who:** OpenAI
- **Type:** model

OpenAI announced GPT-2, a large transformer language model trained to predict the next word on about 40GB of internet text. It did not release the full 1.5-billion-parameter model, citing misuse concerns, and instead released a smaller 124-million-parameter version. The withheld release sparked a wide debate about responsible disclosure in AI research. The full 1.5B-parameter model followed in November 2019.
