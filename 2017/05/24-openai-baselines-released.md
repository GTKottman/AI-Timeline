# OpenAI open-sources Baselines reinforcement learning implementations

- **Date:** 2017-05-24
- **Who:** OpenAI
- **Type:** software

OpenAI released Baselines, a set of high-quality reference implementations of reinforcement learning algorithms, starting with DQN and three variants and promising more algorithms later. The aim was reproducibility: the team noted RL results are noisy and subtle bugs are common, so it published tested code that matched reported performance. It became a common baseline for RL research in TensorFlow.
