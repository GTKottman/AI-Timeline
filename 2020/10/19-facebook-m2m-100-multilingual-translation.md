# Facebook AI releases M2M-100, translation between 100 languages without English

- **Date:** 2020-10-19
- **Who:** Facebook AI
- **Type:** model

M2M-100 is a multilingual machine translation model that translates directly between any pair of 100 languages without routing through English. It was trained on about 7.5 billion sentence pairs mined with open tools, and Facebook reported a 10-point BLEU gain over English-centric systems. The model and code were released openly, which made many-to-many translation available to researchers and smaller teams.
