# TensorFlow 2.3 Release

- **Date:** 2020-07-27
- **Who:** Google / TensorFlow team
- **Type:** software

TensorFlow 2.3 added the tf.data service API, which moves input preprocessing onto a cluster of worker machines, and tf.data snapshots, which save a preprocessed pipeline's output to disk for reuse. The official TensorFlow blog post is dated July 27, 2020; one outlet reported the release on July 28.
