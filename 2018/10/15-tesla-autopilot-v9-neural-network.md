# Tesla Autopilot V9 ships a unified camera neural network

- **Date:** 2018-10-15
- **Who:** Tesla (Autopilot team; Elon Musk)
- **Type:** model

Tesla's version 9 Autopilot software, rolled out to an early-access owner group in early October, included a new neural network that processes all eight cameras with one shared set of weights, at higher input resolution. Analysis of the network by Tesla Motors Club members suggested it was near the limits of the onboard computer. Musk claimed a large gain in useful ops per second over V8.1, which was not independently verified. It mattered as an example of a production car running one end-to-end vision network across all cameras.
