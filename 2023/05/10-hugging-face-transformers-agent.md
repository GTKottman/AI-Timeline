# Hugging Face releases Transformers Agent

- **Date:** 2023-05-10
- **Who:** Hugging Face
- **Type:** software

Transformers Agent, shipped in Transformers v4.29.0, lets a language model turn a text instruction into a plan that calls Hugging Face models and tools, such as document question answering, summarization, captioning and speech tools. It offered a single-run mode and a chat mode that keeps state, and it could use OpenAI models or open models from BigCode and OpenAssistant. It mattered as an early library-level tool-calling agent built into a major open ML framework.
