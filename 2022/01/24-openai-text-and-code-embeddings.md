# OpenAI text and code embeddings by contrastive pre-training

- **Date:** 2022-01-24
- **Who:** OpenAI (Arvind Neelakantan, Tao Xu and 23 co-authors)
- **Type:** paper

OpenAI published a paper on training text and code embedding models with contrastive pre-training on large unsupervised datasets. The authors reported about a 4% relative gain over the previous best unsupervised text embedding models on linear-probe classification across 7 tasks, and about a 20.8% relative gain on code search. The embeddings became a building block for semantic search and retrieval features across later AI products.
