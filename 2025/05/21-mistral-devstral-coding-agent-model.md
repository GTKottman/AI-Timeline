# Mistral releases Devstral, an open-source coding agent model

- **Date:** 2025-05-21
- **Who:** Mistral AI, with All Hands AI
- **Type:** model

Mistral released Devstral, a 24-billion-parameter open model for software engineering agents, built with All Hands AI and based on Mistral Small 3.1. It targets multi-file edits, codebase exploration and bug fixes, and is designed to run on consumer hardware. Mistral reports 46.8% on SWE-bench Verified, a figure from its own evaluation. It is under Apache 2.0 and replaced Codestral for coding tasks.
