# OpenAI releases o3 and o4-mini with tool use in ChatGPT

- **Date:** 2025-04-16
- **Who:** OpenAI
- **Type:** model

OpenAI released o3, its strongest reasoning model at the time and successor to o1, along with the smaller and cheaper o4-mini. Both were trained to think longer before answering and could use every tool inside ChatGPT, including web search and Python file analysis. o4-mini reached all ChatGPT users, free tier included, on April 24. Third-party listings put o4-mini at $1.10 input / $4.40 output per million tokens.
