# Anthropic launches Claude Artifacts

- **Date:** 2024-06-20
- **Who:** Anthropic
- **Type:** product

Anthropic launched Artifacts in preview alongside Claude 3.5 Sonnet. It opens substantial generated content, such as code, documents or small apps, in a workspace beside the chat so the user can view and iterate on it. Later it reached all users and mobile apps, and it became an early example of an AI chat product that works as a mini app builder. The exact day rests on one secondary wiki source, so check it against Anthropic's own post before relying on it.
