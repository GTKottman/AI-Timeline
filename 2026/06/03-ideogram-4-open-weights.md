# Ideogram 4 image model weights released on Hugging Face

- **Date:** 2026-06-03
- **Who:** Ideogram
- **Type:** model

Ideogram released the weights of Ideogram 4, a 9.3B-parameter diffusion transformer, on Hugging Face on June 3, 2026. The weights are under a non-commercial licence while the inference code is Apache 2.0. A quantized nf4 build is reported to run on a single 24 GB GPU, and Ideogram's licensing page describes paid self-hosting for commercial use of the quantized weights. Ranking claims come from Ideogram's model card and were not independently verified.
