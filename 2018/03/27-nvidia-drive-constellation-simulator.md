# NVIDIA DRIVE Constellation autonomous vehicle simulator

- **Date:** 2018-03-27
- **Who:** NVIDIA
- **Type:** product

Announced in the GTC 2018 keynote, DRIVE Constellation is a two-server system for testing self-driving cars in simulation. One server runs DRIVE Sim to generate simulated camera, lidar and radar data; the other runs the DRIVE Pegasus car computer, which processes that simulated input as if it came from real sensors. NVIDIA pitched it as a way to test billions of simulated miles, including rare corner cases that are hard to find on real roads.
