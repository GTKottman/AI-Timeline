# Microsoft announces dedicated Copilot key for Windows PC keyboards

- **Date:** 2024-01-04
- **Who:** Microsoft
- **Type:** hardware

Microsoft announced a dedicated Copilot key for Windows keyboards, replacing the menu key on some machines. It was a hardware-level sign that AI assistants would be built into the operating system and PC design.
