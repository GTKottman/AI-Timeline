# Anthropic releases Claude Code 2.0

- **Date:** 2025-09-29
- **Who:** Anthropic
- **Type:** software

Anthropic released Claude Code 2.0 alongside Claude Sonnet 4.5, adding a native VS Code extension in beta with inline diffs, a refreshed terminal interface, and checkpoints that save the state before each prompt so the agent's file changes can be rolled back (exposed through the /rewind command). Coverage dates the release September 29, 2025.
