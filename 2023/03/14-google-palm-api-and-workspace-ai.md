# Google opens PaLM API and brings generative AI to Workspace

- **Date:** 2023-03-14
- **Who:** Google (Google Cloud, Google Workspace)
- **Type:** product

Google opened its PaLM large language model to developers through a private-preview API and a prototyping tool called MakerSuite. The same day it announced generative AI features for Workspace, including email drafting in Gmail, document writing in Docs, formula generation in Sheets, and content creation in Slides and Meet. The Workspace features were limited to "Trusted Testers" at launch. The announcement came days before Microsoft's "Future of Work" event, and it made Google's model available to outside developers for the first time.
