# Microsoft launches automated ML in Azure Machine Learning preview

- **Date:** 2018-09-24
- **Who:** Microsoft (Azure Machine Learning)
- **Type:** product

Microsoft announced automated ML as a preview capability of the Azure Machine Learning service, alongside a Python SDK, hyperparameter tuning and distributed deep learning. Automated ML picks the algorithm and pipeline for a labelled dataset, aimed at users without deep ML expertise. It was an early push to put model search and selection behind a cloud service, the same idea later sold across the industry as AutoML.
