# Anthropic launches prompt caching for the Claude API

- **Date:** 2024-08-14
- **Who:** Anthropic
- **Type:** product

Anthropic added prompt caching to the Claude API in public beta, so developers can mark reused parts of long prompts and pay about a tenth of the normal input price on cache hits. The beta covered Claude 3.5 Sonnet and Claude 3 Haiku, with Claude 3 Opus added later. Cache entries last five minutes and each hit resets the timer. Anthropic claimed up to 90% lower cost and 85% lower latency on long prompts. The date comes from secondary coverage, and no primary Anthropic announcement dated August 14 was found in the search results.
