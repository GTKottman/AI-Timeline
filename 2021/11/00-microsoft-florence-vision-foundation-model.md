# Microsoft unveils Florence, a foundation model for computer vision

- **Date:** 2021-11-00
- **Who:** Microsoft Research (Florence team)
- **Type:** model

Microsoft Research introduced Florence (arXiv 2111.11432), a vision foundation model meant to extend representations from scenes to objects, from images to video, and from RGB to multiple modalities. It reported new state-of-the-art results across many visual and visual-language benchmarks, including few-shot and zero-shot transfer. Microsoft later offered Florence through Azure Cognitive Services for Vision. The exact November day was not confirmed.
