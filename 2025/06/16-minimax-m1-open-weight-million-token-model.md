# MiniMax releases MiniMax-M1, an open-weight reasoning model with 1M context

- **Date:** 2025-06-16
- **Who:** MiniMax
- **Type:** model

MiniMax released MiniMax-M1, an open-weight hybrid mixture-of-experts reasoning model built on lightning attention, with 456 billion total parameters and about 45.9 billion active per token. It natively handles a 1 million token input context and up to 80,000 output tokens. The authors report using about a quarter of DeepSeek-R1's compute at 100K-token generation. Weights were posted to Hugging Face and GitHub, and coverage calls it Apache 2.0 licensed. The benchmark comparisons are the authors' own.
