# Google unveils third-generation TPU and 100-petaflop TPU pods at I/O

- **Date:** 2018-05-08
- **Who:** Google
- **Type:** hardware

At its I/O 2018 keynote, Google announced its third-generation Tensor Processing Unit and pods that it said would exceed 100 petaflops. Coverage described the new boards as carrying twice the high-bandwidth memory of the prior generation, and the pods as using liquid cooling. Google did not state the numerical precision behind its performance figures, which made comparisons with supercomputers hard. Cloud TPU Pods later became rentable through Google Cloud.
