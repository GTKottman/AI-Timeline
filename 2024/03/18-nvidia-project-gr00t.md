# NVIDIA announces Project GR00T humanoid robot foundation model

- **Date:** 2024-03-18
- **Who:** NVIDIA
- **Type:** model

At GTC 2024, NVIDIA announced Project GR00T, a general-purpose foundation model meant to let humanoid robots understand natural language and learn skills by watching people. The same announcement introduced the Jetson Thor computer for humanoid robots and an update to the Isaac robotics platform. It signaled NVIDIA's push to make robot learning a foundation-model problem, the same way language and vision had become.
