# DeepMind publishes AlphaEvolve paper on LLM-driven algorithm discovery

- **Date:** 2025-06-16
- **Who:** Google DeepMind
- **Type:** paper

The AlphaEvolve paper describes an evolutionary coding agent that uses LLMs to modify code and improve it over repeated rounds, guided by evaluator feedback. The authors report practical gains in Google's computing infrastructure and a method that multiplies two 4x4 complex-valued matrices with 48 scalar multiplications. It is the paper behind the May 2025 AlphaEvolve announcement.
