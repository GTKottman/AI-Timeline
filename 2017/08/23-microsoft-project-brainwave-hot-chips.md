# Microsoft unveils Project Brainwave FPGA platform for real-time AI

- **Date:** 2017-08-23
- **Who:** Microsoft, with Intel FPGAs (Stratix 10)
- **Type:** hardware

At Hot Chips 2017 Microsoft presented Project Brainwave, a deep learning acceleration platform built on FPGAs in its Azure and Bing data centers. It combined a distributed system architecture, a hardware DNN engine synthesized onto Intel Stratix 10 FPGAs, and a compiler and runtime for deploying trained models. Microsoft reported 39.5 teraflops sustained using its 8-bit ms-fp8 format with under one millisecond per request. It mattered as a real-time, low-latency inference architecture.
