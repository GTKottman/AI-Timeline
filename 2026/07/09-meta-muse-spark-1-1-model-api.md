# Meta launches Muse Spark 1.1 and public preview of Meta Model API

- **Date:** 2026-07-09
- **Who:** Meta
- **Type:** product

Meta released Muse Spark 1.1, a multimodal reasoning model aimed at agentic tasks, coding and computer use, and opened a public preview of the Meta Model API to US developers on July 9, 2026. It accepts text, images, video and PDFs and outputs text, priced at $1.25 and $4.25 per million input and output tokens, with $20 in free credits for new accounts. The API is in preview with a waitlist, a shift for a company that had mostly shipped downloadable open weights.
