# Google launches Coral Edge TPU dev board and USB Accelerator

- **Date:** 2019-03-06
- **Who:** Google
- **Type:** hardware

Google launched Coral, its platform for building devices with local AI, selling its Edge TPU chip to outside buyers for the first time. The launch included a Dev Board and a USB Accelerator, and the Edge TPU was aimed at low-power inference. Software runs on TensorFlow Lite, with models quantized and compiled before they run on the chip.
