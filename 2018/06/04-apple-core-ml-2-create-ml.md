# Apple announces Core ML 2 and Create ML at WWDC 2018

- **Date:** 2018-06-04
- **Who:** Apple
- **Type:** software

At WWDC 2018 in San Jose, Apple announced Core ML 2, an update to its on-device machine learning framework. Batch prediction makes models about 30 percent faster, and quantization can shrink trained models by up to 75 percent. Apple paired it with Create ML, a tool for training models on a Mac, which cut one developer's training time from 24 hours to under an hour in its demo. It mattered because it pushed more AI inference and training onto phones and laptops instead of cloud servers.
