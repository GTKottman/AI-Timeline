# Monica launches Manus, an autonomous general AI agent

- **Date:** 2025-03-06
- **Who:** Monica (Butterfly Effect Technology)
- **Type:** product

Chinese startup Monica launched Manus, an agent that runs in the cloud to plan and carry out multi-step tasks without constant human supervision. It launched as an invite-only beta. Coverage describes it as building on models including Anthropic's Claude and fine-tuned Qwen models, though that detail comes from one secondary explainer. Within hours, open-source developers released OpenManus, a clone of its approach, and a paid credit-based plan followed soon after.
