# xAI releases Grok 4.5

- **Date:** 2026-07-16
- **Who:** xAI (SpaceXAI)
- **Type:** model

xAI released Grok 4.5, available in Grok Build, in Cursor on all plans and through the SpaceXAI API console. It can be used at no cost for a limited period in Grok Build and Cursor.
