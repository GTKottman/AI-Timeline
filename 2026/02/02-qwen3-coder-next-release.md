# Alibaba releases Qwen3-Coder-Next

- **Date:** 2026-02-02
- **Who:** Alibaba Qwen team
- **Type:** model

Alibaba's Qwen team released Qwen3-Coder-Next, an 80B-parameter mixture-of-experts coding model with about 3B active parameters, built for coding agents.
