# Facebook open-sources ELF OpenGo Go bot

- **Date:** 2018-05-02
- **Who:** Facebook AI Research (FAIR)
- **Type:** model

FAIR open-sourced ELF OpenGo, a Go-playing system built on its ELF reinforcement-learning platform, releasing both the trained model and the code used to build it. The project aimed to reproduce the AlphaGo Zero approach in an open form. Facebook said the bot won all 14 games against top 30 human Go players, reaching professional status. Coverage contrasted this with DeepMind keeping its own Go model closed.
