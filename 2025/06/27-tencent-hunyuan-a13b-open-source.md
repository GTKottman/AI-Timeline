# Tencent open-sources Hunyuan-A13B

- **Date:** 2025-06-27
- **Who:** Tencent Hunyuan
- **Type:** model

Tencent released Hunyuan-A13B on Hugging Face in pretrained, instruct, FP8 and GPTQ-Int4 versions, with a technical report. It is a mixture-of-experts model with about 80B total and 13B active parameters, a 256K context window and switchable fast and slow reasoning via /think and /no_think. Tencent's benchmark claims were contested. It mattered as a cheap-to-run open model from a large Chinese platform.
