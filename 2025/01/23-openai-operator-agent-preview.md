# OpenAI launches Operator, a browser-using agent preview

- **Date:** 2025-01-23
- **Who:** OpenAI
- **Type:** product

OpenAI released Operator, a research-preview agent that controls a web browser to carry out tasks such as filling forms and booking. It marked OpenAI's move from chat answers toward agents that act on websites.
