# Google announces Kubeflow, an ML stack for Kubernetes

- **Date:** 2017-12-21
- **Who:** Google engineers (Jeremy Lewi, David Aronchick), Kubernetes project
- **Type:** software

Google announced Kubeflow as a new open-source project on the Kubernetes blog. The stated aim was to make machine learning workloads portable and scalable on Kubernetes, so a model could move from a laptop to a large cluster without re-architecting. The first components were JupyterHub for notebooks and a TensorFlow custom resource definition with TF Serving. It mattered because it made Kubernetes the shared base for production ML pipelines.
