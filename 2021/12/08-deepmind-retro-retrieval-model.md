# RETRO: retrieval-enhanced language model paper

- **Date:** 2021-12-08
- **Who:** DeepMind (authors)
- **Type:** paper

The RETRO paper showed a language model that retrieves passages from a database of about two trillion tokens while it generates text. It reached performance comparable to GPT-3 and Jurassic-1 with about 25 times fewer parameters, which suggested that retrieval could replace some scale.
