# Facebook AI introduces BlenderBot 2 with long-term memory and web search

- **Date:** 2021-07-16
- **Who:** Facebook AI Research (Meta AI)
- **Type:** model

BlenderBot 2 added long-term memory across conversations and the ability to search the internet for information during a chat. Facebook released it as an open-source chatbot. It was a step toward retrieval-augmented dialogue, where models ground replies in external knowledge.
