# Facebook announces Tensor Comprehensions, open-source ML compiler

- **Date:** 2018-02-14
- **Who:** Facebook AI Research, with Inria, ETH Zurich and MIT
- **Type:** software

Facebook released Tensor Comprehensions under the Apache 2.0 license, a framework-agnostic compiler that lets researchers write ML operations in mathematical notation and generates tuned GPU code automatically. It used a polyhedral just-in-time compiler built on Halide IR. The arXiv paper reported up to 4x speedups over NVIDIA libraries on some kernels.
