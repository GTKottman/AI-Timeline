# Anthropic releases Claude Opus 5

- **Date:** 2026-07-24
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude Opus 5, which it said comes close to the frontier intelligence of Claude Fable 5 at half the price. It is priced at $5 and $25 per million input and output tokens, the same as Opus 4.8, and became the new default model on Claude Max.
