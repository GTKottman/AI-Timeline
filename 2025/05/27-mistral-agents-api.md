# Mistral Agents API

- **Date:** 2025-05-27
- **Who:** Mistral AI
- **Type:** product

Mistral AI launched the Agents API, a layer over its chat completion API for building agents. Its built-in connectors include code execution in a sandbox, web search and image generation, and it also supports MCP tools. It adds persistent memory across conversations and conversation-state management.
