# GitHub announces Copilot technical preview

- **Date:** 2021-06-29
- **Who:** GitHub (with OpenAI)
- **Type:** product

GitHub introduced Copilot, an AI pair programmer that suggests whole lines and functions in the editor as the developer types. It was built on OpenAI's Codex model and opened to a technical preview, the first wide-scale consumer use of a code-generating LLM.
