# Anthropic launches prompt caching for the Claude API

- **Date:** 2024-08-14
- **Who:** Anthropic
- **Type:** product

Anthropic added prompt caching to the Claude API in public beta, so developers can mark reused parts of long prompts and pay about a tenth of the normal input price on cache hits. Anthropic's page lists Claude 3.5 Sonnet, Claude 3 Opus and Claude 3 Haiku as supported. Anthropic claimed up to 90% lower cost and 85% lower latency on long prompts. Anthropic's page shows a 2025 date, but its own update note says caching became generally available on December 17, 2024, and Aug 2024 coverage confirms the launch date.
