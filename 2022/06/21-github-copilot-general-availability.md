# GitHub Copilot becomes generally available

- **Date:** 2022-06-21
- **Who:** GitHub / Microsoft
- **Type:** product

GitHub moved Copilot out of technical preview and offered it as a paid subscription for individual developers. The AI coding assistant, built on OpenAI's Codex, became a mainstream product for writing code inside editors.
