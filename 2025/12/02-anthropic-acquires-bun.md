# Anthropic acquires Bun JavaScript runtime

- **Date:** 2025-12-02
- **Who:** Anthropic; Bun
- **Type:** acquisition

Anthropic acquired Bun, the JavaScript runtime company, to bring its tooling under the Claude Code team. Claude Code runs on Bun, so the deal tied a key developer-tool dependency to Anthropic's coding agent product.
