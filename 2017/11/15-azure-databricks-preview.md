# Microsoft announces Azure Databricks preview at Connect()

- **Date:** 2017-11-15
- **Who:** Microsoft, Databricks (Apache Spark)
- **Type:** product

Microsoft announced Azure Databricks, an Apache Spark-based analytics service built with the Databricks team and offered as a managed cloud service, at Connect() 2017. Microsoft framed it as Spark-as-a-service for large-scale data and machine learning on Azure, with integrations to Azure storage, data warehousing and Power BI. It put Spark-based AI and data science tooling directly into Azure's cloud catalogue.
