# Facebook finishes moving all translations to neural machine translation

- **Date:** 2017-08-03
- **Who:** Facebook Engineering (Facebook AI Research and applied ML teams)
- **Type:** product

Facebook announced that its translation system had fully moved from phrase-based models to neural machine translation, covering more than 2,000 translation directions and about 4.5 billion translations a day. The systems were built in Caffe2, and the team reported a 2.5x efficiency gain from its framework choice, plus 11% BLEU gain overall. It mattered as one of the first large-scale production deployments of neural translation for a global audience.
