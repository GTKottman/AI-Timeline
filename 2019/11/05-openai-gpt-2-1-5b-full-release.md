# OpenAI releases the full 1.5B-parameter GPT-2 model

- **Date:** 2019-11-05
- **Who:** OpenAI
- **Type:** model

OpenAI released the full 1.5-billion-parameter GPT-2 model with its code and weights, ending the staged release that started in February. It also released a detector model for GPT-2 text, which OpenAI said caught about 95% of 1.5B output. OpenAI said it had seen no strong evidence of misuse so far.
