# Alibaba open-sources QwQ-32B reasoning model

- **Date:** 2025-03-05
- **Who:** Alibaba (Qwen team)
- **Type:** model

Alibaba released QwQ-32B, a 32.5-billion-parameter reasoning model trained with reinforcement learning, under the Apache 2.0 licence on Hugging Face and ModelScope. Alibaba says it performs close to DeepSeek-R1, which has 671 billion parameters, but that claim comes from Alibaba and has not been independently confirmed in the sources checked. It built on the original QwQ preview from November 2024.
