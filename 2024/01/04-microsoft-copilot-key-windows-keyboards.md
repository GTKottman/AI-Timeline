# Microsoft announces dedicated Copilot key for Windows PC keyboards

- **Date:** 2024-01-04
- **Who:** Microsoft
- **Type:** hardware

Microsoft announced a dedicated Copilot key for Windows 11 PC keyboards, placed to the right of the spacebar. Pressing it opens Copilot, or Windows search if Copilot is turned off. It was a hardware-level sign that AI assistants would be built into the operating system and PC design.
