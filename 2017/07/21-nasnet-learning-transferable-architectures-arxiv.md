# NASNet: learning transferable architectures for image recognition (arXiv)

- **Date:** 2017-07-21
- **Who:** Barret Zoph, Vijay Vasudevan, Jonathon Shlens, Quoc V. Le (Google Brain)
- **Type:** paper

The paper (arXiv 1707.07012) searched for a convolutional cell on the small CIFAR-10 dataset with reinforcement learning, then stacked copies of that cell into a larger network for ImageNet. The resulting NASNet reached 82.7% top-1 accuracy on ImageNet, above the best human-designed models at the time while using fewer FLOPs. It was an early, influential example of neural architecture search, showing that learned architectures could beat hand-designed ones. It was later published at CVPR 2018.
