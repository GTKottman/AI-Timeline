# Alibaba releases Qwen3-Coder-480B and the Qwen Code CLI

- **Date:** 2025-07-22
- **Who:** Alibaba (Qwen team)
- **Type:** model

Alibaba released Qwen3-Coder-480B-A35B-Instruct, a mixture-of-experts coding model with 480 billion total and 35 billion active parameters, natively handling 256K-token contexts. Qwen said it set new open-model records on agentic coding and tool-use tasks and was comparable to Claude Sonnet 4 on some of them. The release also included Qwen Code, an open-source command-line coding tool.
