# Intel launches Movidius Neural Compute Stick for offline deep learning

- **Date:** 2017-07-20
- **Who:** Intel (Movidius)
- **Type:** hardware

Intel launched the Movidius Neural Compute Stick, a $79 USB device built around the Myriad 2 vision processor that runs trained deep learning models on-device without a cloud connection. It is the successor to the Fathom stick and was aimed at developers building offline vision and robotics prototypes. It mattered because it made dedicated neural inference hardware cheap and easy to attach to any computer.
