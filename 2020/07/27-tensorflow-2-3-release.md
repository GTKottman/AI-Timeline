# TensorFlow 2.3 Release

- **Date:** 2020-07-27
- **Who:** Google / TensorFlow team
- **Type:** software

TensorFlow 2.3 shipped with the tf.data service, which offloads input preprocessing to a worker cluster, and tf.data snapshots, which save preprocessed data to disk for reuse. The TF Profiler gained a memory profiler and a Python tracer. Keras added image and text dataset-from-directory loaders and experimental preprocessing layers that can live inside the model. The official TensorFlow blog post is dated July 27; a GitHub-mirror listing gives July 24.
