# Nvidia releases Mistral-NeMo-Minitron 8B small language model

- **Date:** 2024-08-21
- **Who:** Nvidia (base model from Mistral NeMo 12B)
- **Type:** model

Nvidia released Mistral-NeMo-Minitron 8B, a smaller model made by width-pruning the Mistral NeMo 12B base and retraining it with knowledge distillation. It was released under the Nvidia Open Model License, with a NIM microservice and Hugging Face weights, and Nvidia positioned it to run on RTX workstations. Nvidia claimed leading accuracy on nine popular benchmarks, a company-reported result.
