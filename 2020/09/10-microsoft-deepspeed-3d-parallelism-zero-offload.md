# Microsoft adds 3D parallelism and ZeRO-Offload to DeepSpeed

- **Date:** 2020-09-10
- **Who:** Microsoft Research
- **Type:** software

Microsoft added four new technologies to its open-source DeepSpeed training library, including 3D parallelism, which combines ZeRO data parallelism, pipeline parallelism and tensor-slicing model parallelism. ZeRO-Offload uses CPU and GPU memory so that a single NVIDIA V100 GPU can run models of up to 13 billion parameters without running out of memory. Microsoft's blog post is dated September 10, 2020.
