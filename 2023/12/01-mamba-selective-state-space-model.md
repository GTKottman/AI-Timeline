# Mamba: Linear-Time Sequence Modeling with Selective State Spaces

- **Date:** 2023-12-01
- **Who:** Albert Gu, Tri Dao
- **Type:** paper

The paper "Mamba: Linear-Time Sequence Modeling with Selective State Spaces" was first posted to arXiv on 1 December 2023. It makes the state space model's parameters depend on the input, so the model can choose what to keep or forget at each step, while still scaling linearly with sequence length. It mattered because it offered a serious non-Transformer architecture for language modeling, with faster inference than attention models of similar size.
