# Anthropic releases Claude 3.5 Sonnet with Artifacts

- **Date:** 2024-06-20
- **Who:** Anthropic
- **Type:** model

Claude 3.5 Sonnet outperformed Claude 3 Opus on many evaluations while running faster and cheaper. Anthropic launched Artifacts alongside it, a side-panel that rendered generated code and documents in claude.ai. It set a new point of comparison for coding assistants.
