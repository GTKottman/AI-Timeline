# Meta releases Muse Wonder, its first frontier model

- **Date:** 2026-10-12
- **Who:** Meta
- **Type:** model

Meta released Muse Wonder and Muse Wonder Full. Muse Wonder is available through the Meta Model API as muse-wonder-1.0 at $4 per million input and $20 per million output tokens, with cached input at $0.20; it is labelled preview. Full is limited to Muse Code subscribers and is not served through the API. Meta says both beat its earlier Muse Spark on coding and long-running agent tasks. Artificial Analysis scored Full at 56 and the API version at 52, against 58 for Claude Opus 5.5, and the figures in Meta's own table do not fully match Artificial Analysis's published numbers.
