# OpenAI releases text-davinci-003

- **Date:** 2022-11-28
- **Who:** OpenAI
- **Type:** model

OpenAI released text-davinci-003, a GPT-3-family model in its API built on the InstructGPT approach with human feedback. OpenAI said it produced clearer and more engaging content and handled more complex instructions. Jan Leike said it scored higher on human preference ratings without being fundamentally more capable than its base model. It was one of the last models in the line before ChatGPT launched two days later.
