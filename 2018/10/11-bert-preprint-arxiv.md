# BERT preprint posted to arXiv

- **Date:** 2018-10-11
- **Who:** Jacob Devlin, Ming-Wei Chang, Kenton Lee, Kristina Toutanova (Google AI Language)
- **Type:** paper

The BERT paper introduced a language model that learns context from both directions of unlabelled text, then adapts to many tasks with one added output layer. It set new benchmark results across eleven NLP tasks. Google open-sourced the code and models a few weeks later, on 2018-11-02.
