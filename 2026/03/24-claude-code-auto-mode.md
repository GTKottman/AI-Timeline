# Anthropic launches auto mode for Claude Code

- **Date:** 2026-03-24
- **Who:** Anthropic
- **Type:** product

Auto mode puts a background classifier in front of each Claude Code tool call, letting low-risk actions run and blocking risky ones such as mass file deletion or data exfiltration. It launched as a research preview; sources disagree on whether Team or Enterprise and API users came first. Anthropic recommends using it in sandboxed environments. It is a step toward agents running long tasks with fewer per-action approval prompts.
