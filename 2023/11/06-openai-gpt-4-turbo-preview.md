# OpenAI previews GPT-4 Turbo at DevDay

- **Date:** 2023-11-06
- **Who:** OpenAI
- **Type:** model

OpenAI previewed GPT-4 Turbo at its first DevDay through the gpt-4-1106-preview API name, with a 128K-token context window and knowledge of world events up to April 2023. Input token prices fell to one third and output token prices to half of GPT-4's. The same event introduced the Assistants API for building virtual assistant agents.
