# Textbooks Are All You Need: phi-1 code model

- **Date:** 2023-06-20
- **Who:** Microsoft Research
- **Type:** paper

The paper introduced phi-1, a 1.3B-parameter Transformer for Python code, trained on about 7B tokens of "textbook quality" web data plus GPT-3.5-generated textbooks and exercises. It reported 50.6% pass@1 on HumanEval, which was strong for its size. The result argued that data quality can substitute for model scale, a line of work that led to the later Phi small-model family.
