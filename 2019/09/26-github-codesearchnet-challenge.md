# GitHub and Microsoft Research launch the CodeSearchNet Challenge

- **Date:** 2019-09-26
- **Who:** GitHub, Microsoft Research (Deep Program Understanding group), Weights & Biases
- **Type:** dataset

CodeSearchNet released a corpus of about six million open-source functions in Go, Java, JavaScript, PHP, Python and Ruby, It also shipped 99 natural-language queries with more than 4,000 relevance annotations and a public leaderboard scored with NDCG. The aim was a shared benchmark for semantic code search, a task where neural methods were growing fast. The accompanying arXiv paper (1909.09436) was submitted September 20, 2019.
