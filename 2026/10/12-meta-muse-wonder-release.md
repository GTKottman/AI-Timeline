# Meta releases Muse Wonder, its first frontier model

- **Date:** 2026-10-12
- **Who:** Meta
- **Type:** model

Meta released Muse Wonder and Muse Wonder Full on October 12, 2026. Muse Wonder is in the Meta Model API as a preview at $4 per million input and $20 per million output tokens, with cached input at $0.20. Full is limited to Muse Code subscribers and is not served through the API. Both have a 1M-token context and, per Meta, beat its earlier Muse Spark on coding and long-running agent tasks. Artificial Analysis scored Full at 56 and the API version at 52, against 48 for Muse Spark 1.3; Meta's own comparisons are self-reported.
