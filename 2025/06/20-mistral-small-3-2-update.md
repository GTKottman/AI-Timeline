# Mistral releases Small 3.2, a 24B instruction-following update

- **Date:** 2025-06-20
- **Who:** Mistral AI
- **Type:** model

Mistral released Small 3.2, an update to Mistral Small 3.1 with the same 24-billion-parameter architecture. It targets instruction following, repetition and function calling, and it is open-weight.
