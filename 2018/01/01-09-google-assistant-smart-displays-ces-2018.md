# Google Assistant smart displays shown at CES 2018

- **Date:** 2018-01-09
- **Who:** Google, LG, Lenovo and other partners
- **Type:** product

The first smart displays with Google Assistant were shown at CES 2018, adding a screen to the voice assistant so it could answer with visual results. It was an early step toward multimodal assistant hardware competing with Amazon's Echo Show.
