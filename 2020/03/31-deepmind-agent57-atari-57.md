# DeepMind's Agent57 beats the human baseline on all 57 Atari games

- **Date:** 2020-03-31
- **Who:** DeepMind
- **Type:** research

DeepMind announced Agent57, a deep reinforcement learning agent that beat the human baseline on all 57 games of the Atari 2600 benchmark, which had been a long-standing goal of the field. It combined an exploration method with a meta-controller that switches between exploratory and exploitative behaviour. Coverage noted that it needed a very large number of game frames, so it was a milestone in capability rather than sample efficiency.
