# Hugging Face and AWS expand partnership

- **Date:** 2023-02-21
- **Who:** Hugging Face and Amazon Web Services (AWS)
- **Type:** other

Hugging Face and AWS announced an expanded partnership that made AWS Hugging Face's preferred cloud provider. Developers could use Amazon SageMaker, Trainium and Inferentia to train, fine-tune and deploy open models. The partnership gave open-model developers a major cloud route at the start of the generative AI boom.
