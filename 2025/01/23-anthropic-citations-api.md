# Anthropic launches the Citations API for grounded Claude answers

- **Date:** 2025-01-23
- **Who:** Anthropic
- **Type:** product

Anthropic added Citations to its API, so developers can pass documents to Claude and get answers that point to the exact passages they draw on. It worked with Claude 3.5 Sonnet and Claude 3.5 Haiku and was generally available on the Anthropic API and Google Cloud's Vertex AI. TechCrunch reported that Citations can add charges depending on the length and number of source documents. Anthropic's own evaluations claim up to a 15% gain over most custom citation setups.
