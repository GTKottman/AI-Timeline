# Microsoft makes Azure Machine Learning service generally available

- **Date:** 2018-12-04
- **Who:** Microsoft
- **Type:** product

Microsoft announced that the Azure Machine Learning service was generally available, giving developers and data scientists a cloud service to build, train and deploy models. Its headline features were automated machine learning, DevOps-style workflow management, deployment to the cloud and the edge, and a Python SDK that works with VS Code, PyCharm, Jupyter and Azure Databricks. It ran alongside the older Azure ML Studio product. Reports said billing for the service started in February 2019.
