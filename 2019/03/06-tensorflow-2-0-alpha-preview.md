# TensorFlow 2.0 alpha released

- **Date:** 2019-03-06
- **Who:** Google (TensorFlow team)
- **Type:** software

Google released the TensorFlow 2.0 alpha at the TensorFlow Dev Summit in Sunnyvale, giving developers an early preview of the major 2.0 redesign. The alpha made eager execution the default, made Keras the high-level API for building and training models, and shipped migration guidance for moving code from TensorFlow 1.x. It mattered because it set the direction for the framework's most widely used API changes.
