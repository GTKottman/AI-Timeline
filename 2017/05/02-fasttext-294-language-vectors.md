# fastText releases pre-trained vectors for 294 languages and compressed models

- **Date:** 2017-05-02
- **Who:** Facebook AI Research (FAIR)
- **Type:** software

The fastText team released pre-trained word vectors for 294 languages, two quick-start tutorials and a model-compression feature that shrinks models to a few hundred kilobytes using FAISS-based techniques. The compression lets text classifiers run on phones and small devices instead of needing gigabytes of memory. It mattered because it made multilingual word embeddings usable by any developer.
