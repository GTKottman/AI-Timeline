# NVIDIA releases Titan V with Volta GPU

- **Date:** 2017-12-00
- **Who:** NVIDIA
- **Type:** hardware

NVIDIA released the Titan V, a desktop card built on the Volta GV100 chip with Tensor Cores, giving researchers Tesla V100-class deep learning performance in a consumer-priced workstation card. It made Tensor Core mixed-precision training available to individual researchers and small labs.
