# Deep Sets

- **Date:** 2017-03-10
- **Who:** Manzil Zaheer, Satwik Kottur, Siamak Ravanbakhsh, Barnabás Póczos, Ruslan Salakhutdinov, Alexander Smola
- **Type:** paper

arXiv preprint that characterizes all permutation-invariant functions on sets and turns that form into a neural architecture that takes sets of any size and order. The method was applied to population statistic estimation, point-cloud classification, set expansion and outlier detection. It was later accepted as a NeurIPS 2017 oral,
