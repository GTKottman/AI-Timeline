# Cohere releases Command A+ as its first fully Apache 2.0 open model

- **Date:** 2026-05-20
- **Who:** Cohere
- **Type:** model

Command A+ merges Cohere's Command A, Reasoning, Vision and Translate variants into one sparse mixture-of-experts model with 218B total and 25B active parameters, supporting 48 languages and a 128K input context. Cohere says it runs on as few as one B200 or two H100 GPUs and ships under Apache 2.0, its first fully Apache-licensed open model. Most sources date the release to May 20, one to May 19. The throughput and quantization claims are the company's own.
