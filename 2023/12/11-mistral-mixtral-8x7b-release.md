# Mistral AI releases Mixtral 8x7B open-weight mixture-of-experts model

- **Date:** 2023-12-11
- **Who:** Mistral AI
- **Type:** model

Mistral first released the model as a bare torrent magnet link, then published the write-up on December 11. Mixtral 8x7B is a sparse mixture-of-experts model with open weights under Apache 2.0. Mistral said it performs at least as well as GPT-3.5 and Llama 2 70B on most benchmarks while using far fewer active parameters per token, which made strong open models practical to run and fine-tune.
