# OpenAI publishes "Evaluating Large Language Models Trained on Code" (Codex paper)

- **Date:** 2021-07-07
- **Who:** OpenAI (Mark Chen, Jerry Tworek and about 50 co-authors)
- **Type:** paper

The paper, arXiv 2107.03374, described Codex, a GPT model fine-tuned on public GitHub code, and introduced the HumanEval benchmark for Python code generation. Codex solved 28.8% of HumanEval problems on a single sample, against 0% for GPT-3 and 11.4% for GPT-J, and 70.2% with 100 samples per problem. The paper also covered limitations, safety, security and economic impact. A production version of the model powered GitHub Copilot, and the HumanEval harness was released as open source.
