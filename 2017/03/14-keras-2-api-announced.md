# Keras 2 API announced, aligned with TensorFlow

- **Date:** 2017-03-14
- **Who:** François Chollet / Keras team (Google)
- **Type:** software

Chollet announced Keras 2 on the Keras blog, with a new API designed to line up with TensorFlow. The Keras API was to ship inside TensorFlow starting with TensorFlow 1.2 as tf.keras, while a separate multi-backend version kept supporting Theano and TensorFlow. This mattered because it made Keras a shared, standard high-level API that many researchers and developers could use across backends.
