# Claude becomes generally available on Amazon Bedrock

- **Date:** 2023-09-28
- **Who:** Anthropic; Amazon Web Services
- **Type:** product

Anthropic announced that Claude was generally available on Amazon Bedrock, so every AWS customer could build with Claude through AWS. It put a frontier model from a second lab into a managed cloud service for foundation models. Agents for Amazon Bedrock, which let Claude take multi-step actions through AWS Lambda functions, was still in preview at the time.
