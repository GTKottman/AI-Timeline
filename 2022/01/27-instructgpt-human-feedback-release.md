# InstructGPT released as OpenAI's default API model

- **Date:** 2022-01-27
- **Who:** OpenAI
- **Type:** model

OpenAI announced InstructGPT, a GPT-3.5-series model tuned on human-written instructions and human feedback. Labelers preferred its outputs over the much larger 175B GPT-3, and it made instruction following and fewer invented facts the default in OpenAI's API. It is the direct technical predecessor of ChatGPT.
