# Google opens Gemini 1.5 Pro to public preview

- **Date:** 2024-04-09
- **Who:** Google, Google Cloud
- **Type:** product

At Google Cloud Next 2024, Google moved Gemini 1.5 Pro from limited testing to a public preview available through the Gemini API in more than 180 countries, with a 1-million-token context window. Google released it alongside a new text embedding model, a file API, system instructions and JSON mode. Long-context access to a frontier-class model through a public API made very long document and video prompts practical for developers.
