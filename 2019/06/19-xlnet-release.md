# XLNet released by CMU and Google Brain

- **Date:** 2019-06-19
- **Who:** Carnegie Mellon University and Google Brain (Zhilin Yang, Zihang Dai, et al.)
- **Type:** model

XLNet is a generalized autoregressive pretraining method for language. It improves on BERT by learning from all permutations of word order, and it beat BERT on 20 tasks, reaching state of the art on 18. The code and the 340M-parameter XLNet-Large model were released under Apache 2.0. It was one of the strongest pretrained language models of mid-2019.
