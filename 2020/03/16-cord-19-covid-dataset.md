# CORD-19 COVID-19 Open Research Dataset released

- **Date:** 2020-03-16
- **Who:** Allen Institute for AI, Chan Zuckerberg Initiative, Georgetown University, Microsoft, US National Library of Medicine
- **Type:** dataset

The CORD-19 dataset of COVID-19 and coronavirus research papers was released as an open resource for text-mining and AI research. The initial release held about 29,000 scholarly articles, over 13,000 with full text, and was set to be updated weekly. Kaggle hosted an accompanying challenge built on it, which made it a common training and search corpus for COVID literature tools.
