# AWS makes Trainium2 Trn2 instances generally available

- **Date:** 2024-12-03
- **Who:** Amazon Web Services (AWS)
- **Type:** hardware

At AWS re:Invent, Amazon made its Trn2 EC2 instances built on the Trainium2 AI chip generally available. Amazon claims 30-40% better price performance than the GPU-based P5e and P5en instances. Trn2 UltraServers linking 64 Trainium2 chips were announced, and Trainium3 was previewed for late 2025. Amazon also announced Project Rainier, a cluster built with Anthropic.
