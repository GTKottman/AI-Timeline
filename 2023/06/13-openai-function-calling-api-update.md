# OpenAI function calling and API model update

- **Date:** 2023-06-13
- **Who:** OpenAI
- **Type:** product

OpenAI added function calling to the Chat Completions API for gpt-3.5-turbo and gpt-4, so developers could describe functions with JSON Schema and have the model return the arguments as JSON for calling external tools and APIs. The same update shipped gpt-4-0613 and gpt-3.5-turbo-0613, a 16k-context gpt-3.5-turbo variant, and price cuts (embeddings and input tokens). Function calling became the standard way to connect models to software tools.
