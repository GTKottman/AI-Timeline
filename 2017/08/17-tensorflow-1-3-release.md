# TensorFlow 1.3 Released

- **Date:** 2017-08-17
- **Who:** Google (TensorFlow team)
- **Type:** software

TensorFlow 1.3 introduced the first canned Estimators, including DNN and linear classifiers and regressors and combined DNN-linear variants, which gave users ready-made model types on top of the core API. The release also moved the build to cuDNN 6.0. The day given is the date of the RStudio blog post announcing the release.
