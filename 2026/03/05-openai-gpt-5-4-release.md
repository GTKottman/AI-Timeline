# OpenAI launches GPT-5.4 with Thinking and Pro versions

- **Date:** 2026-03-05
- **Who:** OpenAI
- **Type:** model

OpenAI launched GPT-5.4 with Thinking and Pro variants, with built-in computer use and better deep research. OpenAI said it made 33% fewer factual errors than GPT-5.2, and it scored 75% on the OSWorld-Verified desktop benchmark, above the 72.4% human average cited.
