# One-Shot Imitation Learning

- **Date:** 2017-03-21
- **Who:** Yan Duan, Marcin Andrychowicz, Bradly Stadie, Jonathan Ho, Jonas Schneider, Ilya Sutskever, Pieter Abbeel, Wojciech Zaremba (OpenAI and collaborators)
- **Type:** paper

arXiv paper submitted March 21, 2017 proposing a meta-learning framework in which a robot learns a task from a single demonstration and generalizes to new instances of that task. The policy takes the current observation plus one demonstration of a different instance and outputs actions. The work was trained over many task families, such as stacking blocks into a tower, and later appeared at NeurIPS 2017.
