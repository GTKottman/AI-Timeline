# Microsoft publishes Kosmos-1 multimodal language model

- **Date:** 2023-02-27
- **Who:** Microsoft Research
- **Type:** model

Microsoft introduced Kosmos-1 in the paper "Language Is Not All You Need: Aligning Perception with Language Models," submitted to arXiv on 27 February 2023. Kosmos-1 is a multimodal large language model trained from scratch on interleaved text and images, and it handles image captioning, visual question answering and few-shot and zero-shot instruction following. It showed that one language model could take visual input directly, an approach later used by many vision-language models.
