# OpenAI retires GPT-4o from ChatGPT

- **Date:** 2026-02-13
- **Who:** OpenAI
- **Type:** product

OpenAI retired GPT-4o from ChatGPT in mid-February, around Valentine's Day, after a backlash from users attached to it. The shutdown showed how model deprecations now affect a large user base.
