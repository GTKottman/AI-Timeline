# Google releases TF-Ranking, a scalable TensorFlow library for learning-to-rank

- **Date:** 2018-12-05
- **Who:** Google AI (Xuanhui Wang, Michael Bendersky; paper authors Pasumarthi, Bruch and colleagues)
- **Type:** software

Google AI announced TF-Ranking, an open-source TensorFlow library for learning-to-rank, which the team said filled a gap because TensorFlow had no out-of-the-box support for ranking. It offers pairwise and listwise losses, ranking-metric optimization and unbiased learning-to-rank, and the companion paper says it was already used in Google production systems. It matters because ranking models for search and recommendation became easier to build inside the mainstream deep learning framework.
