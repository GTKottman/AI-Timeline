# Nvidia Llama-3.1-Nemotron-Ultra-253B open reasoning model

- **Date:** 2025-04-07
- **Who:** Nvidia
- **Type:** model

Nvidia released Llama-3.1-Nemotron-Ultra-253B-v1 on Hugging Face with weights, code and post-training data. It is a 253-billion-parameter model derived from Meta's Llama-3.1-405B through neural architecture search, with a reasoning mode switched on by the system prompt. Nvidia claimed it beat DeepSeek-R1 on several benchmarks at about half the size; those figures are the vendor's own.
