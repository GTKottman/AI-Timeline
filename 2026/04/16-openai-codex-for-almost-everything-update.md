# OpenAI expands Codex to operate computers and handle ongoing work

- **Date:** 2026-04-16
- **Who:** OpenAI
- **Type:** product

The Codex update lets the agent operate the user's computer alongside them, use more tools and apps, generate images, remember preferences and run repeatable work. It also adds PR review, multi-file and terminal views, SSH connections to remote devboxes and an in-app browser. It moves Codex from a coding assistant toward a general work agent across the desktop.
