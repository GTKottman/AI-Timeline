# OpenAI releases MuseNet music generation model

- **Date:** 2019-04-25
- **Who:** OpenAI
- **Type:** model

OpenAI announced MuseNet, a transformer that generates four-minute compositions for up to 10 instruments and blends styles such as Chopin and pop. It learned harmony and rhythm by predicting the next token across MIDI files, with no explicit music theory. It used the same general-purpose approach as GPT-2, adapted with a Sparse Transformer for long sequences, and it was demonstrated in a livestreamed concert.
