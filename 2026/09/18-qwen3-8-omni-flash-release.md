# Alibaba releases Qwen3.8-Omni-Flash

- **Date:** 2026-09-18
- **Who:** Alibaba Qwen team
- **Type:** model

Alibaba released Qwen3.8-Omni-Flash, a multimodal model that accepts text, image, audio and video input with a 1M-token context window. It is generally available on the Qianwen AI Platform and through Alibaba Cloud Model Studio.
