# Microsoft releases Phi-3-mini small language model

- **Date:** 2024-04-23
- **Who:** Microsoft
- **Type:** model

Microsoft released Phi-3-mini, a 3.8 billion parameter model trained on 3.3 trillion tokens, on Azure, Hugging Face and Ollama, with an NVIDIA NIM option. Microsoft said it matched GPT-3.5-class quality in a model small enough to run on phones, and it announced Phi-3-small (7B) and Phi-3-medium (14B) to follow. It pushed the small-model trend that made capable models practical on-device.
