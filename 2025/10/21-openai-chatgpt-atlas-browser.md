# OpenAI launches ChatGPT Atlas, an AI-first web browser

- **Date:** 2025-10-21
- **Who:** OpenAI
- **Type:** product

OpenAI launched ChatGPT Atlas, a Chromium-based browser built around ChatGPT, first for Mac. It has a sidebar that reads the page the user is on, an agent mode that carries out tasks, and optional browser memory. Sources disagree on which plans get Agent Mode. OpenAI says browsing data is not used to train models by default. Coverage framed it as a challenge to Google Chrome and to AI-native browsers such as Perplexity's Comet, and Alphabet shares fell 2.6% the same day.
