# OpenAI previews GPT-4 Turbo at DevDay

- **Date:** 2023-11-06
- **Who:** OpenAI
- **Type:** model

OpenAI previewed GPT-4 Turbo at its first DevDay through the gpt-4-1106-preview API name, with a 128K-token context window and knowledge of world events up to April 2023. Input and output token prices were cut to a third and half of GPT-4's. The same event introduced the Assistants API and added vision, DALL-E 3 image generation and text-to-speech to the API.
