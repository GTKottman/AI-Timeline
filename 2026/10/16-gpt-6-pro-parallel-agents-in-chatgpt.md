# OpenAI adds parallel agents and faster answers to GPT-6 Pro in ChatGPT

- **Date:** 2026-10-16
- **Who:** OpenAI
- **Type:** product

On October 16, 2026 OpenAI updated GPT-6 Pro in ChatGPT with faster responses, better use of plugins and tools, and parallel agents that split one task into subtasks worked on at the same time. Users can follow each agent's progress and open finished subtasks to check them. The feature is limited to Pro users in the Chat tab. OpenAI gave no speed figures, agent counts or regional rollout details, and sources differ on whether the model is called GPT-6 Pro or GPT-6 Astra Pro. Secondary reports trace back to OpenAI's post.
