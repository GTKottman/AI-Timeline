# PyTorch 1.0 stable released at NeurIPS

- **Date:** 2018-12-07
- **Who:** Facebook AI
- **Type:** software

Facebook announced PyTorch 1.0 stable at NeurIPS. Its headline features were a hybrid front end that moves between eager and graph execution through the JIT, a revamped distributed package, a pure C++ front end, and Torch Hub. The release turned PyTorch from a research favourite into a production framework and set up the library's rapid growth in research use.
