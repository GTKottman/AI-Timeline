# Hugging Face launches LeRobot open-source robotics library

- **Date:** 2024-05-06
- **Who:** Hugging Face, Remi Cadene
- **Type:** software

Hugging Face released LeRobot, an open-source PyTorch library of models, datasets and tools for real-world robotics, on GitHub. It covers data sharing and visualization, model training, pretrained policies and integration with physics simulators. Remi Cadene, a former Tesla staff scientist, led the project after joining in March 2024. It brought the Hugging Face model-and-dataset workflow to robot learning.
