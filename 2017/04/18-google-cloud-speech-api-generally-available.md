# Google Cloud Speech API becomes generally available

- **Date:** 2017-04-18
- **Who:** Google Cloud
- **Type:** product

Google moved its Cloud Speech API out of open beta into general availability, bringing the speech recognition core that powers Google Search and Assistant to any developer. The release came with about 3x faster batch processing, better long-form accuracy, support for WAV, Opus and Speex files, and over 80 languages and variants. It mattered because it made production-grade speech recognition available as a paid cloud API.
