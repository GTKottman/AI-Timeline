# DeepMind publishes FunSearch in Nature

- **Date:** 2023-12-14
- **Who:** Google DeepMind
- **Type:** research

FunSearch pairs a pretrained LLM that proposes program code with an automatic evaluator that scores it, and evolves the best programs over many rounds. It produced new best-known solutions to the cap set problem in combinatorics and new online bin-packing heuristics. It was presented as the first case of an LLM system making a new verified discovery on an open scientific problem.
