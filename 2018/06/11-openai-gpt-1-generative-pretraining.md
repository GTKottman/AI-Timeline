# OpenAI releases GPT-1: generative pre-training for language

- **Date:** 2018-06-11
- **Who:** OpenAI (Alec Radford, Karthik Narasimhan, Tim Salimans, Ilya Sutskever)
- **Type:** model

OpenAI released the paper "Improving Language Understanding by Generative Pre-Training" and the first GPT model. It pre-trained a Transformer as a language model on unlabeled text, then fine-tuned it on each task, improving results on 9 of 12 benchmarks studied. The approach of pre-train then fine-tune became the template for later large language models.
