# PyTorch 1.9 released

- **Date:** 2021-06-15
- **Who:** PyTorch (Meta AI open-source team and community)
- **Type:** software

PyTorch 1.9 shipped with over 3,400 commits from 398 contributors. It added scientific computing APIs (torch.linalg, torch.special, complex autograd), a Mobile Interpreter that cut on-device binary size, TorchElastic moved into core for fault-tolerant distributed training, and GPU support in the RPC framework. Domain libraries shipped the same day, including TorchVision SSD models and a wav2vec 2.0 model in TorchAudio that could be deployed outside Python.
