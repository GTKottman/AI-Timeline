# NVIDIA Announces PCIe Version of Volta Tesla V100 at ISC 2017

- **Date:** 2017-06-20
- **Who:** NVIDIA
- **Type:** hardware

At the ISC 2017 supercomputing conference in Frankfurt, NVIDIA formally announced a PCI Express version of the Volta-based Tesla V100 accelerator. The card uses the same GV100 GPU as the SXM2 module, with 112 TFLOPS of tensor performance at a 250 W TDP compared with 300 W for SXM2, and it was due later in 2017. It extended the Volta deep learning accelerator to standard PCIe servers, which made it easier to add to existing data centers.
