# OpenAI's Dactyl learns in-hand dexterity in simulation and transfers to a real robot hand

- **Date:** 2018-07-30
- **Who:** OpenAI
- **Type:** research

OpenAI's "Learning Dexterity" post introduced Dactyl, which manipulates a block with a Shadow Dexterous Hand. It was trained entirely in simulation using randomized physical properties such as friction, with the same general-purpose reinforcement learning algorithm and code used for OpenAI Five, and then transferred to the physical robot without fine-tuning. The accompanying paper, "Learning Dexterous In-Hand Manipulation", was released with it. It mattered as evidence that simulation-trained reinforcement learning could reach real robot manipulation.
