# Facebook AI Research releases ParlAI dialog research platform

- **Date:** 2017-09-09
- **Who:** Facebook AI Research
- **Type:** software

ParlAI is an open source Python platform for dialog research, giving researchers a shared framework to train and test dialog models, Mechanical Turk integration for data collection and evaluation, and a repository of models. The first release covered more than 20 tasks, including SQuAD, bAbI and VQA, along with memory networks and seq2seq models. It mattered because it gave dialog AI a common benchmark and tooling base.
