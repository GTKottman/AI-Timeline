# Amazon Nova Premier generally available

- **Date:** 2025-04-30
- **Who:** Amazon Web Services (AWS)
- **Type:** model

AWS made Nova Premier generally available on Amazon Bedrock as its most capable multimodal model, with a one-million-token context window and text, image and video input. It is positioned as a teacher model for Bedrock Model Distillation, and priced at $2.50 per million input tokens and $12.50 per million output tokens. Independent comparisons found it trailing Gemini 2.5 Pro on coding and some math and science tests.
