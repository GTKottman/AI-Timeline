# xAI opens the Grok 3 and Grok 3 Mini API

- **Date:** 2025-04-03
- **Who:** xAI
- **Type:** product

xAI made Grok 3 and Grok 3 Mini generally available through its API, after promising in February that API access would follow in the coming weeks. The API itself already existed from a November 2024 public beta, so this was the Grok 3 models arriving on it. The date comes from xAI's release notes.
