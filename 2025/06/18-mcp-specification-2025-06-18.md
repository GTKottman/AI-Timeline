# Model Context Protocol specification 2025-06-18 released

- **Date:** 2025-06-18
- **Who:** Model Context Protocol maintainers (Anthropic-led open standard)
- **Type:** software

The 2025-06-18 revision of the MCP spec removed JSON-RPC batching, added structured tool output and resource links in tool results, and added elicitation so servers can ask users for input. It classifies MCP servers as OAuth Resource Servers and requires clients to implement RFC 8707 resource indicators. The auth and structured-output changes shape how remote tool servers are built and secured.
