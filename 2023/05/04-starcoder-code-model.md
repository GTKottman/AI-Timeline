# ServiceNow and Hugging Face release StarCoder code model

- **Date:** 2023-05-04
- **Who:** ServiceNow Research, Hugging Face (BigCode project)
- **Type:** model

StarCoder is a 15.5-billion-parameter open code model with an 8K context window and fill-in-the-middle support, trained on The Stack and fine-tuned from StarCoderBase. It was released under the BigCode Open RAIL-M licence, which allows commercial use with ethical-use restrictions. It mattered as one of the strongest openly available code models at the time and a base for many later coding tools.
