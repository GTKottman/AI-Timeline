# Microsoft and NVIDIA announce Megatron-Turing NLG 530B

- **Date:** 2021-10-11
- **Who:** Microsoft and NVIDIA
- **Type:** model

Microsoft and NVIDIA announced Megatron-Turing NLG, a generative language model with 530 billion parameters trained with DeepSpeed and Megatron parallelism. It was the largest dense English language model announced to that point, and it showed how large-scale training software could be combined across two companies.
