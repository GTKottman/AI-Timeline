# Mozilla releases open-source DeepSpeech speech model and Common Voice dataset

- **Date:** 2017-11-29
- **Who:** Mozilla
- **Type:** software

Mozilla released its first open-source speech recognition engine, DeepSpeech, based on Baidu's Deep Speech research and built on TensorFlow, with Python, Node.js and command-line packages. It reported a 6.5% word error rate on LibriSpeech test-clean and was released with the Common Voice dataset, which nearly 20,000 people contributed to. It gave developers a royalty-free alternative to proprietary speech-to-text APIs.
