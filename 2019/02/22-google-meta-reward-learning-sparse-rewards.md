# Google's Meta Reward Learning (MeRL) for sparse and underspecified rewards

- **Date:** 2019-02-22
- **Who:** Google AI
- **Type:** research

Google introduced Meta Reward Learning (MeRL), which learns an auxiliary reward function using meta-learning, tuned to how well the agent performs on a held-out validation set. It is paired with a memory buffer of successful trajectories gathered by a mode-covering exploration strategy. The authors reported state-of-the-art results on the WikiTableQuestions and WikiSQL semantic parsing benchmarks.
