# LAION-5B: 5.85 billion CLIP-filtered image-text pairs

- **Date:** 2022-03-31
- **Who:** LAION (Romain Beaumont and collaborators)
- **Type:** dataset

LAION released LAION-5B, a public dataset of 5.85 billion CLIP-filtered image-text pairs, with about 2.3 billion English captions. It shipped with image URLs, CLIP ViT-L/14 embeddings and similarity and safety scores, giving open researchers a web-scale training set that had not been available before.
