# AWS makes TorchServe the native default model server in Amazon SageMaker

- **Date:** 2020-09-30
- **Who:** Amazon Web Services (with Facebook / PyTorch)
- **Type:** software

AWS's September 2020 Machine Learning roundup, dated 30 September 2020, listed native TorchServe support in Amazon SageMaker. TorchServe became the default model server for PyTorch inference there, so teams could deploy PyTorch models without writing custom serving code. TorchServe itself had first been released in April 2020; the September change was the deeper native integration.

Note: the date is the roundup date; the original SageMaker launch post was not found.
