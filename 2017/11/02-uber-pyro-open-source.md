# Uber AI Labs open-sources Pyro probabilistic programming language

- **Date:** 2017-11-02
- **Who:** Uber AI Labs
- **Type:** software

Uber AI Labs released Pyro, a probabilistic programming language built on PyTorch. It combines deep learning with Bayesian modelling so researchers can write deep probabilistic models with stochastic inference.
