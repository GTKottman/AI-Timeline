# TensorFlow 2.5.0 release

- **Date:** 2021-05-14
- **Who:** Google (TensorFlow team)
- **Type:** software

TensorFlow 2.5.0 was released in May 2021. DevClass reported the release on 14 May 2021; the official GitHub release date was not confirmed. Highlights included Python 3.9 support, strict round-robin reads in tf.data for synchronous training, and oneDNN CPU optimizations that stay off unless TF_ENABLE_ONEDNN_OPTS is set. It also renamed the environment variable TF_CPP_MIN_VLOG_LEVEL to TF_CPP_MAX_VLOG_LEVEL, a breaking change.
