# Facebook releases PyTorch 1.1 with TensorBoard support

- **Date:** 2019-05-01
- **Who:** Facebook AI Research / PyTorch team
- **Type:** software

At its F8 developer conference Facebook released PyTorch 1.1, which added experimental native TensorBoard support, better distributed training and JIT improvements. It also open-sourced BoTorch and Ax under the MIT license. The release made PyTorch easier to use with TensorFlow's visualization tooling, a sign the frameworks were competing directly.
