# Alibaba releases Qwen2 model family

- **Date:** 2024-06-06
- **Who:** Alibaba Cloud (Qwen team)
- **Type:** model

Qwen2 is a family of open-weight language models in several sizes, four dense models from 0.5B to 72B parameters and one mixture-of-experts model, 57B-A14B, which activates about 14 billion parameters per token. It widened the open-model options for multilingual and coding tasks.
