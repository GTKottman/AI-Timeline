# Deepfake Detection Challenge winners announced

- **Date:** 2020-06-12
- **Who:** Facebook, Partnership on AI, and partners; more than 2,000 participants
- **Type:** competition

Facebook's Deepfake Detection Challenge, run on Kaggle, ended with a top model that scored 65.18% on a black-box test set of videos that entrants never saw. More than 2,000 participants submitted over 35,000 models, sharing a $1 million prize pool.
