# Google Cloud launches Rapid Response Virtual Agent for COVID-19 contact centers

- **Date:** 2020-04-08
- **Who:** Google Cloud (Contact Center AI); partners 8x8, Avaya, Cisco, Five9; Verily (Pathfinder template)
- **Type:** product

Google Cloud offered a fast-deploy virtual agent built on Dialogflow that answers COVID-19 questions, such as symptoms, and passes on CDC and WHO guidance. Organizations could plug in open-source COVID-19 templates, including Verily's Pathfinder, and deploy in any of Dialogflow's 23 supported languages. Early users included state unemployment offices in Illinois, New York and Oklahoma, which were swamped with calls. It showed conversational AI being used as an emergency public-facing service.
