# OpenAI releases o3-mini, first reasoning model for free ChatGPT users

- **Date:** 2025-01-31
- **Who:** OpenAI
- **Type:** model

OpenAI released o3-mini, a smaller and cheaper reasoning model. It let users set reasoning effort to low, medium or high and added function calling and Structured Outputs in the API. It was the first OpenAI reasoning model open to free ChatGPT users. It was previewed in December 2024.
