# Google DeepMind's AlphaEvolve finds a faster 4x4 matrix multiplication method

- **Date:** 2025-05-14
- **Who:** Google DeepMind
- **Type:** research

AlphaEvolve is a coding agent that uses Gemini models to write and test algorithms automatically. DeepMind reported that it found a 48-multiplication method for multiplying 4x4 complex matrices, the first improvement on Strassen's 1969 algorithm in 56 years. It also reported savings in Google's computing costs from the systems it evolved.
