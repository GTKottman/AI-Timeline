# Meta reveals Llama 3 GPU clusters and 350,000 H100 plan

- **Date:** 2024-01-18
- **Who:** Meta, Mark Zuckerberg
- **Type:** hardware

Mark Zuckerberg announced that Meta was training Llama 3 and would have about 350,000 Nvidia H100 GPUs by the end of 2024, roughly 600,000 H100-equivalents of compute including other hardware. Meta also described two 24,576-GPU clusters. It mattered because it set a public compute scale for open-model training and signalled Meta's push toward general-purpose AI.
