# Meta releases Muse Spark Open with open weights

- **Date:** 2026-10-15
- **Who:** Meta (Alexandr Wang)
- **Type:** model

Meta released Muse Spark Open, an 816-billion-parameter mixture-of-experts model with 42 billion active parameters and a 1M-token context, built for coding and agent tasks. It is Meta's first open-weight release from the Spark line, which had launched closed in April, and it appeared on Hugging Face and on cloud catalogues including Amazon SageMaker, Google Cloud Model Garden and Microsoft Foundry. Wang called it the most capable US open-weight model to date. It ships under the Muse Model License, which has commercial limits and is not a fully open-source license, and independent Vals AI results put it at 46.61%, ranked 38th of 49.
