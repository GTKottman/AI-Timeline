# OpenAI text and code embeddings by contrastive pre-training

- **Date:** 2022-01-24
- **Who:** OpenAI (Arvind Neelakantan et al.)
- **Type:** paper

OpenAI published a paper (arXiv 2201.10005, submitted 24 January 2022) on training text and code embedding models with contrastive pre-training on large unsupervised datasets. The authors report a 4% relative gain over the previous best unsupervised text embedding models on linear-probe classification averaged over 7 tasks, and a 20.8% relative gain over prior work on code search. The embeddings support semantic search and retrieval features.
