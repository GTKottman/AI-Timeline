# OpenAI launches GPT-3 API in private beta

- **Date:** 2020-06-11
- **Who:** OpenAI
- **Type:** product

OpenAI opened access to its general-purpose text API, built on GPT-3, in a private beta through a waitlist. Developers could integrate the model into products or explore its strengths and limits. The launch started the wave of apps built on hosted large language models.
