# OpenAI releases GPT-5, and GPT-4o is restored for paying users

- **Date:** 2025-08-07
- **Who:** OpenAI
- **Type:** model

OpenAI released GPT-5 as its main ChatGPT model. The reception was poor, and OpenAI restored GPT-4o for paying subscribers after complaints. It was a major model release that showed how sensitive users were to changes in model behavior.
