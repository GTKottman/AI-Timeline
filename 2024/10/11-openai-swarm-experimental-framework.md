# OpenAI publishes Swarm, an experimental multi-agent framework

- **Date:** 2024-10-11
- **Who:** OpenAI
- **Type:** software

OpenAI published Swarm on GitHub under the MIT license as an experimental, educational framework for building multi-agent systems. Its core ideas are agents with instructions and tools that can hand a conversation off to another agent. OpenAI said it was not an official product and would not be maintained as production software. Swarm became an early reference point for lightweight agent orchestration code.
