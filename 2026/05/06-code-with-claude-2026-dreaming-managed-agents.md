# Anthropic announces Dreaming and Managed Agents features at Code with Claude

- **Date:** 2026-05-06
- **Who:** Anthropic
- **Type:** product

At Anthropic's Code with Claude developer event in San Francisco on May 6, 2026, Anthropic announced "Dreaming," a research-preview feature for Claude Managed Agents that reviews past agent sessions and curates memory so agents improve between runs. A conference recap says Anthropic also doubled Claude Code five-hour rate limits for Pro, Max, Team and seat-based Enterprise plans. One outlet dates Dreaming to May 19 instead.
