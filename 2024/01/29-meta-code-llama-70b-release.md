# Meta releases Code Llama 70B

- **Date:** 2024-01-29
- **Who:** Meta AI
- **Type:** model

Meta added a 70-billion-parameter version to its Code Llama family of open coding models. It was the largest openly released code model of its time and kept Meta's open-weight line competitive for software tasks.
