# Facebook announces PyTorch 1.0 at F8 with ImageNet record

- **Date:** 2018-05-02
- **Who:** Facebook
- **Type:** software

On day 2 of F8, Facebook said PyTorch 1.0 would merge PyTorch, Caffe2 and ONNX into one framework for research and production, with a beta due in the following months. It also reported 85.4% top-1 ImageNet accuracy (single crop) from a model trained on about 1 billion public Instagram images with 1,500 hashtags as labels. The announcement set up the framework's production-ready 1.0 release later in 2018.
