# OpenAI opens fine-tuning for GPT-3.5 Turbo

- **Date:** 2023-08-22
- **Who:** OpenAI
- **Type:** product

OpenAI made fine-tuning available for GPT-3.5 Turbo, letting developers train custom versions on their own data, with GPT-4 fine-tuning promised for later in the fall. OpenAI said data sent to the fine-tuning API stays the customer's and is not used to train other models. This was the first fine-tuning for a ChatGPT-family model, and it opened custom model building to API customers.
