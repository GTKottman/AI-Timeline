# Alibaba open-sources Wan 2.1 video generation models

- **Date:** 2025-02-25
- **Who:** Alibaba Cloud
- **Type:** model

Alibaba announced on February 25, 2025 that it would open-source Wan 2.1, its video and image generation model, with weights public the next day. The release covered four models, T2V-1.3B, T2V-14B, I2V-14B-720P and I2V-14B-480P, for text-to-video and image-to-video, available through ModelScope and Hugging Face with code on GitHub. The release came as competition in China's AI market intensified after DeepSeek's open-source models that month.
