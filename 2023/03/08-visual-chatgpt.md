# Visual ChatGPT: Talking, Drawing and Editing with Visual Foundation Models

- **Date:** 2023-03-08
- **Who:** Microsoft Research Asia (Chenfei Wu, Shengming Yin, Weizhen Qi, Xiaodong Wang, Zecheng Tang, Nan Duan)
- **Type:** research

Microsoft Research Asia posted a paper and open-source system that pairs ChatGPT with visual foundation models (Synced Review reports 22), so the chatbot can receive images, generate them, and edit them through conversation. The approach used the language model as a controller that calls specialist vision tools, a pattern later reused by many tool-using agents. Code was released on GitHub alongside the paper.
