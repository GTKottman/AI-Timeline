# TensorFlow 1.2 release

- **Date:** 2017-06-15
- **Who:** Google (TensorFlow team)
- **Type:** software

TensorFlow 1.2 added tf.layers.conv3d_transpose, tf.Session.make_callable() for lower-overhead repeated execution and a SavedModel CLI, and moved RNN cells onto tf.layers.Layer. The release notes checked here do not mention tf.keras.
