# OpenAI launches ChatGPT Atlas, an AI-first web browser

- **Date:** 2025-10-21
- **Who:** OpenAI
- **Type:** product

OpenAI launched ChatGPT Atlas, a browser built around ChatGPT, first for macOS. It has a sidebar that reads the page the user is on, an agent mode that carries out tasks, and optional browser memory. Agent mode is in preview for paid tiers, and sources differ on which plans get it. OpenAI says browsing data is not used to train models by default.
