# Anthropic releases Claude 2.1 with 200K-token context

- **Date:** 2023-11-21
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude 2.1 with a 200K-token context window, about 150,000 words, and said it significantly reduced hallucination, halving the rate of false statements in secondary reports of its claim. The release added system prompts and a beta tool-use feature. Coverage reported that the full 200K window was reserved for paying Claude Pro users.
