# Microsoft launches automated ML in Azure Machine Learning preview

- **Date:** 2018-09-24
- **Who:** Microsoft (Azure Machine Learning)
- **Type:** product

Microsoft announced automated ML as a preview capability of the Azure Machine Learning service, accessible through the Azure Machine Learning Python SDK and Jupyter notebook experience. Automated ML picks the algorithm and pipeline for a labelled dataset. It was an early push to put model search and selection behind a cloud service, the same idea later sold across the industry as AutoML.
