# Alibaba unveils proprietary Qwen3.7-Max flagship

- **Date:** 2026-05-28
- **Who:** Alibaba Qwen team
- **Type:** model

Alibaba unveiled Qwen3.7-Max, a proprietary flagship model that it said beat Google Gemini and ChatGPT on some coding tests. It marked a shift toward closed flagships in the Qwen line.
