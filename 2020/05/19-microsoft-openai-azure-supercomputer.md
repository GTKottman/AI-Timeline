# Microsoft unveils Azure AI supercomputer built for OpenAI

- **Date:** 2020-05-19
- **Who:** Microsoft, OpenAI
- **Type:** hardware

At its online Build 2020 conference, Microsoft unveiled an Azure-hosted supercomputer built in collaboration with OpenAI and used exclusively for OpenAI's large model training. Reports cited more than 285,000 CPU cores and 10,000 GPUs, and Microsoft claimed it would rank in the global top five. The system was the compute base on which OpenAI later trained GPT-3, tying the 2019 Microsoft investment to the scale of the models that followed.
