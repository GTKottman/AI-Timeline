# ChatGPT gains voice conversations and image input

- **Date:** 2023-09-25
- **Who:** OpenAI
- **Type:** product

OpenAI began rolling out voice and image capabilities to ChatGPT, letting Plus and Enterprise users talk to the model on mobile and choose from five synthetic voices, and share images for analysis. Speech input used OpenAI's Whisper recognition system. The release made multimodal chat a mainstream product, since the model could now see and hear as well as read.
