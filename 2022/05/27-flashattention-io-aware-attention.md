# FlashAttention: fast, memory-efficient exact attention

- **Date:** 2022-05-27
- **Who:** Stanford University researchers (Tri Dao and colleagues)
- **Type:** research

FlashAttention computes exact attention with tiling so that it moves less data between GPU high-bandwidth memory and fast on-chip memory. The method made training long-context Transformers faster and cheaper, and it became a standard kernel in deep learning frameworks.
