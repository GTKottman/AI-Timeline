# Baidu releases open source Apollo 1.5 autonomous driving platform

- **Date:** 2017-09-21
- **Who:** Baidu
- **Type:** software

Baidu released Apollo 1.5, adding open source modules for obstacle perception, planning, cloud simulation, HD maps and end-to-end deep learning driving, and announced an autonomous driving investment fund of about $1.5 billion. The release extended the open platform begun in April and gave developers more of the self-driving stack to reuse.
