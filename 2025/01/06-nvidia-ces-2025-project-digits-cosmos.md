# NVIDIA at CES 2025: Project DIGITS, Cosmos and GeForce RTX 50

- **Date:** 2025-01-06
- **Who:** NVIDIA
- **Type:** hardware

In its CES 2025 keynote NVIDIA announced Project DIGITS, a desktop AI machine built on the GB10 Grace Blackwell Superchip, aimed at running large models locally. It also announced Cosmos, an open-licensed world foundation model platform for physical AI such as robots and self-driving cars, and the GeForce RTX 50 series. Sources give a $3,000 price for DIGITS, which one source says can run models up to 200 billion parameters, but they disagree on whether it ships in March or May. The keynote date is given as January 6 in the sources checked.
