# OpenAI DevDay 2025: Apps SDK, AgentKit and GPT-5 Pro in the API

- **Date:** 2025-10-06
- **Who:** OpenAI
- **Type:** product

At DevDay in San Francisco, OpenAI announced a preview of the Apps SDK, which lets developers build apps that run inside ChatGPT conversations and is built on the Model Context Protocol. Launch partners included Canva, Booking.com, Coursera, Expedia, Figma, Spotify and Zillow. It also launched AgentKit, a toolkit for building agents with a visual Agent Builder, and ChatKit for embedding chat in other apps. GPT-5 Pro, Sora 2 and Sora 2 Pro became available in the API, and two cheaper real-time voice models were announced. Some outlets date DevDay October 7, and the sources are secondary.
