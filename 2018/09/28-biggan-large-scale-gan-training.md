# BigGAN: large-scale GAN training for high-fidelity image synthesis

- **Date:** 2018-09-28
- **Who:** Andrew Brock, Jeff Donahue, Karen Simonyan (DeepMind)
- **Type:** model

BigGAN trained generative adversarial networks at a much larger scale than before and added a regularisation method that lets users trade image quality against diversity. It set state-of-the-art ImageNet image-synthesis results. It showed that scaling compute and batch size could sharply improve GAN output.
