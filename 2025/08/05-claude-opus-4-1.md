# Anthropic releases Claude Opus 4.1

- **Date:** 2025-08-05
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude Opus 4.1 as an upgrade to Opus 4 for agentic tasks, real-world coding and reasoning. Anthropic reported 74.5% on SWE-bench Verified, and improvements in detail tracking and agentic search for research. It kept the same price as Opus 4.
