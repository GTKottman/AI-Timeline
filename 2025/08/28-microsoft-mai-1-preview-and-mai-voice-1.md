# Microsoft unveils MAI-1-preview and MAI-Voice-1, its first in-house models

- **Date:** 2025-08-28
- **Who:** Microsoft AI
- **Type:** model

Microsoft AI released MAI-1-preview, a mixture-of-experts model that Microsoft describes as its first foundation model trained end to end in-house, alongside the voice model MAI-Voice-1. MAI-1-preview was trained on about 15,000 NVIDIA H100 GPUs and was aimed at everyday questions. Microsoft said it would roll the text model into Copilot over the following weeks and opened it to public testing on LMArena. Commentators saw it as a step to reduce reliance on OpenAI, which Microsoft said it would keep using.
