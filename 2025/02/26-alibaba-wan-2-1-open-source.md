# Alibaba open-sources Wan 2.1 video generation models

- **Date:** 2025-02-26
- **Who:** Alibaba Cloud
- **Type:** model

Alibaba open-sourced four Wan 2.1 video and image generation models on February 26, 2025, local time in China. The four are T2V-1.3B and T2V-14B for text-to-video, and I2V-14B-720P and I2V-14B-480P for image-to-video. Weights are on ModelScope and Hugging Face, with code on GitHub.
