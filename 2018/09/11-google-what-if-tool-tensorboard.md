# Google releases the What-If Tool for probing ML models without code

- **Date:** 2018-09-11
- **Who:** Google AI
- **Type:** software

Google launched the What-If Tool, a feature of the open-source TensorBoard app. It lets people inspect a TensorFlow model and its dataset through a visual interface with no code. Users can explore counterfactual examples, edit datapoints by hand, and compare performance and fairness across data subgroups. It made model debugging and fairness checks available to people who do not write machine learning code.
