# DeepSeek quietly releases R1-0528, an updated open reasoning model

- **Date:** 2025-05-28
- **Who:** DeepSeek
- **Type:** model

DeepSeek posted an update to R1 on Hugging Face, with improved benchmark performance, better front-end coding, fewer hallucinations, and support for JSON output and function calling. The model card reports AIME 2025 accuracy rising from 70% to 87.5%, and one source puts average reasoning length rising from about 12K to about 23K tokens. The model is 671 billion parameters (685 billion including its multi-token prediction module) under the MIT license.
