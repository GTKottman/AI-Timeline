# Google open-sources Active Question Answering in TensorFlow

- **Date:** 2018-10-10
- **Who:** Google AI Language
- **Type:** software

Google AI Language released an open-source TensorFlow package for Active Question Answering (ActiveQA). In it, a reinforcement learning agent learns to rephrase a question and query an existing QA system to get better answers. The release included a pretrained reformulation model, an answer selection model on GloVe embeddings, and the BiDAF QA system used as the environment, with trained checkpoints.
