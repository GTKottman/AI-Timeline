# Black Forest Labs FLUX.1 Kontext

- **Date:** 2025-05-29
- **Who:** Black Forest Labs
- **Type:** model

Black Forest Labs unveiled FLUX.1 Kontext, a suite of models that generate and edit images from both a text prompt and an input image, so edits can be made iteratively in context. It shipped with the BFL Playground for testing. The company said the FLUX.1 family had produced 700 million images via API to date. Sources disagree on whether Kontext weights were openly released or only offered in a closed beta, so check BFL's announcement before relying on the access terms.
