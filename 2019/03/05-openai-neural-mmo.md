# OpenAI Neural MMO multiagent game environment

- **Date:** 2019-03-05
- **Who:** OpenAI
- **Type:** software

OpenAI released Neural MMO, a massively multiagent game environment for reinforcement learning, with an RPG-style world where agents forage for food and water, gather resources and fight each other. Agents are rewarded for how long they survive rather than for fixed objectives, and the environment scales to many servers with 128 agents each. OpenAI framed it as a testbed for open-ended multiagent research, arguing that many agents and species produce better exploration and niche formation.
