# Alibaba releases Qwen2.5-Omni-7B, an end-to-end multimodal model for devices

- **Date:** 2025-03-26
- **Who:** Alibaba (Qwen team)
- **Type:** model

Alibaba released Qwen2.5-Omni-7B, a 7-billion-parameter model that takes text, images, audio and video and streams text and speech responses. Its Thinker-Talker design splits text reasoning and speech generation into separate components. Alibaba published it on Hugging Face, GitHub and ModelScope. Transformers documentation lists March 26, 2025 as the release date; Simon Willison dates the release March 27.
