# Anthropic announces Dreaming and Managed Agents features at Code with Claude

- **Date:** 2026-05-06
- **Who:** Anthropic
- **Type:** product

At Anthropic's developer conference in San Francisco, the company announced four Claude Managed Agents features, including "Dreaming," a scheduled process that reviews past agent sessions and curates memory so agents improve between runs. Anthropic also doubled Claude Code rate limits and raised Opus API limits. Third-party guides describe Dreaming as a gated research preview, so access may be limited. The date comes from a single secondary account of the conference.
