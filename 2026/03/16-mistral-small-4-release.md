# Mistral releases Small 4 under Apache 2.0

- **Date:** 2026-03-16
- **Who:** Mistral AI
- **Type:** model

Mistral Small 4 merges the earlier Magistral (reasoning), Pixtral (multimodal) and Devstral (agentic coding) lines into one open model. It is a mixture-of-experts model with reported 119B total parameters, about 6B active per token, a 256K context window and configurable reasoning effort, released under Apache 2.0. One model covering reasoning, vision and coding under a permissive license lowers the cost of running several specialist models.
