# AWS announces G4 instances with NVIDIA T4 GPUs

- **Date:** 2019-03-18
- **Who:** Amazon Web Services, NVIDIA
- **Type:** hardware

AWS announced G4 cloud instances built on NVIDIA's Turing-based T4 Tensor Core GPUs, unveiled at NVIDIA's GTC conference. Each instance could carry up to eight T4 GPUs with AWS-custom Intel CPUs, aimed at ML inference along with video transcoding and graphics work. The launch gave cloud customers a lower-cost inference GPU option and extended the Tensor Core line into the major public cloud.
