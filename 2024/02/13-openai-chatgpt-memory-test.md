# OpenAI tests memory for ChatGPT

- **Date:** 2024-02-13
- **Who:** OpenAI
- **Type:** product

OpenAI began a limited test of memory in ChatGPT, rolled out to a small group of Free and Plus users. ChatGPT could save details from conversations or when asked to remember something, and users could view, delete or disable memories, or use temporary chats that do not use memory. It mattered because it was the first step toward a chatbot that keeps persistent user context across sessions.
