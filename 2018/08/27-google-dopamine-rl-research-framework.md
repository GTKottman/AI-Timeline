# Google Brain releases Dopamine, a TensorFlow framework for reinforcement learning research

- **Date:** 2018-08-27
- **Who:** Google Brain (Pablo Samuel Castro, Marc G. Bellemare)
- **Type:** software

Google Brain released Dopamine, a TensorFlow framework for reinforcement learning research. It was built to be adaptable, stable and reproducible, so that researchers at any experience level can rerun and compare agents on the same footing. It gave the RL community a small, reproducible baseline codebase, a common need in a field where results often failed to replicate.
