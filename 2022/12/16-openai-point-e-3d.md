# OpenAI Point-E: text-to-3D point clouds

- **Date:** 2022-12-16
- **Who:** OpenAI
- **Type:** model

OpenAI released Point-E, which generates 3D point clouds from text prompts in a couple of minutes on a GPU. It worked by generating a single image first and then a 3D point cloud conditioned on that image.
