# Google launches Gemini 3.1 Flash Live audio model

- **Date:** 2026-03-26
- **Who:** Google DeepMind
- **Type:** model

Gemini 3.1 Flash Live is a low-latency audio-to-audio model that processes speech natively rather than through a text step, with support for over 90 languages. Google reports 90.8% on ComplexFuncBench Audio for multi-step function calling from spoken commands. It is in preview through the Gemini Live API and powers upgraded Gemini Live and Search Live, which expanded to more than 200 countries.
