# InstructGPT released as OpenAI's default API model

- **Date:** 2022-01-27
- **Who:** OpenAI
- **Type:** model

OpenAI announced that InstructGPT, a GPT-3 model tuned with human feedback on instruction following, is now the default language model on its API. In OpenAI's comparison, labelers preferred outputs from the 1.3B InstructGPT model over those of the 175B GPT-3 model. The InstructGPT method is the direct technical predecessor of ChatGPT.
