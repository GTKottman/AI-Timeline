# OpenAI releases Jukebox music generation model

- **Date:** 2020-04-30
- **Who:** OpenAI
- **Type:** model

OpenAI announced Jukebox, a neural network that generates music with rudimentary singing across many genres and artist styles. It is trained on 1.2 million songs with lyrics and metadata, and uses a VQ-VAE-style audio compressor with autoregressive upsampling to raw audio. OpenAI open-sourced the code and pretrained weights, and it became a widely cited example of raw-audio generative modeling.
