# OpenAI introduces CriticGPT to find errors in ChatGPT code

- **Date:** 2024-06-27
- **Who:** OpenAI (paper co-authored by Jan Leike)
- **Type:** research

OpenAI introduced CriticGPT, a GPT-4-based model trained to critique ChatGPT responses and point out bugs in its code, to help human trainers during RLHF labelling. In OpenAI's tests, model-written critiques were preferred over human critiques 63% of the time on code with naturally occurring LLM errors. The accompanying paper, "LLM Critics Help Catch LLM Bugs," described AI-assisted human feedback as a route to scalable oversight.
