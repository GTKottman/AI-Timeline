# Class action lawsuit filed against GitHub Copilot

- **Date:** 2022-11-03
- **Who:** Matthew Butterick and the Joseph Saveri Law Firm (plaintiffs); defendants GitHub, Microsoft and OpenAI
- **Type:** policy

A proposed class action was filed in US federal court in San Francisco against GitHub, Microsoft and OpenAI over the Copilot code assistant. The plaintiffs argued Copilot reproduces licensed open-source code without attribution or license notices, and reported damages claims of at least $9 billion. It was one of the first major copyright suits over code and model training data, and most of its claims were dismissed in 2024.
