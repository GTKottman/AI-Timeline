# Google open-sources DeepLab-v3+ for semantic image segmentation

- **Date:** 2018-03-12
- **Who:** Google Research
- **Type:** software

Google Research open-sourced DeepLab-v3+, its best-performing semantic segmentation model, in TensorFlow. The release included training and evaluation code plus models pretrained on Pascal VOC 2012 and Cityscapes. The model adds a decoder that sharpens segmentation boundaries and uses depthwise separable convolution, and it gave researchers and developers a strong ready-made segmentation baseline.
