# Microsoft launches new Bing and Edge with ChatGPT-class OpenAI model

- **Date:** 2023-02-07
- **Who:** Microsoft / OpenAI
- **Type:** product

Microsoft launched a new Bing search with a chat mode built on a next-generation OpenAI model customized for search, with limited access at launch. It was the first large-scale put of a frontier chatbot into a major search engine and forced Google to accelerate its own plans.
