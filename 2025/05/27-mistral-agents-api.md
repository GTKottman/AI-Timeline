# Mistral Agents API

- **Date:** 2025-05-27
- **Who:** Mistral AI
- **Type:** product

Mistral AI launched the Agents API, a layer over its chat completion API for building agents with built-in connectors for code execution (in a sandbox), web search, image generation and MCP tools. It adds persistent memory across conversations and conversation-state management. At launch it ran on mistral-medium-latest and mistral-large-latest.
