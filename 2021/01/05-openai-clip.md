# OpenAI introduces CLIP vision-language model

- **Date:** 2021-01-05
- **Who:** OpenAI
- **Type:** model

OpenAI introduced CLIP, a neural network trained on image and text pairs from the internet to learn visual concepts from natural language supervision. It classifies images zero-shot from text labels and became a core component of later text-to-image systems. It was released the same day as DALL-E.
