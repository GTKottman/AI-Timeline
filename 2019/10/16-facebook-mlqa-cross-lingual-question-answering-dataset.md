# Facebook AI releases MLQA, a cross-lingual question answering benchmark

- **Date:** 2019-10-16
- **Who:** Facebook AI Research (Patrick Lewis, Barlas Oğuz, Ruty Rinott, Sebastian Riedel, Holger Schwenk); UCL for Riedel
- **Type:** dataset

MLQA is an extractive question answering benchmark across seven languages (English, Arabic, German, Spanish, Hindi, Vietnamese, Simplified Chinese), with parallel Wikipedia-based instances. It tests cross-lingual transfer, where a model trained in English answers questions in another language, and a harder variant mixing question and context languages. The paper found transfer performance well behind training-language performance. The data and evaluation script were released on GitHub in SQuAD format.
