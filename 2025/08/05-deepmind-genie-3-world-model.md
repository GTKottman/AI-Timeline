# Google DeepMind unveils Genie 3 real-time world model

- **Date:** 2025-08-05
- **Who:** Google DeepMind
- **Type:** model

Genie 3 is a general-purpose world model that generates interactive environments from text prompts that users can move through in real time. Text-based "promptable world events" can change the weather or objects inside a generated world. It renders at 720p and keeps scenes consistent for a few minutes, and it was offered first as a limited research preview.
