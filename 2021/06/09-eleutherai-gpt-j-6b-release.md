# EleutherAI releases GPT-J-6B

- **Date:** 2021-06-09
- **Who:** EleutherAI
- **Type:** model

EleutherAI released GPT-J-6B, a 6-billion-parameter language model trained on The Pile with Mesh Transformer JAX, under the Apache 2.0 licence. It was one of the largest freely available GPT-style models at the time and became a common base for open-source experiments.
