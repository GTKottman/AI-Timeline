# Apple releases MLX open-source array framework for Apple silicon

- **Date:** 2023-12-05
- **Who:** Apple
- **Type:** software

Apple released MLX, an open-source array framework for Apple silicon, with a NumPy-like Python API and a C++ API. Its arrays live in unified memory, so they can move between CPU and GPU without copying. It was pitched as a toolkit for training, fine-tuning and running transformer models on Apple chips. The early-December 2023 release date is taken from press coverage; the exact day was not confirmed from Apple's post.
