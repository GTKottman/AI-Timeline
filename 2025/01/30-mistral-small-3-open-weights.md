# Mistral releases Mistral Small 3 as open weights

- **Date:** 2025-01-30
- **Who:** Mistral AI
- **Type:** model

Mistral AI released Mistral Small 3, a 24-billion-parameter model built for fast responses, with both pretrained and instruction-tuned versions under the Apache 2.0 license. Open weights at that size made it easy for developers to run locally.
