# Google releases Tensor2Tensor library for reproducible deep learning research

- **Date:** 2017-06-19
- **Who:** Google Brain (Łukasz Kaiser and team)
- **Type:** software

Google open-sourced Tensor2Tensor, a TensorFlow library of models, datasets, hyperparameters and training setups for sequence tasks. It shipped with the best models from recent papers, including the Transformer from "Attention Is All You Need," so that results could be reproduced and compared easily. It mattered because it packaged the newly published Transformer into a shared, runnable toolkit.
