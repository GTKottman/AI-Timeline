# Google open-sources BERT

- **Date:** 2018-11-02
- **Who:** Google AI Language (Jacob Devlin, Ming-Wei Chang)
- **Type:** model

Google released the TensorFlow code and pre-trained BERT-Base and BERT-Large checkpoints, both cased and uncased, on GitHub with a Colab notebook. BERT pre-trains a bidirectional Transformer, and the paper reported top results on 11 NLP tasks including SQuAD v1.1. Open weights let any team fine-tune state-of-the-art language models on one GPU or TPU, and BERT became a foundation for much later NLP work.
