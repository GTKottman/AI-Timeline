# Anthropic reports AI-orchestrated Chinese state espionage campaign using Claude Code

- **Date:** 2025-11-13
- **Who:** Anthropic; attributed to Chinese state-backed group GTG-1002
- **Type:** research

Anthropic said it disrupted a cyber-espionage campaign, detected in mid-September 2025, in which attackers used Claude Code as the main execution agent against about 30 organizations. Anthropic said only a small number of intrusions succeeded. Security researchers questioned how autonomous the attack really was.
