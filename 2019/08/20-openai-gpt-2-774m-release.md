# OpenAI releases the 774M-parameter GPT-2 model

- **Date:** 2019-08-20
- **Who:** OpenAI
- **Type:** model

OpenAI released a mid-sized GPT-2 model with 774 million parameters, about half the size of the full model. It was part of the staged release plan announced in February. It was the first step of the staged release OpenAI had described in February.
