# Microsoft Kosmos-1 multimodal language model

- **Date:** 2023-03-02
- **Who:** Microsoft Research
- **Type:** model

Microsoft unveiled Kosmos-1, a multimodal large language model trained from scratch on interleaved text and image data. The paper ("Language Is Not All You Need: Aligning Perception with Language Models") claimed it could follow instructions, learn in context, and handle visual tasks such as image description and visual IQ-style puzzles. It mattered as an early example of a language model that treats images as native input rather than a bolted-on add-on. Reporting dates the reveal to the start of March; the arXiv paper ID (2302.14045) points to a late-February posting, so treat the day as approximate.
