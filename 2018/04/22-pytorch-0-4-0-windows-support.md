# PyTorch 0.4.0 released with Windows support

- **Date:** 2018-04-22
- **Who:** Facebook AI Research and PyTorch community
- **Type:** software

PyTorch 0.4.0 merged the Variable and Tensor classes, deprecated the volatile flag, and added Windows support. The official migration guide is dated April 22, 2018, and press coverage followed on April 25. Windows builds were offered as Conda binaries and pip wheels for Python 3.5 and 3.6, without distributed training at first.
