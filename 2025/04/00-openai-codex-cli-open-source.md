# OpenAI Codex CLI open-source coding agent

- **Date:** 2025-04-00
- **Who:** OpenAI
- **Type:** software

OpenAI released Codex CLI, a terminal coding agent that reads files, edits code and runs commands on the user's machine, and made it open source. It offers Suggest, Auto Edit and Full Auto approval modes, with Suggest as the default. The exact day in April 2025 is not confirmed: one source dates the launch to April 17, and the GitHub repository shows no launch date.
