# Google DeepMind launches AlphaGenome for DNA regulation

- **Date:** 2025-06-25
- **Who:** Google DeepMind
- **Type:** model

AlphaGenome is a DeepMind model that predicts how stretches of non-coding DNA, up to about 1 million base pairs, control gene activity, and how single-letter variants can disrupt that control. It launched as a preprint, a blog post and a non-commercial API preview. It mattered because it covers many genome-regulation tasks in one model.
