# DeepSeek starts Open Source Week with FlashMLA

- **Date:** 2025-02-24
- **Who:** DeepSeek
- **Type:** software

DeepSeek began a week of releasing one open-source infrastructure repository each day. Day 1 was FlashMLA, a decoding kernel for NVIDIA Hopper GPUs for variable-length sequences. The later days covered DeepEP, a communication library for mixture-of-experts training and inference, and DeepGEMM, an FP8 matrix-multiply library. Sources differ on the full list of five, which includes releases such as 3FS and DualPipe. The week ran until February 28, 2025.
