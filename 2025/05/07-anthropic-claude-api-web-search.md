# Anthropic adds web search to the Claude API

- **Date:** 2025-05-07
- **Who:** Anthropic
- **Type:** product

Anthropic launched a web search tool in the Claude API, letting Claude retrieve current information from the web and cite its sources. Claude decides when to search and can run several searches in sequence, and admins can allow or block domains. It was priced at $10 per 1,000 searches plus token costs.
