# Google opens PaLM API and MakerSuite to developers

- **Date:** 2023-03-14
- **Who:** Google
- **Type:** product

Google opened its PaLM large language model to developers through a private-preview API and a prototyping tool called MakerSuite. The PaLM API went to select developers in a private preview with a waitlist to follow, and MakerSuite was released as a low-code prototyping tool.
