# Google updates Open Images dataset with bounding-box annotations

- **Date:** 2017-07-20
- **Who:** Google Research
- **Type:** dataset

Google released an update to its Open Images dataset, now with bounding-box annotations for objects, giving researchers localized labels for a large, openly licensed image collection. Bounding boxes are needed to train and evaluate object detectors, so the update made the dataset useful for detection research. It mattered because it added a large public detection training resource.
