# AAIA'17 Data Mining Challenge opens

- **Date:** 2017-03-23
- **Who:** AAIA'17 organizers, FedCSIS 2017 conference
- **Type:** competition

The AAIA'17 Data Mining Challenge, run alongside the FedCSIS 2017 conference, released its data and task descriptions on March 23, 2017, with prediction submissions due May 14. The first prize was 1000 USD plus conference registration. It was a general data mining contest rather than a deep learning benchmark, but it gave researchers a public benchmark on that date.
