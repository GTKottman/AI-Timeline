# Alibaba releases Ovis Image

- **Date:** 2025-11-29
- **Who:** Alibaba (AIDC-AI)
- **Type:** model

Alibaba's AIDC-AI team released Ovis-Image, an open-weight 7B text-to-image model optimized for high-quality text rendering.
