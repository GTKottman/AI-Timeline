# OpenAI launches ChatGPT agent

- **Date:** 2025-07-17
- **Who:** OpenAI
- **Type:** product

OpenAI launched ChatGPT agent, a mode in which ChatGPT uses its own virtual computer to carry out multi-step tasks. It combined the web-clicking of Operator with the multi-site research of Deep Research. Rollout began for Pro, Plus and Team subscribers, with Enterprise and Edu to follow. It mattered as OpenAI's first general-purpose agent inside ChatGPT.
