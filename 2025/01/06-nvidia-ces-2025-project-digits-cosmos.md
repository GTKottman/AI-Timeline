# NVIDIA at CES 2025: Project DIGITS, Cosmos and GeForce RTX 50

- **Date:** 2025-01-06
- **Who:** NVIDIA
- **Type:** hardware

In its CES 2025 keynote NVIDIA announced Project DIGITS, a desktop AI machine built on the GB10 Grace Blackwell Superchip, aimed at running large models locally. Sources give a $3,000 price and say it can run models up to 200 billion parameters. It also announced Cosmos, a world foundation model platform for physical AI such as robots and autonomous vehicles, and the GeForce RTX 50 series. The keynote took place on January 6, 2025, Las Vegas time.
