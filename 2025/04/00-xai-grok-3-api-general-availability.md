# xAI makes Grok 3 generally available through its API

- **Date:** 2025-04-00
- **Who:** xAI
- **Type:** product

xAI's API release notes list "Grok 3 models launch on API" under April 2025 and say the Grok 3 flagship models are now generally available via the API. The release notes give no day. Coverage conflicts: one aggregator says April 3, 2025, while Seeking Alpha reported the launch on April 10, 2025.
