# Midjourney releases Version 6.1

- **Date:** 2024-07-31
- **Who:** Midjourney
- **Type:** model

Midjourney V6.1 improved image coherence, anatomy and text in images over V6, and was the default model for many users. It kept Midjourney ahead on image quality among consumer image tools.
