# DeepSeek releases V3.2-Exp with sparse attention and cuts API prices

- **Date:** 2025-09-29
- **Who:** DeepSeek
- **Type:** model

DeepSeek released V3.2-Exp, an experimental open-weight model built on V3.1-Terminus that adds DeepSeek Sparse Attention. A lightning indexer ranks the parts of a long context, and attention then runs over the top relevant tokens, which cuts the cost of long-context inference. DeepSeek says it performs on par with V3.1-Terminus across public benchmarks and cut its API prices by more than half. It was released under an MIT licence, and DeepSeek called it an intermediate step toward its next architecture.
