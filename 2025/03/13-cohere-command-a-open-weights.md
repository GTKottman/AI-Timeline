# Cohere Command A

- **Date:** 2025-03-13
- **Who:** Cohere
- **Type:** model

Cohere released Command A, a 111-billion-parameter model with a 256K context window that Cohere says runs on as few as two GPUs. Weights are on Hugging Face under a CC-BY-NC license, which is non-commercial, so commercial use is not permitted under that license.
