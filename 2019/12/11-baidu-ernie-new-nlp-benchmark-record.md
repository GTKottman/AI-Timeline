# Baidu's ERNIE pretrained model reports a new NLP benchmark record

- **Date:** 2019-12-11
- **Who:** Baidu
- **Type:** model

Baidu reported that its ERNIE pretrained language model reached a new record on NLP benchmarks, extending its earlier ERNIE 1.0 and ERNIE 2.0 releases. Only the headline and the Synced Review write-up were checked for this entry, so the benchmark details are unverified.
