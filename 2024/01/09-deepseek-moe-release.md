# DeepSeek releases DeepSeek-MoE open models

- **Date:** 2024-01-09
- **Who:** DeepSeek
- **Type:** model

DeepSeek released DeepSeek-MoE base and chat models, a mixture-of-experts design that activates only part of its parameters per token. It was one of the first open releases from the Chinese lab that later drew wide attention.
