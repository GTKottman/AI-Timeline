# Anthropic open-sources the Model Context Protocol (MCP)

- **Date:** 2024-11-25
- **Who:** Anthropic
- **Type:** software

Anthropic open-sourced the Model Context Protocol, an open standard for connecting AI assistants to data sources and tools. The release came with the protocol spec, Python and TypeScript SDKs, local MCP server support in the Claude desktop apps, and reference servers for Google Drive, Slack, GitHub, Git, Postgres and Puppeteer. It mattered because it gave every model and tool one common connector instead of a custom integration per pair.
