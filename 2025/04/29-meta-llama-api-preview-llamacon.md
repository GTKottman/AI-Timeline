# Meta announces the Llama API in limited preview at LlamaCon

- **Date:** 2025-04-29
- **Who:** Meta
- **Type:** product

At its first LlamaCon developer event, Meta launched the Llama API in limited preview. It is free during the preview but needs a waitlist place, and it covers Llama 4 Scout and Maverick, with tools for fine-tuning and evaluation. It is compatible with the OpenAI SDK and has Python and TypeScript SDKs. Meta had not disclosed pricing, and cited more than 1.2 billion Llama downloads.
