# Google releases TensorFlow 2.0

- **Date:** 2019-09-30
- **Who:** Google TensorFlow team
- **Type:** software

TensorFlow 2.0 became generally available, with Keras as the high-level API, eager execution on by default, and a more flexible low-level API. The release also claimed up to 3x faster training with mixed precision on Volta and Turing GPUs. It was a major simplification of the most widely used deep learning framework.
