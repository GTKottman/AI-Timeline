# DeepMind Sparrow: a dialogue agent trained to be helpful and safe

- **Date:** 2022-09-28
- **Who:** DeepMind
- **Type:** model

DeepMind posted the Sparrow paper describing an information-seeking dialogue agent trained with targeted human judgements. It was designed to be more helpful, correct and harmless than a prompted baseline and to cite evidence for its claims.
