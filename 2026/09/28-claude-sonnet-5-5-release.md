# Anthropic releases Claude Sonnet 5.5

- **Date:** 2026-09-28
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude Sonnet 5.5, which Anthropic said is up to 30% faster than Sonnet 5 and up to 30% lower in cost per task. Pricing stayed at $2 per million input tokens and $10 per million output tokens.
