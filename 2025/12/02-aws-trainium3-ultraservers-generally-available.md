# AWS makes Trainium3 UltraServers generally available

- **Date:** 2025-12-02
- **Who:** Amazon Web Services; Anthropic and other early customers named
- **Type:** hardware

At AWS re:Invent, Amazon made Trainium3 UltraServers generally available, built on its 3nm Trainium3 chip. AWS claims up to 4.4x more compute than Trainium2 UltraServers and about 4x better energy efficiency, with systems scaling to 144 chips. AWS also previewed Trainium4, which it said would work alongside Nvidia NVLink Fusion. The launch matters because it puts a second non-Nvidia training and inference platform at scale in the largest cloud.
