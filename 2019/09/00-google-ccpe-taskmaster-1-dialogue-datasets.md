# Google Releases CCPE and Taskmaster-1 Dialogue Datasets

- **Date:** 2019-09-00
- **Who:** Google
- **Type:** dataset

Google released two natural language dialogue datasets in September 2019: Coached Conversational Preference Elicitation (CCPE), for learning user preferences through conversation, and Taskmaster-1, a task-oriented dialogue dataset. Open datasets like these help researchers train and benchmark conversational AI systems. The source reports the month only, so the exact day is not recorded.
