# tf-seq2seq: open-source sequence-to-sequence framework for TensorFlow

- **Date:** 2017-04-11
- **Who:** Google Brain
- **Type:** software

Google Brain released tf-seq2seq, an open-source sequence-to-sequence framework in TensorFlow for experimenting with encoder-decoder models. It exposes configurable options such as encoder and decoder depth, attention mechanism, RNN cell type and beam size. It was pitched for machine translation, summarization, image captioning, speech recognition and conversation modeling, with preprocessed data and tutorials. The code went to GitHub under google/seq2seq.
