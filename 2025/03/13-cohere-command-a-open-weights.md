# Cohere Command A

- **Date:** 2025-03-13
- **Who:** Cohere
- **Type:** model

Cohere released Command A, a 111-billion-parameter model with a 256K context window that Cohere says runs on as few as two GPUs. Cohere claimed it matched or beat GPT-4o and DeepSeek-V3 on enterprise tasks. Weights were published on Hugging Face under a non-commercial license, which Simon Willison noted made it open weights but not open source.
