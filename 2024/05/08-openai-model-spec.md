# OpenAI publishes the Model Spec

- **Date:** 2024-05-08
- **Who:** OpenAI
- **Type:** research

OpenAI published the first draft of its Model Spec, a public document setting out the objectives, rules and default behaviors it wants its models to follow in the API and ChatGPT. It was framed as a way to make model behavior legible and to gather public feedback on how models should handle conflicts between instructions and safety. It was an early public written model-behavior framework from a major lab.
