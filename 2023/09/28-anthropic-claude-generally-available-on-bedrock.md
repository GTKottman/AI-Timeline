# Claude becomes generally available on Amazon Bedrock

- **Date:** 2023-09-28
- **Who:** Anthropic; Amazon Web Services
- **Type:** product

Anthropic announced that Claude was generally available on Amazon Bedrock, so any AWS customer could build with Claude through AWS. The launch followed Amazon's expanded investment in Anthropic announced days earlier. It put a frontier model from a second lab into a managed cloud service for foundation models. Agents for Amazon Bedrock were still in preview at the time.
