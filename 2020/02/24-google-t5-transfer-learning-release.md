# Google Research explains T5 and releases its code and pre-trained models

- **Date:** 2020-02-24
- **Who:** Google Research; Adam Roberts, Colin Raffel (with Noam Shazeer, Katherine Lee and others)
- **Type:** model

Google Research published a blog post on T5, the Text-To-Text Transfer Transformer, which frames every NLP task as text in, text out. The post introduced the C4 pre-training corpus and said the code and pre-trained models were released. The underlying paper (arXiv 1910.10683) was posted in October 2019. T5-Base and T5-Large became widely used transfer learning baselines.
