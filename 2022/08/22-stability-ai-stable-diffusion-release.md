# Stability AI releases Stable Diffusion as open weights

- **Date:** 2022-08-22
- **Who:** Stability AI (with CompVis and Runway researchers)
- **Type:** model

Stability AI released Stable Diffusion, a latent text-to-image diffusion model whose source code and weights were publicly available. Because anyone could run it on a consumer GPU, it spread quickly and began a wave of open image-generation tools and fine-tuned models.
