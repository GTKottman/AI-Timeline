# TensorFlow 1.2 release brings tf.keras into core TensorFlow

- **Date:** 2017-06-14
- **Who:** Google (TensorFlow team)
- **Type:** software

TensorFlow 1.2 shipped the Keras API inside core TensorFlow as tf.keras, as the Keras 2 announcement had promised. The release also added tf.layers.conv3d_transpose, tf.Session.make_callable() for lower-overhead repeated execution and a SavedModel CLI, and moved RNN cells onto tf.layers.Layer. It mattered because it made the most-used high-level API a built-in part of the main deep learning framework.
