# CycleGAN: unpaired image-to-image translation

- **Date:** 2017-03-30
- **Who:** Jun-Yan Zhu, Taesung Park, Phillip Isola, Alexei A. Efros (UC Berkeley, Berkeley AI Research)
- **Type:** paper

arXiv preprint that translates images from one domain to another without paired training examples. It combines two adversarial losses with a cycle-consistency loss, so translating to the other domain and back recovers the original image. Applications included collection style transfer, object transfiguration, season change and photo enhancement. The official code is on GitHub.
