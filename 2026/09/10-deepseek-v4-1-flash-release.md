# DeepSeek releases V4.1-Flash, a multimodal model

- **Date:** 2026-09-10
- **Who:** DeepSeek
- **Type:** model

DeepSeek released V4.1-Flash, a multimodal mixture-of-experts model that accepts image input, with a 1M-token context window. A limited beta ran before the official release.
