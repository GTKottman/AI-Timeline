# DeepSeek releases DeepSeek-Coder-V2 open-source code model

- **Date:** 2024-06-00
- **Who:** DeepSeek
- **Type:** model

DeepSeek released DeepSeek-Coder-V2, an open-source Mixture-of-Experts code model continued from an intermediate DeepSeek-V2 checkpoint on about 6 trillion more tokens. The paper reports 90.2% on HumanEval, 76.2% on MBPP+ and 43.4% on LiveCodeBench,. Sources confirm the month (June 2024) but not the exact day, so the day is set to 00 until the release date is checked against the model card.
