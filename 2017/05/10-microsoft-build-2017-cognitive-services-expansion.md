# Microsoft Build 2017: Cognitive Services expand to 29 services with custom training

- **Date:** 2017-05-10
- **Who:** Microsoft
- **Type:** product

At Build 2017 Microsoft grew Cognitive Services to 29 APIs by adding Custom Vision Service, Video Indexer, Custom Decision Service and Bing Custom Search, all in public preview. The main idea was letting developers train Microsoft's algorithms on their own data. Microsoft also opened the Cognitive Services Labs for experimental services and previewed Azure Batch AI Training for deep neural networks. It mattered because it moved custom model training into a managed cloud API.
