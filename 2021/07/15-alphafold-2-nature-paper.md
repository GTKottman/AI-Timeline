# DeepMind publishes AlphaFold 2 in Nature

- **Date:** 2021-07-15
- **Who:** DeepMind
- **Type:** research

DeepMind published AlphaFold 2 in Nature, with its source code released. The system predicted protein structures at near-experimental accuracy, which solved a long-standing problem in biology. It showed that deep learning could make a core scientific breakthrough.
