# Microsoft unveils Azure AI supercomputer built for OpenAI

- **Date:** 2020-05-19
- **Who:** Microsoft, OpenAI
- **Type:** hardware

At its online Build 2020 conference, Microsoft unveiled an Azure-hosted supercomputer built in collaboration with OpenAI and used exclusively for OpenAI's large model training. Microsoft cited more than 285,000 CPU cores and 10,000 GPUs. CTO Kevin Scott said it was probably about the fifth most powerful machine in the world, and Microsoft did not submit it to the TOP500 list. The system was the compute base on which OpenAI later trained GPT-3, tying the 2019 Microsoft investment to the scale of the models that followed.
