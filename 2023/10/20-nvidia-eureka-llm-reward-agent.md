# NVIDIA Research unveils Eureka, a GPT-4 agent that writes robot reward code

- **Date:** 2023-10-20
- **Who:** NVIDIA Research
- **Type:** research

NVIDIA Research introduced Eureka, a GPT-4-powered agent that writes reward functions for reinforcement learning from environment source code and a task description. It iterates through reward sampling, GPU-accelerated evaluation and reflection on training statistics. NVIDIA reported that its reward programs beat expert-written ones across 29 tasks on 10 robot platforms, and a simulated Shadow Hand learned to spin a pen. The code was released for use with the Isaac Gym simulator.
