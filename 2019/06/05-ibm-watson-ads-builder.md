# IBM launches Watson Ads Builder, an AI self-service ad tool

- **Date:** 2019-06-05
- **Who:** IBM (Watson)
- **Type:** product

IBM launched Watson Ads Builder, a self-service advertising product that uses natural language processing and generation to build one-on-one conversational ads from a brand's own content. Agencies and developers can ingest brand information and generate consumer-specific dialogue without writing code. Launch date is taken from IBM's press release datelined June 5, 2019; other outlets report June 3 or June 12.
