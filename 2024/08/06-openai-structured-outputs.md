# OpenAI launches Structured Outputs in the API

- **Date:** 2024-08-06
- **Who:** OpenAI
- **Type:** product

OpenAI added Structured Outputs, which makes model output follow a developer-supplied JSON Schema reliably, where the earlier JSON mode only guaranteed valid JSON. It came as a json_schema option in response_format for gpt-4o-2024-08-06 and as strict mode on function calls. OpenAI reported 100% schema adherence on its complex-schema evals against under 40% for gpt-4-0613, a company-run result.
