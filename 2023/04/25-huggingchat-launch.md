# Hugging Face launches HuggingChat

- **Date:** 2023-04-25
- **Who:** Hugging Face (built on the OpenAssistant project, LAION)
- **Type:** product

Hugging Face launched HuggingChat, an open-source chat interface built on the OpenAssistant model, as a free rival to ChatGPT. At launch it stored no chat data and had no user accounts; Hugging Face called it an early v0 prototype. It mattered as an open, hosted chat product built on openly trained weights.
