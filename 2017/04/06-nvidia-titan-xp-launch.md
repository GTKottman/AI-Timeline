# NVIDIA Titan Xp launch

- **Date:** 2017-04-06
- **Who:** NVIDIA
- **Type:** hardware

NVIDIA launched the Titan Xp at $1,199, a Pascal GPU with 12 GB of GDDR5X memory and 3840 CUDA cores. NVIDIA marketed it heavily for deep learning researchers rather than gamers. It was a common workstation GPU for training neural networks in 2017.
