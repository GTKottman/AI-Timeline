# PyTorch Developer Day 2020 held virtually

- **Date:** 2020-11-12
- **Who:** PyTorch (Facebook AI)
- **Type:** other

PyTorch held a virtual Developer Day on November 12, 2020 for researchers and developers. It had talks on core framework updates and new tools and libraries, plus a poster session. All talks were livestreamed to the public, while networking was invitation-only.
