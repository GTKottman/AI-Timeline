# OpenAI's Glow: generative flow with invertible 1x1 convolutions

- **Date:** 2018-07-09
- **Who:** Diederik P. Kingma, Prafulla Dhariwal (OpenAI)
- **Type:** model

Glow is a flow-based generative model built on invertible 1x1 convolutions. It improved log-likelihood on standard benchmarks and could synthesise and edit realistic large images. It showed that exact-likelihood generative models could produce high-quality faces, giving an alternative to GANs.
