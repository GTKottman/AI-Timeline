# Baidu launches Project Apollo open autonomous driving platform

- **Date:** 2017-04-19
- **Who:** Baidu
- **Type:** software

Baidu announced Project Apollo, an open platform for self-driving cars, and said it would open source code for perception, trajectory planning, vehicle control, the vehicle operating system and testing tools. The package also included hardware, a vehicle platform and cloud data services. Opening the stack gave outside developers and automakers a shared base for autonomous driving research.
