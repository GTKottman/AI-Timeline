# OpenAI releases SimpleQA, an open factuality benchmark

- **Date:** 2024-10-30
- **Who:** OpenAI
- **Type:** dataset

OpenAI released SimpleQA, an open-source benchmark of 4,326 short, fact-seeking questions with single correct answers, designed to measure hallucination in language models. Each answer is graded as correct, incorrect or not attempted, so the benchmark also tests whether a model knows when to abstain. At release, the best model scored under 43 percent, which showed how hard reliable factual recall remained. A later Google paper found label errors and introduced a cleaned variant.
