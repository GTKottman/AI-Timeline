# OpenAI retires GPT-4o from ChatGPT

- **Date:** 2026-02-13
- **Who:** OpenAI
- **Type:** product

OpenAI removed GPT-4o from ChatGPT on February 13, 2026, along with several other older models. OpenAI had announced the change on January 29. The API was not changed.
