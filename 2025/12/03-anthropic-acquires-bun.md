# Anthropic acquires Bun JavaScript runtime

- **Date:** 2025-12-03
- **Who:** Anthropic; Bun
- **Type:** acquisition

Anthropic said it is acquiring Bun, the JavaScript runtime, to speed up development of Claude Code. Claude Code had reached $1 billion in run-rate revenue in November. Bun will remain open source under the MIT license. Financial terms were not disclosed.
