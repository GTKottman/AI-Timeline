# Baidu releases ERNIE 1.0 pretrained language model

- **Date:** 2019-03-16
- **Who:** Baidu (PaddlePaddle team)
- **Type:** model

Baidu released ERNIE 1.0, an open-source pretrained language model that learns from knowledge integration such as entities and phrases, not just masked words. It was among the first open-source pretrained NLP models from a major Chinese company. The improved ERNIE 2.0 followed in July 2019. The model is built on Baidu's PaddlePaddle framework.
