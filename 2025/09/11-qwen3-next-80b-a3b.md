# Alibaba Qwen3-Next-80B-A3B released

- **Date:** 2025-09-11
- **Who:** Alibaba (Qwen team)
- **Type:** model

Alibaba released Qwen3-Next-80B-A3B as open-weight models, with separate Instruct and Thinking variants. The model has 80 billion total parameters and about 3 billion active per token, and uses a hybrid attention design rather than standard attention alone. Its native context window is 262,144 tokens, extensible to 1 million with YaRN. One source dates the release to September 11, 2025.
