# BDD100K driving video dataset released

- **Date:** 2018-05-30
- **Who:** UC Berkeley BAIR (Fisher Yu and collaborators); Nexar (supplied the data); Berkeley DeepDrive Industry Consortium
- **Type:** dataset

BDD100K is a crowdsourced database of 100,000 driving videos, each about 40 seconds at 720p and 30 fps, with phone GPS/IMU trajectories. Annotations include image tags, object boxes, drivable areas, lane markings and full-frame instance segmentation, covering multiple tasks for multitask learning (arXiv:1805.04687). The footage spans varied geography, weather, and day and night driving, which made it a large public benchmark for self-driving perception.
