# Anthropic names Accenture as first embedded independent evaluator

- **Date:** 2026-09-18
- **Who:** Anthropic; Accenture
- **Type:** other

Anthropic announced that Accenture would be its first embedded independent evaluator, with permanent access to test its models. It was a step toward third-party evaluation built into frontier-lab release processes.
