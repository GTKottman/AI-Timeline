# Arm unveils Project Trillium machine learning processors

- **Date:** 2018-02-13
- **Who:** Arm
- **Type:** hardware

Arm announced Project Trillium, a suite of processor IP with a dedicated ML processor rated at 4.6 TOPS (3 TOPS per watt) and a second-generation object detection processor. Its neural network software supports frameworks such as TensorFlow, Caffe and Android NN. It was aimed first at mobile and other low-power devices.
