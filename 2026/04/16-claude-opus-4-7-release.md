# Anthropic releases Claude Opus 4.7

- **Date:** 2026-04-16
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude Opus 4.7, an upgrade over Opus 4.6 with the largest gains on the hardest software engineering tasks. It accepts images up to 2,576 pixels on the long edge and adds an xhigh effort level between high and max. Pricing stayed at $5 per million input tokens and $25 per million output tokens.
