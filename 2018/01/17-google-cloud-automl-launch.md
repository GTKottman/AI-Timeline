# Google launches Cloud AutoML

- **Date:** 2018-01-17
- **Who:** Google Cloud AI (Fei-Fei Li, Jia Li)
- **Type:** product

Google launched Cloud AutoML, starting with AutoML Vision in alpha, a service that builds custom image recognition models from user-uploaded data with little machine learning expertise. It uses transfer learning and neural architecture search. It was one of the first major cloud products aimed at automating model design.
