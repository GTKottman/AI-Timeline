# Runway announces Gen-2 text-to-video model

- **Date:** 2023-03-20
- **Who:** Runway
- **Type:** model

Runway announced Gen-2, a text-to-video model that could also start from an uploaded image, with access first through a waitlist run in a private Discord channel. The clips were only a few seconds long and rough in motion, but Bloomberg called it the most high-profile text-to-video generation outside a lab. By June 2023 it was broadly available in the browser and as an iOS app, making it one of the first commercial text-to-video tools.
