# Facebook AI publishes RoBERTa, a robustly optimized BERT

- **Date:** 2019-07-26
- **Who:** Facebook AI; University of Washington
- **Type:** paper

The RoBERTa paper showed that BERT was significantly undertrained. Training longer, with bigger batches and more data, removing next-sentence prediction, and using dynamic masking matched or beat every model published after BERT. It set state of the art on GLUE, RACE and SQuAD, and the models and code were released in fairseq.
