# OpenAI introduces DALL-E 3, text-to-image model with better prompt following

- **Date:** 2023-09-20
- **Who:** OpenAI
- **Type:** model

OpenAI introduced DALL-E 3, an image generator designed to follow detailed prompts more closely than earlier versions, built natively into ChatGPT. It launched as a research preview for ChatGPT Plus and Enterprise customers in October.
