# Microsoft announces Copilot+ PCs with on-device NPUs

- **Date:** 2024-05-20
- **Who:** Microsoft (with Qualcomm, Intel, AMD and PC partners)
- **Type:** hardware

Microsoft unveiled Copilot+ PCs, Windows laptops built around a CPU, GPU and an NPU rated at 40+ TOPS for running AI features on the device. The first machines used Qualcomm Snapdragon X Elite and X Plus, and the launch introduced Recall, which lets users search their past activity. It set a hardware baseline for local AI in consumer PCs.
