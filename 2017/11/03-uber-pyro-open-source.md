# Uber AI Labs open-sources Pyro probabilistic programming language

- **Date:** 2017-11-03
- **Who:** Uber AI Labs
- **Type:** software

Uber AI Labs released Pyro, a probabilistic programming language built on PyTorch, so researchers could write deep probabilistic models with stochastic inference. It combined PyTorch's dynamic graphs with Bayesian modelling. It became one of the main tools for probabilistic deep learning research.
