# Apple announces Core ML for on-device machine learning at WWDC 2017

- **Date:** 2017-06-00
- **Who:** Apple
- **Type:** software

Apple introduced Core ML at WWDC 2017, an API for running trained machine learning models directly on iPhone, iPad, Mac, Apple Watch and Apple TV. The framework defined a public .mlmodel file format for neural networks and tree ensembles, and it ran models on the device so user data did not have to leave it. It mattered because it gave millions of app developers a standard, on-device path for deploying AI models. The exact keynote day was not confirmed in the sources, so the day is recorded as 00.
