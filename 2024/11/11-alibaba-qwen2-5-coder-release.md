# Alibaba releases Qwen2.5-Coder series

- **Date:** 2024-11-11
- **Who:** Alibaba Cloud (Qwen team)
- **Type:** model

Qwen2.5-Coder is a series of open code models built on Qwen2.5, aimed at code generation and reasoning across many languages. It extended the open coding model options available to developers.
