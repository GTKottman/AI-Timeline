# Google Research publishes Grasp2Vec, self-supervised robot object representations

- **Date:** 2018-12-11
- **Who:** Google Research (Eric Jang and Coline Devin, with Vincent Vanhoucke and Sergey Levine)
- **Type:** research

Google Research explained Grasp2Vec, a method where a robot learns object embeddings from its own grasping attempts without human labels. The idea is that removing an object from a bin should change the scene embedding in a predictable way, so the difference between before and after scenes matches the grasped object. The learned embeddings support localizing a query object in an image and instance grasping, where the robot is shown a picture of the desired object and grasps the matching one.
