# AI21 Labs launches Jurassic-2 language models

- **Date:** 2023-03-09
- **Who:** AI21 Labs
- **Type:** model

AI21 Labs released Jurassic-2 in Large, Grande and Jumbo sizes, each with an instruction-tuned variant, and added task APIs for paraphrasing, summarizing, grammar checking and text segmentation. AI21 claimed faster response times than Jurassic-1 and support for several languages beyond English. It mattered as a commercial alternative to OpenAI's API for enterprises that wanted hosted models with instruction following. AI21 did not publish exact parameter counts.
