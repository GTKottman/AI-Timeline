# Anthropic acquires developer-tools startup Stainless

- **Date:** 2026-05-18
- **Who:** Anthropic; Stainless
- **Type:** acquisition

Anthropic acquired Stainless, a developer-tools startup whose SDK generation tools were used by OpenAI, Google and Cloudflare. The deal gave Anthropic control of API client tooling that many AI companies depend on.
