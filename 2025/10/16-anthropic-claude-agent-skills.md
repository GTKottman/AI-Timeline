# Anthropic launches Agent Skills for Claude

- **Date:** 2025-10-16
- **Who:** Anthropic
- **Type:** product

Anthropic launched Agent Skills, folders of instructions, scripts and resources that Claude loads only when a task calls for them. The same format works in the Claude apps, Claude Code and the API. Skills were offered to Pro, Max, Team and Enterprise users, with built-in ones for Excel, Word, PowerPoint and PDF tasks and support for custom uploads. Developers can use them through the Claude Agent SDK and the API.
