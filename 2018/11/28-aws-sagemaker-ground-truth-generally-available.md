# AWS makes SageMaker Ground Truth generally available

- **Date:** 2018-11-28
- **Who:** Amazon Web Services
- **Type:** product

At re:Invent 2018, AWS made SageMaker Ground Truth generally available. The service labels training data by combining human annotators (Mechanical Turk, vendors or the customer's own staff) with a model that learns from their labels and labels the rest. AWS claimed up to 70% lower labeling cost than human-only annotation. The same week it also made SageMaker RL and SageMaker Neo generally available. It mattered as a managed tool for the data-labeling step that most ML projects spend the most effort on.
