# Meta releases Muse Spark 1.2 and Muse Code terminal agent

- **Date:** 2026-08-05
- **Who:** Meta
- **Type:** model

On August 5, 2026 Meta released Muse Spark 1.2, a coding-focused update to Muse Spark 1.1 with a 1M-token context, alongside Muse Code, a terminal coding agent in beta for macOS and Linux. Muse Code runs persistent background agents that can fan out subagents and logs every model call and edit so work can resume after a crash. Meta reports 82.9% on Terminal-Bench 2.1 and 59.3% on DeepSWE v1.1, up from 76.2 and 53.0, measured in its own harness; DeepLearning.AI reports independent evaluations place it a notch below the frontier at lower cost per task.
