# Databricks releases Dolly 2.0, a commercially usable open instruction model

- **Date:** 2023-04-12
- **Who:** Databricks
- **Type:** model

Databricks released Dolly 2.0, a 12-billion-parameter model fine-tuned on a human-written instruction dataset its employees created. The weights, code and dataset were all released for commercial use, which made it a notable open alternative to closed chat models.
