# Report reveals Anthropic's Project Panama book-scanning effort

- **Date:** 2026-01-27
- **Who:** Anthropic
- **Type:** dataset

The Washington Post reported that Anthropic had run a large-scale project to buy and scan physical books for training data, after earlier litigation over pirated copies. It showed how labs were turning to lawful-acquisition paths for text corpora.
