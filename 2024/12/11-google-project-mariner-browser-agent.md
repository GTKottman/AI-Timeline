# Google unveils Project Mariner, a Chrome agent that uses the web for you

- **Date:** 2024-12-11
- **Who:** Google DeepMind
- **Type:** product

Google DeepMind unveiled Project Mariner, a research prototype built on Gemini 2.0 that runs as an experimental Chrome extension, moves the cursor, clicks and fills in forms. It works only within the active browser tab, and it requests user confirmation before sensitive actions. It was first limited to trusted testers, with a waitlist for others. Google said it scored 83.5% on the WebVoyager benchmark.
