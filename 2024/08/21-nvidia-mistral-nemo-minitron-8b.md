# Nvidia releases Mistral-NeMo-Minitron 8B small language model

- **Date:** 2024-08-21
- **Who:** Nvidia (base model from Mistral NeMo 12B)
- **Type:** model

Nvidia released Mistral-NeMo-Minitron 8B, a smaller model made by pruning the Mistral NeMo 12B base and retraining it with knowledge distillation. It ships as a NIM microservice with Hugging Face weights, and Nvidia positioned it to run on RTX-powered workstations. Nvidia says it leads on nine popular benchmarks for models of its size, a company-reported result.
