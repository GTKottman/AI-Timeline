# Meta releases BlenderBot 3 conversational AI

- **Date:** 2022-08-05
- **Who:** Meta AI
- **Type:** model

Meta AI released BlenderBot 3, a public chatbot built on the 175-billion-parameter OPT model, with model weights, code, datasets and model cards. Unlike BlenderBot 2 it can search the internet to discuss almost any topic, and it learns from live conversations and user feedback, filtering suspicious feedback. Meta said openly that it was "certainly not at a human level," and coverage soon reported offensive and false answers, which made the launch a public test of chatbot safety.
