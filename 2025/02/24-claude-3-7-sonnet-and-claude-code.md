# Anthropic releases Claude 3.7 Sonnet and Claude Code

- **Date:** 2025-02-24
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude 3.7 Sonnet, a hybrid model that could answer quickly or think step by step for longer. It shipped alongside Claude Code, a command-line tool that lets Claude read a codebase, edit files and run commands. Together they moved Anthropic toward agentic coding.
