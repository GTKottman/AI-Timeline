# TensorFlow 1.5 released with Eager Execution preview and TensorFlow Lite developer preview

- **Date:** 2018-01-26
- **Who:** Google (TensorFlow team)
- **Type:** software

TensorFlow 1.5 added a preview of Eager Execution, which runs operations immediately from Python instead of building a static graph first, and a developer preview of TensorFlow Lite for mobile and embedded devices. The release moved to CUDA 9 and cuDNN 7 binaries. Eager mode made TensorFlow easier to debug and closer to the imperative style researchers used in PyTorch.
