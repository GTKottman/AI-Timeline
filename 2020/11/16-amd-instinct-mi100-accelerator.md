# AMD launches Instinct MI100, its first CDNA accelerator for HPC and AI

- **Date:** 2020-11-16
- **Who:** AMD
- **Type:** hardware

AMD launched the Instinct MI100 at SC20 with ROCm 4.0. It was the first accelerator built on the new CDNA architecture, which AMD positioned for HPC and AI, and it claimed up to 46.1 TFLOPS of FP32 matrix performance for machine learning. AMD presented it as a rival to Nvidia's A100, and the performance figures were AMD's own claims.
