# Stability AI releases SDXL 1.0 as an open image model

- **Date:** 2023-07-26
- **Who:** Stability AI
- **Type:** model

Stability AI released SDXL 1.0, the full version of its open text-to-image model. The company said it runs on consumer GPUs with 8GB VRAM, and the model uses a base model plus a refinement model. Its code was released under the CreativeML Open RAIL++-M license.
