# OpenAI Releases GPT-5.5

- **Date:** 2026-04-23
- **Who:** OpenAI
- **Type:** model

OpenAI released GPT-5.5 (codename "Spud") for paid ChatGPT tiers and Codex, with API access to follow. OpenAI positioned it as its smartest model yet, aimed at multi-step coding, computer use, data analysis and research tasks with less direction, and said it is more token-efficient than GPT-5.4. The benchmark claims (such as 82.7% on Terminal-Bench 2.0) are OpenAI's own and were not independently checked.
