# Anthropic releases Claude Opus 4.8

- **Date:** 2026-05-28
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude Opus 4.8, an upgrade over Opus 4.7 with better benchmark results and fewer unsupported claims. API pricing stayed at $5 and $25 per million input and output tokens. Fast mode costs $10 and $50 per million tokens.
