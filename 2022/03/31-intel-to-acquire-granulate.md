# Intel to acquire Granulate

- **Date:** 2022-03-31
- **Who:** Intel; Granulate Cloud Solutions
- **Type:** acquisition

Intel agreed to buy Granulate, an Israeli maker of real-time optimization software for cloud and data-center workloads, announced March 31, 2022. Intel did not disclose the price. TechCrunch reported, citing sources, that the deal was about $650 million. The software tunes production workloads without code changes.
