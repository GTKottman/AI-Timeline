# 01.AI open-sources Yi-6B and Yi-34B base models

- **Date:** 2023-11-02
- **Who:** 01.AI
- **Type:** model

01.AI, founded by Kai-Fu Lee, open-sourced the base models Yi-6B and Yi-34B, a bilingual English and Chinese pair, according to the project changelog. The 200K-context base models followed on November 5 and the chat models on November 23. The original release used a custom community license rather than Apache 2.0. It added a strong open 34B bilingual model to the open-weight field.
