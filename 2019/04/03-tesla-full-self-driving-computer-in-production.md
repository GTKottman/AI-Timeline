# Tesla says its full self-driving computer is in production

- **Date:** 2019-04-03
- **Who:** Tesla
- **Type:** hardware

Tesla announced that its new full self-driving computer, previously called Autopilot Hardware 3.0, was in production. The custom chip, built by Samsung, has neural network accelerators and was shipping in Model S, Model X and Model 3 cars. Tesla said full self-driving would be enabled through later software updates.
