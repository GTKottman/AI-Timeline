# Microsoft Build 2018: Project Brainwave preview and Windows ML

- **Date:** 2018-05-07
- **Who:** Microsoft
- **Type:** hardware

At Build 2018 Microsoft previewed Project Brainwave, an FPGA-based architecture for low-latency real-time AI inference on Azure, running on Intel FPGAs. The same week it announced Windows Machine Learning, the Azure ML SDK for Python in preview, and Project Kinect for Azure. Brainwave showed Microsoft pushing custom hardware for inference alongside GPUs and TPUs.
