# Facebook AI unveils SEER, billion-parameter self-supervised vision model

- **Date:** 2021-03-04
- **Who:** Facebook AI (Meta AI)
- **Type:** model

Facebook AI announced SEER, a self-supervised computer vision model with about a billion parameters, pretrained on a billion uncurated public Instagram images with no labels. It combines RegNet architectures with the SwAV clustering method. SEER reached 84.2% top-1 accuracy on ImageNet, and with only 1% of ImageNet labels it reached 60.5%. It showed that self-supervised learning could work on uncurated data at very large scale.
