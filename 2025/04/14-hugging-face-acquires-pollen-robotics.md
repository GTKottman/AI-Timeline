# Hugging Face acquires Pollen Robotics

- **Date:** 2025-04-14
- **Who:** Hugging Face; Pollen Robotics
- **Type:** acquisition

Hugging Face acquired Pollen Robotics, the French maker of the open-source humanoid Reachy 2, in its first move into hardware. The price was not disclosed. Wired reported that Hugging Face plans to sell Reachy 2 and let developers download the code and suggest improvements.
