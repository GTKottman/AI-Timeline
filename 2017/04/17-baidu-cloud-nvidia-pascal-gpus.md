# Baidu brings NVIDIA Pascal GPUs into its cloud for AI

- **Date:** 2017-04-17
- **Who:** Baidu; NVIDIA
- **Type:** hardware

NVIDIA's April 17, 2017 press release, "Baidu Advances AI in the Cloud with Latest NVIDIA Pascal GPUs," said its deep learning platform was now part of Baidu Cloud's deep learning service, which offers Pascal-based Tesla P40 GPUs and NVIDIA software for TensorFlow and PaddlePaddle.
