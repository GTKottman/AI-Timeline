# OpenAI moves to a "capped-profit" structure

- **Date:** 2019-03-11
- **Who:** OpenAI
- **Type:** funding

OpenAI announced OpenAI LP, a hybrid of for-profit and nonprofit that it called "capped-profit." Investors and employees can earn returns up to a cap, with returns above it going to the nonprofit. The company said it needed billions of dollars for cloud compute, talent and AI supercomputers, which pushed it to a structure that could raise outside capital. The change set up the Microsoft investment that followed in July 2019.
