# AWS Panorama Appliance and Device SDK for edge computer vision

- **Date:** 2020-12-01
- **Who:** Amazon Web Services (AWS)
- **Type:** hardware

At AWS re:Invent 2020, AWS announced the Panorama Appliance, an on-premises device that adds computer vision to existing IP cameras so that models run locally instead of in the cloud. It runs models on several camera streams at once. The appliance launched as a preview, and AWS announced a Panorama Device SDK for device makers to build Panorama-enabled cameras and edge appliances, with partner cameras to follow.
