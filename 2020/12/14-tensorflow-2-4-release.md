# TensorFlow 2.4 released with stable multi-worker distribution

- **Date:** 2020-12-14
- **Who:** Google (TensorFlow team)
- **Type:** software

TensorFlow 2.4 made MultiWorkerMirroredStrategy a stable API and added a preview of asynchronous parameter-server training. It added tf.experimental.numpy, a NumPy-compatible API. The pip packages were built with CUDA 11 and cuDNN 8.0.2.
