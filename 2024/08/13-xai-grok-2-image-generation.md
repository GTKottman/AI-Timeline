# xAI releases Grok-2 with image generation on X

- **Date:** 2024-08-13
- **Who:** xAI
- **Type:** model

Grok-2 was released to X Premium and Premium+ users and was the first Grok model to generate images inside the product. The image generator used the open-source FLUX.1 model from Black Forest Labs. It showed xAI competing directly with image tools inside a social platform.
