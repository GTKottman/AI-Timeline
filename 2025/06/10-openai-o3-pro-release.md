# OpenAI releases o3-pro in the API and ChatGPT Pro

- **Date:** 2025-06-10
- **Who:** OpenAI
- **Type:** model

OpenAI released o3-pro, a version of o3 that uses more compute to reason longer on hard problems. It went live in the developer API the same day at $20 per million input tokens and $80 per million output tokens, which Maginative reports as an 87% price cut from o1-pro. It replaced o1-pro for ChatGPT Pro and Team users, with Enterprise and Edu access the following week.
