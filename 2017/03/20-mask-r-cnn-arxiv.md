# Mask R-CNN: instance segmentation paper (arXiv)

- **Date:** 2017-03-20
- **Who:** Kaiming He, Georgia Gkioxari, Piotr Dollár, Ross Girshick (Facebook AI Research)
- **Type:** paper

Mask R-CNN was posted to arXiv (1703.06870). It adds a parallel mask-prediction branch to Faster R-CNN, so one network detects objects, classifies them and outputs a pixel mask for each. The authors reported top results on the COCO instance segmentation, detection and keypoint tracks, and released code. It became one of the most-used baselines for instance segmentation and later detection systems.
