# Alibaba Qwen3-Next-80B-A3B released

- **Date:** 2025-09-11
- **Who:** Alibaba (Qwen team)
- **Type:** model

Alibaba released Qwen3-Next-80B-A3B on Hugging Face, an open-weight model with 80 billion total parameters and about 3.9 billion active per token. It uses a hybrid Transformer-Mamba design with a 262,144-token native context window, extensible to 1 million with YaRN, and ships as separate Instruct and Thinking variants.
