# Google launches Antigravity agentic development platform

- **Date:** 2025-11-18
- **Who:** Google (Google DeepMind)
- **Type:** software

Google launched Antigravity, an agent-first development platform, alongside Gemini 3, entering the AI IDE race against VS Code-based tools. It offers an Editor View for conventional AI-assisted coding and a Manager View for running several agents in parallel, with agents producing task lists, plans, screenshots and browser recordings as artifacts for review. The public preview was free for individual developers on macOS, Linux and Windows, and users could choose Gemini 3, Claude Sonnet 4.5 or OpenAI's gpt-oss.
