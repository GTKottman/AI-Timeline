# Google publishes PowerSign and AddSign, optimizers found by machine search

- **Date:** 2018-03-28
- **Who:** Google Brain
- **Type:** research

Google Brain posted a blog explaining how it used machine learning to discover neural network optimizers. A recurrent controller, trained with reinforcement learning, picked update rules from simple building blocks. Two discovered rules, PowerSign and AddSign, were competitive across tasks including ImageNet classification and Google's neural machine translation system,. The work built on the ICML 2017 paper "Neural Optimizer Search with Reinforcement Learning."
