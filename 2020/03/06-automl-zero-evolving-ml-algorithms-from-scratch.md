# AutoML-Zero: evolving machine learning algorithms from scratch

- **Date:** 2020-03-06
- **Who:** Google (Esteban Real, Chen Liang, David So, Quoc Le)
- **Type:** research

The paper posted to arXiv in March 2020 asked whether whole machine learning algorithms could be discovered automatically, starting from empty programs built only from basic mathematical operations. Evolutionary search rediscovered ideas such as two-layer networks trained by backpropagation, and found techniques like normalized gradients and weight averaging on CIFAR-10 variants. It was presented at ICML 2020 and pushed AutoML beyond tuning hand-designed layers toward searching over the algorithms themselves.
