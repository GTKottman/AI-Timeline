# DeepMind unveils AlphaCode

- **Date:** 2022-02-02
- **Who:** DeepMind
- **Type:** model

DeepMind introduced AlphaCode, a code-generation system for competitive programming with a largest model of 41.4 billion parameters. In simulated runs on ten Codeforces contests it performed around the median human participant, and the team released its competitive programming dataset. The result showed language models could handle problems that need algorithmic reasoning, not only short code completion.
