# Alibaba releases Qwen2.5-Coder series

- **Date:** 2024-11-11
- **Who:** Alibaba Cloud (Qwen team)
- **Type:** model

Qwen2.5-Coder is a family of six open code models from 0.5B to 32B parameters, built on Qwen2.5 and trained on 5.5 trillion tokens of code-related data. The flagship 32B model supports more than 40 programming languages, with context windows of up to 128,000 tokens. It extended the open coding model options available to developers.
