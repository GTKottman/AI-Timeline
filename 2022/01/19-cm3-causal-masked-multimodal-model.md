# CM3: A Causal Masked Multimodal Model of the Internet

- **Date:** 2022-01-19
- **Who:** Meta AI
- **Type:** paper

CM3 is a generative model trained on web and Wikipedia documents that contain both text and image tokens. It combines left-to-right generation with masking of long spans, so one model can both generate and infill mixed text and image content.
