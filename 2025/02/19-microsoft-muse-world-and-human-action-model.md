# Microsoft unveils Muse, a World and Human Action Model for gameplay

- **Date:** 2025-02-19
- **Who:** Microsoft Research, Ninja Theory, Microsoft Game Intelligence and Teachable AI Experiences teams
- **Type:** model

Microsoft introduced Muse, which it calls the first World and Human Action Model (WHAM), trained on gameplay from the Xbox game Bleeding Edge. It can generate game visuals, predict controller inputs, or both. The research was published in Nature on February 19, 2025. Microsoft released the weights and sample data, and the model is available through Azure AI Foundry; its listing says it is intended for academic research only.
