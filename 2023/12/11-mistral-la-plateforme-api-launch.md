# Mistral AI launches La plateforme API with Mistral Medium

- **Date:** 2023-12-11
- **Who:** Mistral AI
- **Type:** product

Mistral launched La plateforme, a hosted API for its models, on the same day it published Mixtral 8x7B. The platform added Mistral Medium as a proprietary tier alongside the open-weight models. It was Mistral's first step into paid API sales.
