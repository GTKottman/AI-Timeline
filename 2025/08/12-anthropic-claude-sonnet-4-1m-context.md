# Anthropic expands Claude Sonnet 4 to 1 million token context

- **Date:** 2025-08-12
- **Who:** Anthropic
- **Type:** model

Anthropic made a 1 million token context window available in public beta for Claude Sonnet 4 on the Anthropic API and Amazon Bedrock, a five-fold increase that fits codebases of more than 75,000 lines. Prompts above 200K tokens were priced higher, and access began with Tier 4 developers before widening. Vertex AI support followed on 2025-08-26. It mattered as Anthropic matching the long-context window Google and OpenAI already offered.
