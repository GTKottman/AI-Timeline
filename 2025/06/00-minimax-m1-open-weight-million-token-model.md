# MiniMax releases MiniMax-M1, an open-weight reasoning model with 1M context

- **Date:** 2025-06-00
- **Who:** MiniMax
- **Type:** model

MiniMax released MiniMax-M1, an open-weight hybrid mixture-of-experts reasoning model with 456 billion total parameters and about 45.9 billion active per token. It handles a context of up to 1 million tokens. Weights were posted to Hugging Face and GitHub. Sources give June 16 and June 17, 2025 for the release, so the exact day is unresolved.
