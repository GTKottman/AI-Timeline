# Microsoft releases Florence-2 vision foundation model

- **Date:** 2024-06-19
- **Who:** Microsoft Azure AI (Microsoft Research)
- **Type:** model

Microsoft released Florence-2, a unified vision foundation model in 232M and 771M parameter sizes under an MIT license on Hugging Face. One prompt-based interface handles captioning, object detection, segmentation, OCR and region grounding, and Microsoft said the small model could outperform larger specialist models. It was trained on the FLD-5B dataset of 126 million images with 5.4 billion annotations, and Microsoft Research's record ties it to CVPR 2024.
