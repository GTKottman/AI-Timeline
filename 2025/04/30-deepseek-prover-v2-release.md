# DeepSeek releases Prover-V2 for Lean 4 theorem proving

- **Date:** 2025-04-30
- **Who:** DeepSeek
- **Type:** model

DeepSeek uploaded DeepSeek-Prover-V2 to Hugging Face without a formal announcement, in 7B and 671B sizes. The 671B model is built on DeepSeek-V3-Base and targets formal theorem proving in Lean 4. It reached an 88.9% pass ratio on MiniF2F-test and solved 49 of 658 PutnamBench problems, as reported in coverage. DeepSeek also released ProverBench, a 325-problem benchmark.
