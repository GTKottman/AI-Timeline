# PyTorch 1.8 released with stable torch.fft and torch.linalg

- **Date:** 2021-03-04
- **Who:** Meta AI (PyTorch team)
- **Type:** software

PyTorch 1.8 shipped on March 4, 2021 with more than 3,000 commits since 1.7. The release made the NumPy-style torch.fft and torch.linalg APIs stable. DevClass noted that torch.fx was still beta in this release.
