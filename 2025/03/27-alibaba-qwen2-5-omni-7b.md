# Alibaba releases Qwen2.5-Omni-7B, an end-to-end multimodal model for devices

- **Date:** 2025-03-27
- **Who:** Alibaba (Qwen team)
- **Type:** model

Alibaba released Qwen2.5-Omni-7B, a 7-billion-parameter model that takes text, images, audio and video and answers with real-time text and speech. Its Thinker-Talker design splits the text reasoning and speech generation into separate parts so that one does not disturb the other. Alibaba aimed it at phones and laptops and published it on Hugging Face, GitHub and ModelScope, and one source gives an Apache 2.0 licence. Performance claims come from Alibaba.
