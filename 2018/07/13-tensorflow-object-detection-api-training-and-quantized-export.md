# TensorFlow Object Detection API gains faster TPU training and mobile export

- **Date:** 2018-07-13
- **Who:** Google Research (TensorFlow team)
- **Type:** software

Google added Cloud TPU training, an export path to TensorFlow Lite, and new detectors such as RetinaNet, a MobileNet adaptation of RetinaNet, and the Pooling Pyramid Network to the TensorFlow Object Detection API. The post reported that a ResNet-50 RetinaNet reached 35% COCO mAP in under 3.5 hours on Cloud TPUs, so detectors could be trained and served faster and run on phones.
