# Arm unveils Project Trillium machine learning processors

- **Date:** 2018-02-13
- **Who:** Arm
- **Type:** hardware

Arm announced Project Trillium, a suite of processor IP including an ML processor and a separate object detection processor, aimed first at mobile devices. It was designed to bring neural network acceleration to phones and other low-power devices, with support for frameworks such as TensorFlow and Caffe. It signaled that the main chip-IP company was building dedicated AI hardware for edge devices.
