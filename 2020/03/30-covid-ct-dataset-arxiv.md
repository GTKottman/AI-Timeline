# COVID-CT-Dataset: public CT scan dataset for COVID-19 detection posted to arXiv

- **Date:** 2020-03-30
- **Who:** Jinyu Zhao, Yichen Zhang, Xuehai He, Pengtao Xie (first version; later expanded with Xingyi Yang and Shanghang Zhang)
- **Type:** dataset

The first version of this arXiv paper released a public dataset of CT scans from COVID-19 patients, starting with 275 positive scans, for training machine learning detectors. A deep convolutional network trained on it reached an F1 score of about 0.85. Because CT data from patients was scarce in early 2020, a free public set let other groups benchmark COVID-19 CT classifiers. Later versions expanded the set to 349 COVID-19 CT images plus 463 non-COVID CTs.
