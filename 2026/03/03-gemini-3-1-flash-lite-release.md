# Google releases Gemini 3.1 Flash-Lite

- **Date:** 2026-03-03
- **Who:** Google DeepMind
- **Type:** model

Google released Gemini 3.1 Flash-Lite, a model optimized for high-volume, latency-sensitive tasks such as translation and classification. It extended the Gemini 3.1 line to lower-cost, faster tiers for developers.
