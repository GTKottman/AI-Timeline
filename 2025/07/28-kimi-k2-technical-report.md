# Moonshot AI publishes Kimi K2 technical report

- **Date:** 2025-07-28
- **Who:** Moonshot AI
- **Type:** paper

The Kimi K2 paper describes a large language model with 1 trillion total parameters, 32 billion active per token. It introduces MuonClip, an optimizer that extends Muon with a QK-clip method to stabilize training, and a post-training pipeline built on large-scale agentic data synthesis and reinforcement learning. The base and post-trained checkpoints were released publicly.
