# Microsoft releases DeBERTaV3 with ELECTRA-style pretraining

- **Date:** 2021-11-18
- **Who:** Microsoft Research (Pengcheng He, Jianfeng Gao, Weizhu Chen)
- **Type:** model

Microsoft Research posted DeBERTaV3 on arXiv (2111.09543, first version 18 November 2021). It upgrades DeBERTa by replacing masked language modelling with ELECTRA-style replaced token detection, using gradient-disentangled embedding sharing. The authors report results on NLU benchmarks, and the model weights are published on Hugging Face under the microsoft namespace.
