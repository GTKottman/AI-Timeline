# NVIDIA GauGAN turns sketches into photorealistic landscapes

- **Date:** 2019-03-18
- **Who:** NVIDIA (research team)
- **Type:** model

NVIDIA unveiled GauGAN at GTC 2019, a GAN-based tool that turns rough segmentation-style sketches of blocks such as water, snow and grass into nearly photorealistic landscape images. Users paint with bucket, pen and pencil tools, and each run yields a different image for the same sketch. NVIDIA presented it as a demonstration of its neural network platforms, and it showed how semantic maps can drive image synthesis for creative work.
