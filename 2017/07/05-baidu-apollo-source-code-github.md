# Baidu Opens Apollo Autonomous Driving Source Code on GitHub

- **Date:** 2017-07-05
- **Who:** Baidu (COO Lu Qi; partner consortium of more than 50 companies)
- **Type:** software

At Baidu Create, Baidu's first AI developer conference in Beijing, Baidu said the Apollo self-driving platform source code had been posted to GitHub, with Apollo 1.0 aimed at letting developers build autonomous vehicles quickly. The open components covered obstacle perception, trajectory planning, vehicle control and vehicle operating systems, plus testing tools. It mattered because a large Chinese platform company made a full self-driving software stack public and invited outside automakers and developers to build on it.
