# Meta announces the Llama API in limited preview at LlamaCon

- **Date:** 2025-04-29
- **Who:** Meta
- **Type:** product

At its first LlamaCon developer event, Meta launched the Llama API in limited preview for US-based developers. It is free during the preview but requires joining a waitlist, and it includes fine-tuning and evaluation tools. It is compatible with the OpenAI SDK and has Python and TypeScript SDKs. Meta did not share pricing at launch.
