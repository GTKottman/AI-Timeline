# Microsoft invests $1 billion in OpenAI

- **Date:** 2019-07-22
- **Who:** Microsoft, OpenAI
- **Type:** funding

Microsoft agreed to invest $1 billion in OpenAI to pursue artificial general intelligence. It made Microsoft OpenAI's exclusive cloud provider and set up plans to build Azure-based AI supercomputing infrastructure. The deal came as OpenAI moved to its capped-profit structure, and it gave OpenAI the compute it needed to train much larger models.
