# Make-A-Scene: scene-based text-to-image generation

- **Date:** 2022-03-24
- **Who:** Meta AI
- **Type:** paper

Make-A-Scene added a scene layout as an input next to the text prompt, so users could control where objects and regions go in a generated image. The paper showed that a simple extra control signal could make text-to-image generation more usable for artists.
