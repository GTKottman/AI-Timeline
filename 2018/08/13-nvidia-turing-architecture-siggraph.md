# Nvidia unveils Turing GPU architecture with RT and Tensor cores

- **Date:** 2018-08-13
- **Who:** Nvidia (Jensen Huang)
- **Type:** hardware

At SIGGRAPH 2018 in Vancouver, Nvidia unveiled the Turing architecture, its eighth GPU generation, with dedicated RT cores for real-time ray tracing and Tensor cores for deep-learning inference. Initial products were the Quadro RTX 8000, 6000 and 5000. Turing put dedicated AI inference hardware into mainstream graphics GPUs. Note: the exact day (Aug 13) is from memory and was not confirmed in a source.
