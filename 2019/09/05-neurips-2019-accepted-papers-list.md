# NeurIPS 2019 accepted papers list published

- **Date:** 2019-09-05
- **Who:** NeurIPS 2019 organizers (Neural Information Processing Systems conference)
- **Type:** other

The NeurIPS 2019 accepted-papers list went public in early September 2019, with about 1,429 papers selected for the December conference in Vancouver. Universities and labs announced their own acceptances around the same time. The list set the agenda for the field's largest machine learning conference of the year, which ran December 8 to 14, 2019. Exact posting day is taken from a secondary report that says the list appeared the day before its September 6 article, so treat the day as approximate.
