# DeepSeek quietly releases R1-0528, an updated open reasoning model

- **Date:** 2025-05-28
- **Who:** DeepSeek
- **Type:** model

DeepSeek posted an update to R1 on Hugging Face and described it as improved benchmark performance, better front-end coding, fewer hallucinations, and support for JSON output and function calling. The model card reports AIME 2025 accuracy rising from 70% to 87.5%, a figure from the model card. Average reasoning length went from about 12K to about 23K tokens. The model has 685 billion parameters and is under MIT licence, and a distilled DeepSeek-R1-0528-Qwen3-8B variant was released too.
