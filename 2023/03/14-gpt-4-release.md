# OpenAI releases GPT-4, a multimodal model accepting image and text input

- **Date:** 2023-03-14
- **Who:** OpenAI
- **Type:** model

OpenAI introduced GPT-4, a large multimodal model that accepts image and text input and produces text, with stronger reasoning and exam performance than GPT-3.5. It became the reference frontier model of 2023 and was made available to ChatGPT Plus subscribers and API developers.
