# Google releases Gemma 2 2B

- **Date:** 2024-07-31
- **Who:** Google / Google DeepMind
- **Type:** model

Google released the 2-billion-parameter version of Gemma 2, completing the Gemma 2 family after the 9B and 27B models of June 27. It was aimed at running locally on laptops and phones, and it shipped the same day as ShieldGemma and Gemma Scope. The release is listed in Google's official Gemma release log, and it set the open small-model pattern that later Gemma versions followed.
