# Google Releases Open Images V5 with Segmentation Masks

- **Date:** 2019-05-08
- **Who:** Google
- **Type:** dataset

Google released Open Images V5, an update to its large public image dataset, adding segmentation masks for 2.8 million object instances across 350 categories. Segmentation masks give pixel-level labels, which are more detailed than bounding boxes and are used to train and benchmark object segmentation models. The release came with a new instance segmentation track for the Open Images Challenge at ICCV 2019.
