# Microsoft extends OpenAI partnership with multiyear, multibillion-dollar investment

- **Date:** 2023-01-23
- **Who:** Microsoft / OpenAI
- **Type:** funding

Microsoft announced a multiyear, multibillion-dollar investment extending its partnership with OpenAI, with Azure as the exclusive cloud for OpenAI's research and API. Bloomberg reported about $10 billion, which was not confirmed by the companies. The deal put OpenAI models into Bing, Word, PowerPoint and Outlook.
