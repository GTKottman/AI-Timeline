# OpenAI introduces GPTs, customizable ChatGPT versions

- **Date:** 2023-11-06
- **Who:** OpenAI
- **Type:** product

OpenAI introduced GPTs, customized ChatGPT versions with tailored instructions, knowledge files and tools that anyone could build and share. It was an early step toward agent-like AI apps and an app-store style marketplace.
