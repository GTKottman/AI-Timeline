# Google Gemini Diffusion text and code model

- **Date:** 2025-05-20
- **Who:** Google DeepMind
- **Type:** model

Google DeepMind showed Gemini Diffusion at Google I/O, an experimental text and code model that generates output by converting random noise into coherent text or code, instead of predicting one token at a time. Google said it generates content significantly faster than its fastest model so far, with coding performance matching that model. Access is by waitlist.
