# MiniMax open-sources MiniMax-01 with a 4-million-token context

- **Date:** 2025-01-15
- **Who:** MiniMax
- **Type:** model

MiniMax released the MiniMax-01 series as open weights: MiniMax-Text-01, a language model, and MiniMax-VL-01, a vision-language model. The model combines lightning linear attention with softmax layers and mixture-of-experts, with 456 billion total parameters and 45.9 billion active per token. MiniMax claims a 4 million token context. The weights carry a custom model agreement, while the inference code is MIT-licensed. The technical report is arXiv 2501.08313.
