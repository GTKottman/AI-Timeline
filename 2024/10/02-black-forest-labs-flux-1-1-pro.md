# Black Forest Labs releases FLUX 1.1 [pro] and its API

- **Date:** 2024-10-02
- **Who:** Black Forest Labs
- **Type:** model

FLUX 1.1 [pro] became the flagship image model of Black Forest Labs and was offered through a proprietary API. Its release marked the company's move from open research releases toward a commercial API business.
