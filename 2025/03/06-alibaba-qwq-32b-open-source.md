# Alibaba open-sources QwQ-32B reasoning model

- **Date:** 2025-03-06
- **Who:** Alibaba (Qwen team)
- **Type:** model

Alibaba released QwQ-32B, a 32-billion-parameter reasoning model trained with reinforcement learning on Qwen2.5-32B, as open weights on Hugging Face and ModelScope under the Apache 2.0 license. Alibaba says it performs close to DeepSeek-R1, which has 671 billion parameters; that is Alibaba's claim. Coverage dates the release to March 6, 2025, while a March 5 date appears in some listings.
