# OpenAI shows a robot hand solving a Rubik's Cube

- **Date:** 2019-10-16
- **Who:** OpenAI
- **Type:** research

OpenAI's paper "Solving Rubik's Cube with a Robot Hand" trained a Shadow Dexterous Hand entirely in simulation using reinforcement learning with automatic domain randomization. The learned policy transferred to the real robot, which solved the cube with one hand. It showed that sim-to-real transfer could handle fine dexterous manipulation.
