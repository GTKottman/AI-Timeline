# OpenAI brings o1-pro to the developer API at a high price

- **Date:** 2025-03-19
- **Who:** OpenAI
- **Type:** model

OpenAI released o1-pro in its developer API. It costs $150 per million input tokens and $600 per million output tokens, and has a 200,000-token context window with up to 100,000 output tokens, according to TechRepublic. Techzine reported that at first only selected developers who had spent at least $5 on the API could use it. Coverage gives March 19 as the launch date; TechRepublic, dated March 20, reported the announcement on March 20.
