# Google releases Google Assistant SDK for third-party hardware

- **Date:** 2017-04-27
- **Who:** Google
- **Type:** software

Google released a developer preview SDK that lets third parties build Google Assistant into their own speakers and gadgets. Google suggested Raspberry Pi devices for prototyping and supplied a Python sample for the Raspberry Pi 3. The preview lacked hotword support.
