# Google Brain releases TensorFlow Eager Execution preview

- **Date:** 2017-10-31
- **Who:** Google Brain
- **Type:** software

Google Brain introduced eager execution for TensorFlow as an experimental preview: operations run immediately when called from Python, with no Session needed. It made TensorFlow's debugging and dynamic control flow closer to PyTorch's define-by-run style, and models built eagerly could still be exported to graphs for production. The feature was announced as a way to get community feedback on the design.
