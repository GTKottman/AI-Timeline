# Focal loss and RetinaNet for dense object detection (arXiv)

- **Date:** 2017-08-07
- **Who:** Tsung-Yi Lin, Priya Goyal, Ross Girshick, Kaiming He, Piotr Dollár (Facebook AI Research)
- **Type:** paper

"Focal Loss for Dense Object Detection" (arXiv 1708.02002) argued that one-stage detectors lagged two-stage ones mainly because of the huge imbalance between background and object examples. The fix, focal loss, down-weights easy examples in the cross-entropy, and the RetinaNet detector trained with it matched one-stage speed while beating the best two-stage detectors on accuracy. It became a standard loss for object detection.
