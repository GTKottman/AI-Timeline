# Apple releases MLX open-source array framework for Apple silicon

- **Date:** 2023-12-05
- **Who:** Apple, Awni Hannun
- **Type:** software

Apple machine learning researcher Awni Hannun announced MLX on X on December 5, 2023, and Apple published it on GitHub as an open-source array framework for Apple silicon. It has a NumPy-like Python API and a C++ API, with arrays in unified memory so they can move between CPU and GPU without copying. It was pitched as a toolkit for training, fine-tuning and running transformer models on Apple chips.
