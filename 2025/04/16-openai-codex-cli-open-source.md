# OpenAI Codex CLI open-source coding agent

- **Date:** 2025-04-16
- **Who:** OpenAI
- **Type:** software

OpenAI released Codex CLI, a terminal coding agent that reads files, edits code and runs commands on the user's machine, and made it fully open source. It offers Suggest, Auto Edit and Full Auto approval modes, and by default sandboxes shell commands (sandbox-exec on macOS, Docker on Linux). Sam Altman announced it alongside the o3 and o4-mini models.
