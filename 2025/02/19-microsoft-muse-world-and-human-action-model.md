# Microsoft unveils Muse, a World and Human Action Model for gameplay

- **Date:** 2025-02-19
- **Who:** Microsoft Research, Ninja Theory, Microsoft Game Intelligence and Teachable AI Experiences teams
- **Type:** model

Microsoft introduced Muse, which it calls the first World and Human Action Model (WHAM), trained on gameplay from the Xbox game Bleeding Edge. It can generate game visuals, predict controller inputs, or do both, and Microsoft says it keeps a consistent 3D game world. The research was published in Nature the same week, with Microsoft framing it as a tool for developers and for preserving older games.
