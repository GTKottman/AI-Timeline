# Alibaba Tongyi-MAI releases Z-Image open image model

- **Date:** 2025-11-26
- **Who:** Alibaba Tongyi-MAI
- **Type:** model

Tongyi-MAI released Z-Image, an open-weight 6B-parameter image generation model under the Apache 2.0 license. The team published the model on Hugging Face.
