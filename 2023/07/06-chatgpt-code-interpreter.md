# ChatGPT Code Interpreter for Plus users

- **Date:** 2023-07-06
- **Who:** OpenAI
- **Type:** product

OpenAI rolled out Code Interpreter to ChatGPT Plus subscribers. The feature lets ChatGPT run Python in a sandboxed environment with no internet access to analyze uploaded data, make charts, edit files and do math. It began as a plugin alpha in March. Sources differ by a day on the exact date (July 6 vs July 7), so July 6 is the announcement date given by the sources.
