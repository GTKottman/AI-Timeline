# OpenAI releases o1-preview and o1-mini reasoning models

- **Date:** 2024-09-12
- **Who:** OpenAI
- **Type:** model

OpenAI released o1-preview and o1-mini, models trained with reinforcement learning to reason through a chain of thought before answering. They were available to ChatGPT Plus and Team users, and GitHub began testing o1-preview in Copilot the same day. The release started the reasoning-model category that other labs followed.
