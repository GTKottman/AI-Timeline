# Amazon unveils Inferentia inference chip at re:Invent

- **Date:** 2018-11-28
- **Who:** Amazon Web Services (Andy Jassy keynote)
- **Type:** hardware

At re:Invent 2018, AWS unveiled Inferentia, its custom machine learning inference chip, along with Elastic Inference, a GPU-powered inference acceleration service. The chip was to be available through EC2 and SageMaker and to work with frameworks such as TensorFlow and PyTorch. AWS said it was expected to be available in 2019. It mattered as Amazon's own silicon for serving models.
