# Microsoft makes Azure Machine Learning service generally available

- **Date:** 2018-12-04
- **Who:** Microsoft
- **Type:** product

Microsoft announced that the Azure Machine Learning service was generally available, a cloud service for building, training and deploying models. Its features included automated model selection and hyperparameter tuning, deployment to the cloud, on premises or the edge (IoT), and a Python SDK with development environments for Visual Studio Code, PyCharm, Jupyter and Azure Databricks notebooks. Pricing was set to take effect February 1, 2019.
