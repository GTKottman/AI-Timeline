# DeepSeek releases DeepSeek-V2 open mixture-of-experts model

- **Date:** 2024-05-06
- **Who:** DeepSeek
- **Type:** model

DeepSeek open-sourced DeepSeek-V2, a 236-billion-parameter mixture-of-experts model with 21 billion parameters active per token, in base and chat versions under the MIT license for code. Its design cut inference cost sharply, and its low API price set off a price war among Chinese model providers. The smaller DeepSeek-V2-Lite followed on May 16. The May 6 date comes from a third-party listing and the official repository changelog; check the repository for the exact day.
