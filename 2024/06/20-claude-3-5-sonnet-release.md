# Anthropic releases Claude 3.5 Sonnet with Artifacts

- **Date:** 2024-06-20
- **Who:** Anthropic
- **Type:** model

Claude 3.5 Sonnet outperformed Claude 3 Opus on many evaluations while running about twice as fast and at a lower price ($3 per million input tokens against Opus's $15). Anthropic launched Artifacts alongside it, a workspace beside the chat where generated code, documents and web designs can be viewed and edited. It set a new point of comparison for coding assistants.
