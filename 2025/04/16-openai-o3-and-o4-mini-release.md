# OpenAI releases o3 and o4-mini with tool use in ChatGPT

- **Date:** 2025-04-16
- **Who:** OpenAI
- **Type:** model

OpenAI released o3, its strongest reasoning model at the time, along with the smaller and cheaper o4-mini. Both were trained to think longer before answering and could use the tools inside ChatGPT, including web search and Python analysis of uploaded files. Plus, Pro and Team users got both in the model selector, and developers got them through the Chat Completions and Responses APIs. API prices were $10 input / $40 output per million tokens for o3 and $1.10 / $4.40 for o4-mini.
