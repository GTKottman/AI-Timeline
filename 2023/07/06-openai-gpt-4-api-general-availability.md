# OpenAI makes GPT-4 API generally available

- **Date:** 2023-07-06
- **Who:** OpenAI
- **Type:** product

OpenAI made the GPT-4 API (8K context) generally available, first to developers with a history of successful payments, with new developers promised later that month. GPT-3.5 Turbo, DALL-E and Whisper APIs were opened broadly the same day, and older Completions models were set to retire. This moved GPT-4 from a waitlist to a production service that developers could build on.
