# Apple Core ML Model Deployment at WWDC 2020

- **Date:** 2020-06-22
- **Who:** Apple
- **Type:** software

At WWDC 2020 Apple added Model Deployment to Core ML. Developers can update a model over the air without shipping a new app build. The same update added model encryption in Xcode, and Create ML gained video action-classification and image/video style-transfer templates. The date is inferred from the report that the updates followed the Monday keynote, which was June 22.
