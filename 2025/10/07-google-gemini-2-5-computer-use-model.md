# Google releases Gemini 2.5 Computer Use model for browser and app agents

- **Date:** 2025-10-07
- **Who:** Google DeepMind
- **Type:** model

Google DeepMind released Gemini 2.5 Computer Use, a model built on Gemini 2.5 Pro for agents that operate user interfaces by clicking, typing and scrolling in browsers and mobile apps. It went into preview through the Gemini API, Google AI Studio and Vertex AI. Developers can set the agent to refuse or ask for confirmation before high-stakes actions. Google's performance claims are partly self-reported and partly from Browserbase tests. One report says it works only through the browser.
