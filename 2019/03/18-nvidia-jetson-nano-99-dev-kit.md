# Nvidia announces $99 Jetson Nano developer kit

- **Date:** 2019-03-18
- **Who:** Nvidia
- **Type:** hardware

At GTC 2019 Nvidia unveiled the Jetson Nano, a $99 AI computer for makers, students and developers. It has a 128-core Maxwell GPU, a quad-core Arm CPU and 4GB of memory, and runs full desktop Linux with JetPack 4.2. It brought CUDA-based neural network inference to low-cost edge devices, which helped spread AI experimentation to hobbyists and robotics projects.
