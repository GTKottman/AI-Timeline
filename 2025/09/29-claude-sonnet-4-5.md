# Anthropic releases Claude Sonnet 4.5 and the Claude Agent SDK

- **Date:** 2025-09-29
- **Who:** Anthropic
- **Type:** model

Anthropic released Claude Sonnet 4.5, which it called its best coding model and its strongest option for building agents and using computers. Anthropic reported 61.4% on OSWorld, up from 42.2% for Sonnet 4, and kept the price the same as Sonnet 4. It shipped with updates to Claude Code and the new Claude Agent SDK.
