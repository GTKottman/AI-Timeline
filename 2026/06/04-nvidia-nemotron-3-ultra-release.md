# NVIDIA releases Nemotron 3 Ultra open model

- **Date:** 2026-06-04
- **Who:** NVIDIA
- **Type:** model

NVIDIA released Nemotron 3 Ultra, an open model with 550B total and 55B active parameters. The release includes NVFP4 and BF16 checkpoints, datasets, and the training recipes in the Nemotron developer repository.
