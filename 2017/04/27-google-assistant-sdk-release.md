# Google releases Google Assistant SDK for third-party hardware

- **Date:** 2017-04-27
- **Who:** Google
- **Type:** software

Google released a software development kit that lets third parties build Google Assistant into their own speakers and gadgets, including Raspberry Pi-based devices. It opened the Assistant to hardware makers beyond Google's own Home speaker. It was a key step in making Google Assistant available across third-party devices.
