# Vectra raises $100M Series E for AI-driven network security

- **Date:** 2019-06-10
- **Who:** Vectra AI; lead investor TCV, with Khosla Ventures and Accel participating
- **Type:** funding

Vectra, a network detection and response company that uses machine learning to spot attacker behaviour inside enterprise networks, closed a $100 million Series E led by TCV. Existing investors Khosla Ventures and Accel also took part. The round showed that AI-driven security analytics was attracting late-stage capital in 2019.
