# AlphaFold Protein Structure Database launches

- **Date:** 2021-07-22
- **Who:** DeepMind and EMBL-EBI
- **Type:** dataset

DeepMind and EMBL-EBI launched a public database with more than 350,000 AlphaFold-predicted protein structures, later expanded much further. Researchers could look up predicted structures freely, which made AI-generated scientific data widely usable.
