# Mistral releases Mathstral 7B and Codestral Mamba

- **Date:** 2024-07-16
- **Who:** Mistral AI; Project Numina
- **Type:** model

Mistral released two open models on the same day: Mathstral 7B, built with Project Numina for math reasoning, and Codestral Mamba, a code model using the Mamba state-space architecture under Apache 2.0. It showed Mistral testing non-transformer designs and domain-specialised small models.
