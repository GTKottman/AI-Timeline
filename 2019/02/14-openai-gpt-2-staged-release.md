# OpenAI announces GPT-2 and withholds the full model

- **Date:** 2019-02-14
- **Who:** OpenAI
- **Type:** model

OpenAI announced GPT-2, a large transformer language model trained to predict the next word on about 40GB of internet text. It did not release the full model, citing misuse concerns, and instead published a much smaller version and a technical paper. The withheld release sparked a wide debate about responsible disclosure in AI research. The full 1.5B-parameter model followed in November 2019.
