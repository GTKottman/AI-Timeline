# DeepMind introduces MuZero

- **Date:** 2020-12-23
- **Who:** DeepMind
- **Type:** model

DeepMind introduced MuZero, a reinforcement learning system that masters Go, chess, shogi and Atari games without being given the rules. It learns a model of the environment that predicts only the quantities needed for planning. The result removed the need for hand-coded game rules in strong game-playing AI.
