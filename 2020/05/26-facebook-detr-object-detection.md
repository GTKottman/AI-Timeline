# Facebook AI releases DETR, end-to-end object detection with transformers

- **Date:** 2020-05-26
- **Who:** Facebook AI (Carion, Massa, Synnaeve, Usunier, Kirillov, Zagoruyko)
- **Type:** paper

The arXiv paper "End-to-End Object Detection with Transformers" (arXiv:2005.12872) recast object detection as direct set prediction with a transformer encoder-decoder and bipartite matching loss. It removed hand-designed parts such as anchor generation and non-maximum suppression. Results matched Faster R-CNN on COCO, and the code and pretrained models were released on GitHub.
