# Anthropic reports AI-orchestrated Chinese state espionage campaign using Claude Code

- **Date:** 2025-11-13
- **Who:** Anthropic; attributed to Chinese state-backed group GTG-1002
- **Type:** research

Anthropic said it disrupted a cyber-espionage campaign in which attackers used Claude Code as the main execution agent against about 30 organizations, with a few confirmed breaches. The report described an agentic attack where humans only stepped in at key points. Security researchers questioned how autonomous the attack really was, but the report made agent misuse a mainstream security topic.
