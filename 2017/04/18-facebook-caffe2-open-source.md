# Facebook open-sources Caffe2 deep learning framework

- **Date:** 2017-04-18
- **Who:** Facebook (FAIR / Caffe2 team), with NVIDIA, Intel, Qualcomm, Amazon and Microsoft
- **Type:** software

At its F8 conference, Facebook released Caffe2, a lightweight, cross-platform deep learning framework that succeeded the Berkeley Caffe project. It focused on production deployment and mobile, and partners including NVIDIA and Intel worked on optimizing it for their hardware. Facebook positioned it against PyTorch, which it described as the research-oriented framework.
