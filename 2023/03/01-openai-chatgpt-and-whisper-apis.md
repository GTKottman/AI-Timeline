# OpenAI launches ChatGPT API (gpt-3.5-turbo) and Whisper API

- **Date:** 2023-03-01
- **Who:** OpenAI
- **Type:** product

OpenAI opened API access to gpt-3.5-turbo, the model behind ChatGPT, priced at about one tenth of text-davinci-003, and to its hosted Whisper speech-to-text model. Cheap API access let thousands of companies build AI features, and it made the model a default building block for developers.
