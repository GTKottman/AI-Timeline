# Anthropic launches Claude Cowork research preview

- **Date:** 2026-01-12
- **Who:** Anthropic
- **Type:** product

Anthropic launched Claude Cowork as a research preview: a desktop computer agent built on Claude Code and aimed at non-technical users for general productivity work on files and tasks. It first reached Claude Max subscribers in the macOS app, with other users sent to a waitlist. Sources differ on the date of the broader rollout; one site says the full research-preview launch with connectors, plugins and skills came January 30. It marked Anthropic's move from coding agents into general knowledge-work agents.
