# Anthropic publishes Scaling Monosemanticity and Golden Gate Claude

- **Date:** 2024-05-21
- **Who:** Anthropic (Adly Templeton, Tom Henighan and team)
- **Type:** research

Anthropic published "Scaling Monosemanticity," which used dictionary learning to extract millions of interpretable features from Claude 3 Sonnet, including features tied to concepts such as the Golden Gate Bridge, deception and dangerous content. To show the method, Anthropic ran a public demo, Golden Gate Claude, with the bridge feature amplified, for about 24 hours. It was a large step in mechanistic interpretability on a production-scale model.
