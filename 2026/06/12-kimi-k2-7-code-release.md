# Moonshot releases Kimi K2.7-Code open-weight coding model

- **Date:** 2026-06-12
- **Who:** Moonshot AI
- **Type:** model

Moonshot AI released Kimi K2.7-Code on June 12, 2026, a coding-focused successor to K2.6 with 1 trillion total parameters (32 billion active), open weights on Hugging Face under a Modified MIT licence, and a 256K-token context that accepts image and video input. Moonshot says it uses about 30% fewer reasoning tokens than K2.6 and scores 62.0 on Kimi Code Bench V2 against 50.9 for K2.6. These benchmark figures are vendor-reported and not independently verified, and pricing differs by provider.
