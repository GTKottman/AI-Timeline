# Scaling Laws for Reward Model Overoptimization

- **Date:** 2022-10-19
- **Who:** OpenAI researchers
- **Type:** research

The paper measured how optimizing a model against an imperfect proxy reward model affects its true performance, using a fixed reference reward model to stand in for human raters. It showed that past a point more optimization makes results worse, which became a standard concern in RLHF work.
