# GitHub announces Copilot X, built on GPT-4

- **Date:** 2023-03-22
- **Who:** GitHub (Microsoft), OpenAI
- **Type:** product

GitHub unveiled Copilot X, its plan for AI-assisted development, adding an in-editor chat interface, pull request descriptions, and adopting OpenAI's GPT-4 for these chat features. It mattered as one of the first large developer tools to build a full conversational assistant on GPT-4 inside the IDE.

Sources differ on the day: most report March 22, while some outlets and one GitHub blog URL point to March 23.
