# Mistral launches Codestral, its first code model

- **Date:** 2024-05-29
- **Who:** Mistral AI
- **Type:** model

Codestral is a 22-billion-parameter code model trained on more than 80 programming languages, including Python, Java, C++ and JavaScript. Mistral called it open, though TechCrunch noted its license bars commercial use. It integrates with LlamaIndex, LangChain, Continue.dev and Tabnine, and was Mistral's first generative model specialised for coding.
