# OpenAI releases GPT-4.5

- **Date:** 2025-02-27
- **Who:** OpenAI
- **Type:** model

OpenAI released GPT-4.5, a large model it described as its most knowledgeable and lowest-hallucination chat model so far, with less focus on step-by-step reasoning than the o-series.
