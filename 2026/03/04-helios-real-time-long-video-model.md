# Helios real-time long video model released

- **Date:** 2026-03-04
- **Who:** Peking University, ByteDance (with reported contributions from Canva and Chengdu Anu Intelligence)
- **Type:** model

Helios is a 14B-parameter autoregressive diffusion model that generates minute-scale video in near real time, reported at 19.5 FPS on a single NVIDIA H100. It supports text-to-video, image-to-video and video-to-video and is released with code, weights and three checkpoints under Apache 2.0. It matters because long, fast video generation on one GPU makes open video models usable for interactive work rather than only offline rendering.
