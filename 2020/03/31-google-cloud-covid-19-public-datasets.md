# Google Cloud opens COVID-19 public datasets with BigQuery ML for researchers

- **Date:** 2020-03-31
- **Who:** Google Cloud (COVID-19 Public Dataset Program)
- **Type:** dataset

Google Cloud made a set of public health and COVID-19 datasets free to query in BigQuery, including Johns Hopkins CSSE case data, World Bank global health data and OpenStreetMap data. Researchers could train models directly on this data with BigQuery ML at no extra compute cost. The launch gave researchers in the pandemic a single hosted place to combine case counts with other data, and the program was for educational and research use only.
