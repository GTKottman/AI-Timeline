# Microsoft releases phi-1.5, a 1.3-billion-parameter model

- **Date:** 2023-09-00
- **Who:** Microsoft Research
- **Type:** model

Microsoft released phi-1.5, a 1.3-billion-parameter language model trained on the phi-1 data sources plus about 20 billion new synthetic "textbook-like" tokens, with generic web-crawl data excluded. Microsoft reported performance comparable to models five times larger on its own tests of common-sense reasoning and basic math and coding. It showed that small models trained on curated synthetic text could compete with much larger ones. The release month is September 2023, from the arXiv ID 2309.05463; the exact day was not confirmed.
