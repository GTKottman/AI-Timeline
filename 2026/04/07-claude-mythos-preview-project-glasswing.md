# Anthropic announces Claude Mythos Preview for cyber defence

- **Date:** 2026-04-07
- **Who:** Anthropic
- **Type:** model

Anthropic announced Claude Mythos Preview, a limited-access model given to 11 companies and organisations to find and fix software vulnerabilities under Project Glasswing. Anthropic withheld broad release because of its offensive cyber capability, a new pattern for frontier releases.
