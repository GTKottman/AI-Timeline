# Google DeepMind publishes Frontier Safety Framework v2.0

- **Date:** 2025-02-04
- **Who:** Google DeepMind
- **Type:** policy

Version 2.0 of DeepMind's Frontier Safety Framework defines critical capability levels for misuse in CBRN, cyber and machine learning R&D, and adds an exploratory section on deceptive alignment. It recommends particularly high security levels for models whose ML R&D capabilities could significantly speed up or automate AI development. DeepMind's frontier safety page now lists later versions, so v2.0 is superseded.
