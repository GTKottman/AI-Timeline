# Mistral releases Devstral, an open-source coding agent model

- **Date:** 2025-05-21
- **Who:** Mistral AI, with All Hands AI
- **Type:** model

Mistral released Devstral Small 24B, a 24-billion-parameter open model for software engineering agents, built with All Hands AI and fine-tuned from Mistral Small 3.1. It is released under Apache 2.0 and targets multi-file edits, codebase exploration and bug fixes. Mistral reports 46.8% on SWE-bench Verified, a figure from its own evaluation.
